Question

Let ( p(x) = 6x^4 + 7x^3 + ax^2 + bx + c ), where ( a ), ( b ), and ( c ) are constants. When ( p(x) ) is divided by ( x+2 ) and when ( p(x) ) is divided by ( x-2 ), the two remainders are equal. It is given that ( p(x) = (lx^2 + 5x + 8)(2x^2 + mx + n) ), where ( l ), ( m ), and ( n ) are constants.

(a) Find ( l ), ( m ), and ( n ). (5 marks)

(b) How many real roots does the equation ( p(x) = 0 ) have? Explain your answer. (5 marks)

深度分析

多項式　認知層次：分析　建議作答 300 秒

核心公式／定理：$p(x) \equiv (lx^2 + 5x + 8)(2x^2 + mx + n)$、$R = p(-2) = p(2)$

提示 1（啟發）
Hint1: 比較最高次項係數是求 $l, m$ 的最快方法。
提示 2（知識）
Hint2: 餘數定理指出 $p(-2) = p(2)$，代入計算即可解出 $n$。
提示 3（破題）
Hint3: 解釋實根時需檢查二次因式的判別式 $\Delta$ 及是否為完全平方數。

速解策略：先比係數得 $l,m$；再代 $x=\pm2$ 令餘數相等解 $n$；最後分析 $(2x^2+mx+n)$ 的 $\Delta$ 判斷實根數目並解釋。
