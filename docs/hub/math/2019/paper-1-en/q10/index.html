Question

It is given that ( h(x) ) is partly constant and partly varies as ( x ). Suppose that ( h(-2) = -96 ) and ( h(5) = 72 ).

(a) Find ( h(x) ). (3 marks)

(b) Solve the equation ( h(x) = 3x^2 ). (2 marks)

深度分析

變分　認知層次：應用　建議作答 180 秒

核心公式／定理：$h(x) = \begin{cases} a & x < c \\ b(x-c) + d & x \ge c \end{cases}$、$x^2 - px - q = 0$

提示 1（啟發）
Hint1: 變分函數通常由一條水平線與一條斜線組成，注意連接點連續性。
提示 2（知識）
Hint2: 利用 $h(-2)$ 判斷其位於常數段還是變數段，以此決定參數設定方式。
提示 3（破題）
Hint3: 解出方程後務必檢查每個 $x$ 值是否落在對應的分段定義域內。

速解策略：先畫草圖定變分點，代入兩點求參數；解方程時分段處理並嚴格檢查定義域。
