Question

Find the range of values of $ k $ such that the circle $ x^2 + y^2 + 2x - 2y - 7 = 0 $ and the straight line $ 3x - 4y + k = 0 $ intersect.

  • A. $-8 < k < 22$
  • B. $-8 \leq k \leq 22$
  • C. $ k < -22 $ or $ k > 8 $
  • D. $ k \leq -22 $ or $ k \geq 8 $
Share on WhatsAppShare on Telegram

Answer

Correct answer: B. -8 \leq k \leq 22

深度分析

圓與直線的相交條件　認知層次：分析　建議作答 90 秒

核心公式／定理：(x-a)^2 + (y-b)^2 = r^2、d = |Ax_0 + By_0 + C| / \sqrt{A^2 + B^2}

提示 1（啟發）
首先，請將圓的方程式配方，找出圓心坐標 $(a,b)$ 與半徑 $r$。
提示 2（知識）
其次，利用點到直線距離公式，計算圓心到直線 $3x-4y+k=0$ 的距離 $d$。
提示 3（破題）
最後，根據「相交」的定義（相割或相切），建立不等式 $d \le r$ 並求解 $k$ 的範圍。

誘答項逆向工程

A

概念錯誤　混淆相交與相割的定義範圍

學生算出距離不等式後，誤以為「相交」僅指兩個不同交點（相割），忽略了相切時也算作相交的一種情況，因此錯誤地使用了嚴格不等號 <。
B　✓ 正確答案
C

計算粗心　圓心坐標或半徑計算錯誤

學生在將圓的一般式 $x^2+y^2+2x-2y-7=0$ 轉為標準式時出錯，可能算錯了圓心 $(\pm1, \mp1)$ 或半徑平方 $r^2$ 的數值，導致後續距離公式中的常數項計算偏差。
D

策略錯誤　不等號方向判斷錯誤

學生正確算出臨界值 $k=\pm8$，但在解絕對值不等式 $|k+8| \le 30$ 時，錯誤地將結果寫成「或」的關係（相離條件），而非「且」的範圍。

速解策略：配方得圓心 $(\pm1, \mp1)$，半徑 $r=4$；利用距離公式建 $|k+8|/5 \le 4$。
