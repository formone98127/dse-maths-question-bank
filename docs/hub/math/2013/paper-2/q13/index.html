題目

已知 $z$ 隨 $x$ 正變且隨 $\sqrt{y}$ 反變。若 $y$ 減少 $64\%$ 且 $z$ 增加 $25\%$，則 $x$

  • A. 增加 $20\%$。
  • B. 增加 $80\%$。
  • C. 減少 $25\%$。
  • D. 減少 $75\%$。

深度分析

比例關係與百分比變化　認知層次：應用　建議作答 90 秒

核心公式／定理：z = k * x / sqrt(y)、新舊值關係式：(1+p_x)/(1-p_y_sqrt) = 新/舊比例係數

提示 1（啟發）
首先寫出 z 與 x, y 之間的數學關係式，注意是隨 sqrt(y) 反變。
提示 2（知識）
計算當 y 減少 64% 時，sqrt(y) 實際減少了多少百分比？
提示 3（破題）
將已知的 y 與 z 的變化率代入公式，解出 x 的變化百分比。

誘答項逆向工程

A

計算粗心　平方根計算錯誤

忽略了 y 減少 64% 後其平方根僅減少 40%，誤以為 sqrt(y) 也減少 64%，導致分母變化算錯，進而得出 x 需增加 20% 的錯誤結論。
B

概念錯誤　反變概念混淆

未能正確理解隨 sqrt(y) 反變的含義，可能誤認為 y 減少會導致 x 大幅增加以補償，或錯誤地將分母變化直接轉化為分子增加的百分比。
C　✓ 正確答案
D

計算粗心　百分比方向搞反

正確算出 sqrt(y) 減少 40%，但在設定方程式時，錯誤地將分子 x 的變化方向與分母關係弄反，或誤以為 x 需減少才能維持平衡。

速解策略：設原值為 1，新 sqrt(y) 為 0.6，新 z 為 1.25，則新 x = 1.25 * 0.6 = 0.75，即減少 25%。
