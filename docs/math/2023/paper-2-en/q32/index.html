Question

The L.C.M. of $a^{4} b^{2} c$, $a^{3} b^{4} c$ and $a^{2} b^{5} c^{2}$ is

  • A. $a^{2} b^{2} c$
  • B. $a^{2} b^{2} c^{2}$
  • C. $a^{4} b^{5} c$
  • D. $a^{4} b^{5} c^{2}$

Answer

Correct answer: D. a^{4} b^{5} c^{2}

深度分析

指數法則與最小公倍數　認知層次：應用　建議作答 45 秒

核心公式／定理：L.C.M.(a^x b^y c^z, a^p b^q c^r) = a^{max(x,p)} b^{max(y,q)} c^{max(z,r)}

提示 1（啟發）
回顧指數法則：當兩個數相乘時，相同底數的指數會相加；求公倍數時需考慮所有質因數。
提示 2（知識）
最小公倍數 (L.C.M.) 的定義是能被這兩個數整除的最小正整數，因此每個質因數的指數應取兩者中的最大值。
提示 3（破題）
分別比較 a, b, c 三個底數在兩個式子中的指數：max(4,3), max(2,4), max(1,2)。

誘答項逆向工程

A

概念錯誤　混淆 L.C.M. 與 G.C.M.

學生誤以為求最小公倍數要取指數的最小值，這其實是求最大公約數 (G.C.M.) 的作法，導致選出 a^2b^2c。
B

計算粗心　未比較 c 指數

學生正確找出 a 與 b 的最大指數，但在處理 c 時，錯誤地取了最小值 1 而非最大值 2，或單純抄錯題目中的 c^2。
C

概念錯誤　忽略 c 的指數

學生在比較 a 與 b 時無誤，但在處理 c 時完全遺漏了題目中的 c^2，錯誤地將其視為 c^1。
D　✓ 正確答案

速解策略：對每個變數取指數的最大值，即 a^{max(4,3)}b^{max(2,4)}c^{max(1,2)}
