題目

圖 5(a) 顯示以正方形為底的直立角錐體 VABCD ，其中 ∠VAB = 72° 。該底的邊長為 20 cm 。設 P 及 Q 分別為 VA 及 VD 上的點使得 PQ 平行於 BC 且 ∠PBA = 60° 。從 VABCD 切去角錐體 VPBCQ 造成一幾何模型，如圖 5(b) 所示。

(a) 求 AP 的長度。 (2 分)

(b) 設 α 爲平面 PBCQ 與底 ABCD 間之交角。

(i) 求 α 。 (3 分)

(ii) 設 β 爲 PB 與底 ABCD 間之交角。α 與 β 哪一個較大？試解釋你的答案。 (6 分) | | | | | | | | | | | | | | | | | | | | | | | | | | | | | | |

深度分析

立體幾何　認知層次：應用　建議作答 420 秒

核心公式／定理：cos A = (b^2 + c^2 - a^2) / (2bc)、sin θ = opposite / hypotenuse

提示 1（啟發）
先畫出直立角錐側視圖，標明已知角度與邊長。
提示 2（知識）
回憶：二面角之平面角需由兩平面交線上一點作垂線至各平面。
提示 3（破題）
提示：PQ∥BC 且 BC⊥平面 VAD ⇒ PQ⊥平面 VAD，故截面 PBCQ 為梯形。

速解策略：先解△VAB 得 VA，再由相似或比例求 AP；二面角取 AD 中點作垂線，線面角則投影 PB 至底面。
