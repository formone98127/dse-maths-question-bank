題目

For $ 0^\circ \leq x < 360^\circ $, how many roots does the equation $ \cos^2 x - \sin x = 1 $ have?

  • A. 2
  • B. 3
  • C. 4
  • D. 5

深度分析

三角函數　認知層次：分析　建議作答 60 秒

核心公式／定理：$\cos^2 x + \sin^2 x = 1$

提示 1（啟發）
提示 1：利用畢氏恆等式 $\cos^2 x = 1 - \sin^2 x$ 將原方程轉換成僅含 $\sin x$ 的一元二次方程式。
提示 2（知識）
提示 2：解出該一元二次方程式後，你會得到關於 $\sin x$ 的兩個不同數值，請分別列出所有可能的角度解。
提示 3（破題）
提示 3：最後務必檢查每一個求得的 $x$ 值是否滿足題目給定的範圍條件 $0^\circ \leq x < 360^\circ$

誘答項逆向工程

A

計算粗心　漏解根

解出 $\sin x = -1$ 後，只寫出 $x=270^\circ$ 這一個解，忘記了 $\sin x = 0$ 時對應的 $x=0^\circ, 360^\circ(排除)$ 與 $x=180^\circ$
B　✓ 正確答案
C

計算粗心　多算根

將 $x=360^\circ$ 誤認為在範圍內，或錯誤地將 $\sin x = -1$ 的解算出兩個值（如混淆週期性），導致總數變成 4 個。
D

策略錯誤　範圍判斷錯誤

完全忽略題目給定的 $0^\circ \leq x < 360^\circ$ 的嚴格不等號，將 $x=360^\circ$ 也計入根數中，導致總數多算一個。

速解策略：代換 $\cos^2 x$，解一元二次式得 $\sin x$ 值，再求角度並檢查範圍。
