題目

令 $h$ 成為公式 $9(h+6k)=7h+8$ 的主項。 (3分)

WhatsApp 分享Telegram 分享

深度分析

主項變換　認知層次：應用　建議作答 90 秒

核心公式／定理：ax + b = c \Rightarrow x = \frac{c - b}{a}

提示 1（啟發）
先展開左邊括號：9h + 54k = 7h + 8
提示 2（知識）
將所有 h 移到一邊：9h - 7h = 8 - 54k
提示 3（破題）
最後除以 h 的係數即可

速解策略：展開後移項合併，得 2h = 8 - 54k，再除以 2。
