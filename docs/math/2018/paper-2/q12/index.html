題目

設 $ a_n $ 為某數列的第 $ n $ 項。若 $ a_3 = 21 $ 、 $ a_6 = 89 $ 及對任意正整數 $ n $，$ a_{n+2} = a_n + a_{n+1} $，則 $ a_1 = $

  • A. 8
  • B. 13
  • C. 34
  • D. 55

深度分析

線性遞迴數列 (Fibonacci 類)　認知層次：分析　建議作答 90 秒

核心公式／定理：$ a_{n+2} = a_n + a_{n+1} $、$ a_6 = a_4 + a_5 = (a_3 + a_4) + (a_3 + 2a_4) $

提示 1（啟發）
提示 1：利用遞迴公式 $a_{n+2} = a_n + a_{n+1}$，將所有項用 $a_3$ 和 $a_4$ 表示。
提示 2（知識）
提示 2：觀察 $a_6$ 與 $a_3, a_4$ 的係數關係，建立關於 $a_4$ 的一次方程式求解。
提示 3（破題）
提示 3：求得 $a_4$ 後，利用 $a_5 = a_3 + a_4$ 和 $a_6 = a_4 + a_5$ 驗證，最後由 $a_4 = a_3 + a_2$ 及 $a_3 = a_1 + a_2$ 解出 $a_1$

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　係數計算錯誤

將 $a_6$ 表達為 $3a_4 + 2a_3$ 時，誤算係數或代入數值時出錯，導致解得 $a_1=13$
C

概念錯誤　混淆遞迴關係

誤以為 $a_6$ 與 $a_3$ 之間有直接倍數關係，或直接套用 Fibonacci 標準值而忽略初始條件不同
D

策略錯誤　方向錯誤

嘗試從 $a_1$ 正向推導至 $a_6$，但因未知數過多而放棄或隨意猜測大數字選項

速解策略：將 $a_6$ 用 $a_3, a_4$ 表示，解出 $a_4$，再倒推求 $a_1$
