題目

某劇院的座位由第一行至最後一行及由左至右按數目次序編號，如圖 7 所示。第一行有 12 個座位。接着的每一行較前一行多 3 個座位。若該劇院不能容納多於 930 個座位，該劇院最多有多少行座位？

深度分析

數列　認知層次：應用　建議作答 90 秒

核心公式／定理：$a_n = a_1 + (n-1)d$、$S_n = \frac{n}{2}[2a_1 + (n-1)d]$

提示 1（啟發）
回想等差數列首項與公差的定義。
提示 2（知識）
確認 S_n 公式中的係數是否正確代入。
提示 3（破題）
解出 n 後，務必檢查是否符合「最多」的條件。

速解策略：用 S_n = n/2[24 + (n-1)3] ≤ 930 化簡得 3n²+9n-1860≤0，解出正根後取整數上限。
