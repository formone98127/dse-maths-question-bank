Question

Let $I = \int_{1}^{4} \frac{1}{\sqrt{t}} e^{-\frac{t}{2}} \mathrm{d}t$.

(a) (i) Use the trapezoidal rule with 6 sub-intervals to estimate $I$.

(ii) Is the estimate in (a)(i) an over-estimate or under-estimate? Justify your answer.

(7 marks)

(b) Using a suitable substitution, show that $I = 2 \int_{1}^{2} e^{-\frac{x^2}{2}} \mathrm{d}x$.

(3 marks)

(c) Using the above results and the Standard Normal Distribution Table on page 14, show that $\pi < 3.25$.

(3 marks)

深度分析

積分法　認知層次：應用　建議作答 420 秒

核心公式／定理：\int_{a}^{b} f(x) dx \approx \frac{h}{2}[f(x_0) + 2f(x_1) + \dots + 2f(x_n) + f(x_n)]、\text{若 } f'(x) < 0, \text{則曲線為凹向上 (convex), 梯形法則高估}、\Phi(z) = P(Z \le z)

提示 1（啟發）
提示 1：梯形法則公式中，中間點的係數是 2，端點是 1。
提示 2（知識）
提示 2：判斷高估/低估時，觀察 f(t) 是否為減函數且曲線凹向上（convex）。
提示 3（破題）
提示 3：代換後注意 \sqrt{t} 與 e^{-t/2} 的係數變化，通常會出現 \pi 相關項。

速解策略：先算梯形法則數值；再求二階導數判斷凹凸性；最後用 t=2x^2 代換並查表比較大小。
