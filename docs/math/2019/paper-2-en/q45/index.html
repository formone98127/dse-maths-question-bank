Question

The mean, the range and the variance of a set of numbers are $m$, $r$ and $v$ respectively. Each number of the set is multiplied by 6 and then 5 is added to each resulting number to form a new set of numbers. Which of the following is/are true? I. The mean of the new set of numbers is $6m+5$. II. The range of the new set of numbers is $6r+5$. III. The variance of the new set of numbers is $6v+5$.

  • A. I only.
  • B. II only.
  • C. I and III only.
  • D. II and III only.
Share on WhatsAppShare on Telegram

Answer

Correct answer: A. I only

深度分析

統計量變換性質　認知層次：分析　建議作答 45 秒

核心公式／定理：\bar{x}_{new} = a\bar{x}_{old} + b、Range_{new} = a \times Range_{old}、Var(X+c) = Var(X)、Var(aX) = a^2 Var(X)

提示 1（啟發）
思考：若將每個數據乘以 $a$，數據間距會如何變化？若加上 $b$，數據間的距離會改變嗎？
提示 2（知識）
知識：平均值、分佈域（極差）與方差對於線性變換 $Y = aX + b$ 的反應不同。平移（+5）不影響離散程度，縮放（x6）會影響。
提示 3（破題）
破題：逐一檢查 I, II, III。I 是平均值公式；II 是極差需乘以係數；III 是方差需乘以係數平方且不受平移影響。

誘答項逆向工程

A　✓ 正確答案
B

概念錯誤　誤認平均值變換規則

學生可能認為平均值僅加 5，忽略了乘以 6 的係數影響，或者混淆了分佈域的計算方式。
C

概念錯誤　誤認方差變換規則

學生錯誤地認為方差會加上常數 5，未理解平移（+5）不影響方差，且忽略了係數平方。
D

概念錯誤　誤認分佈域變換規則

學生可能認為分佈域是平均值加常數，或者在計算方差時同時加入了錯誤的平移項。

速解策略：平均值 $\to 6m+5$ (對)；分佈域 $\to 6r$ (錯)；方差 $\to 36v$ (錯)。僅 I 正確。
