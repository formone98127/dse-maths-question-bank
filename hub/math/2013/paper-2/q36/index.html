題目

$i+2i^2+3i^3+4i^4$ 的實部為

  • A. $2$。
  • B. $-2$。
  • C. $6$。
  • D. $-6$。

深度分析

複數運算與冪次週期性　認知層次：應用　建議作答 45 秒

核心公式／定理：$i^2 = -1$、$i^3 = -i$、$i^4 = 1$、$\text{Re}(a+bi) = a$

提示 1（啟發）
回想虛數單位 $i$ 的冪次週期性：$i^1=i, i^2=-1, i^3=-i, i^4=1$，之後會重複。
提示 2（知識）
將原式展開為 $i + 2(-1) + 3(-i) + 4(1)$，並區分哪些項是實數、哪些是虛數。
提示 3（破題）
複數的實部僅包含不含 $i$ 的項，請將上述展開式中不含 $i$ 的數字相加。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　符號錯誤

計算出 2-1-3+4=2，但將 i^3 的實部誤認為 -1 而非 0，或最後一步加法算錯成 -2。
C

概念錯誤　忽略虛數部

完全忽略 i^3 的虛數性質，將 i^3 當作實數 -1 處理，導致 2-1-3+4=2 但邏輯錯誤；或誤算 i^4 為 -1。
D

計算粗心　全項符號反轉

正確算出各項實部為 2, -1, 0, 4，但最後加法錯誤或將所有項符號全部取反得到 -6。

速解策略：展開各項，利用 $i^2=-1, i^3=-i, i^4=1$，僅保留不帶 $i$ 的實數項相加即可。
