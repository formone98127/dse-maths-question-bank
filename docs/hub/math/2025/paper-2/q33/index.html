題目

已知 $\log_{5}y$ 為 $\log_{25}x$ 的線性函數。該線性函數的圖像在垂直軸上的截距及在水平軸上的截距分別為 12 及 2。若 $y=mx^{n}$，則 $n=$

  • A. $-12$
  • B. $-4$
  • C. $-3$
  • D. $-1$

深度分析

對數函數與指數關係　認知層次：應用　建議作答 90 秒

核心公式／定理：$\log_{a^b} c = \frac{1}{b}\log_a c$、$y - y_0 = m(x - x_0)$、$y = mx^n \Rightarrow \log_y = n \log_x + C$

提示 1（啟發）
提示 1：將題目中的對數式子轉換成同一底數（例如以 5 為底），觀察 $y$ 與 $\log x$ 之間的線性關係。
提示 2（知識）
提示 2：利用線性方程式的截距形式 $y = mx + c$，其中垂直截距為 $c$，水平截距需代入 $y=0$ 求解對應自變量。
提示 3（破題）
提示 3：將得到的線性關係式與 $\log y = n \log x + k$ 對照，找出指數 $n$ 的係數對應關係。

誘答項逆向工程

A

概念錯誤　混淆截距與係數關係

學生誤將垂直截距 12 當作指數 n，或錯誤認為水平截距直接影響 n 的符號而未考慮底數轉換。
B

計算粗心　底數換算錯誤

學生在處理 $\log_{25}x$ 時，未正確將底數 25 轉換為 $5^2$，導致係數計算偏差。
C　✓ 正確答案
D

審題不清　忽略截距定義

學生誤解水平軸截距為 $x=2$ 時對應的 $y$ 值非零，或混淆了 $x$ 與 $\log x$ 的變量關係。

速解策略：換底後得 $\log_5 y = \frac{1}{2}\log_5 x + c$，利用截距求 $c$ 與斜率，對照 $y=mx^n$ 取對數後的係數。
