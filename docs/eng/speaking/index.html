小組討論在考乜

說話卷四通常包括小組討論同個人回應。評核重點係溝通能力：可唔可以理解題目、提出相關意見、回應其他人、在有限時間推進討論，而唔係背一篇演講稿。實際流程同準備時間請以當年指示為準。

  • 開場：用一句複述題目範圍，再提出第一個可討論角度，邀請其他人補充。避免一開口講三分鐘。
  • 發展：每點用「意見 + 理由 + 短例子」。例子要具體，但唔好變成長篇故事。
  • 互動：同意時要加新資訊；唔同意時先概括對方意思，再講分歧同替代方案。只講 I disagree 會好弱。
  • 時間管理：如果討論停喺同一點，主動轉去題目另一部分，或者總結已有共識再往前。
  • 收束：留少少時間歸納兩至三個重點，而唔係突然停止。

有用、但唔好變成套語嘅功能句

下面只係功能方向，請用自己嘅字改寫，避免全組人講同一句。

  • 邀請：Maybe we could start with… / Would you like to add something about…
  • 澄清：If I understand you correctly… / Do you mean that…
  • 推進：Another issue the question asks us to consider is…
  • 溫和異議：I see your point, but one risk is… A possible alternative is…
  • 總結：So far we seem to agree on… We still need to decide…

個人回應

個人短答要直接回應提問，結構可用「立場或判斷 + 兩個理由 + 一句限制或例子」。唔好重覆小組討論已經講過嘅長段。如果問題要求你評估某個建議，記得兩邊都略為照顧，再先下結論。

練習方法

  • 用一個社會或校園議題，限時討論四至五分鐘，錄音之後只檢查：有冇喺聽人、有冇壟斷、有冇離題。
  • 練習轉述別人意見，訓練自己唔好只等發言空隙。
  • 語氣自然、音量清楚、眼神照顧組員，比語氣演戲更重要。
