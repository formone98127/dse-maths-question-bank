題目

設 $A(n)$ 為一等差數列的第 $n$ 項。已知 $A(5)=26$ 及 $A(12)=61$。

(a) 求 $A(1)$。

(b) 假定對任意正整數 $n$，$\log_{2}G(n)=A(n)$。求 $k$ 的最大值使得 $\log_{8}(G(1)G(2)G(3)\cdots G(k))<999$。

深度分析

數列　認知層次：應用　建議作答 300 秒

核心公式／定理：$A(n) = A(1) + (n-1)d$、$\log_a(x^y) = y\log_a x$、$\log_b x = \frac{\ln x}{\ln b}$

提示 1（啟發）
提示 1：先將所有對數轉換為相同底數（建議用底數 2）。
提示 2（知識）
提示 2：回憶等差數列通項公式 $A(n) = A(1) + (n-1)d$。
提示 3（破題）
提示 3：注意題目要求的是 G 的乘積對數，可利用對數性質轉為冪次形式。

速解策略：先求 d 與 A(1)，將 log8 換底為 2，化簡後得關於 k 的不等式 $\frac{3}{4}k^2 + \dots < 999$，解二次不等式取最大整數。
