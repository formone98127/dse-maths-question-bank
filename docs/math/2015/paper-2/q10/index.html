題目

存款 $50000$ ，年利率 $6\%$ ，年期 $3$ 年，複利計算，每季一結。求本利和準確至最接近的元。

  • A. $59000$
  • B. $59551$
  • C. $59755$
  • D. $59781$

深度分析

複利計算　認知層次：應用　建議作答 90 秒

核心公式／定理：A = P(1 + r/n)^(nt)

提示 1（啟發）
複利計算需考慮利息再投資，公式為 A = P(1 + r/n)^(nt)。
提示 2（知識）
注意題目要求每季結息，故年利率需除以 4，總期數為年數乘以 4。
提示 3（破題）
代入數值後請保留足夠小數位至最後一步再四捨五入至最接近的元。

誘答項逆向工程

A

計算粗心　單利誤用

學生可能將年利率直接乘以年數，或忽略複利效應，使用單利公式計算導致結果偏低。
B

計算粗心　結算頻率錯誤

學生可能誤以為每年結息一次，將 n 設為 1，導致計算出的本利和低於實際複利結果。
C

計算粗心　四捨五入誤差

學生在計算過程中可能過早進行四捨五入，或對指數運算精度掌握不足，導致結果偏離。
D　✓ 正確答案

速解策略：使用複利公式，注意季結頻率調整利率與期數。
