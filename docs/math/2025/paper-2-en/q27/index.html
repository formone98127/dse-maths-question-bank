Question

The coordinates of the centre of the circle $ C $ are $ (7, -5) $. If $ C $ cuts the $ x $-axis at the points $ P $ and $ Q $ such that $ PQ = 24 $, then the equation of $ C $ is

  • A. $ x^2 + y^2 - 14x + 10y - 95 = 0 $
  • B. $ x^2 + y^2 + 14x - 10y - 95 = 0 $
  • C. $ x^2 + y^2 - 14x + 10y - 119 = 0 $
  • D. $ x^2 + y^2 + 14x - 10y - 119 = 0 $
Share on WhatsAppShare on Telegram

Answer

Correct answer: A. x^2 + y^2 - 14x + 10y - 95 = 0

深度分析

圓的方程　認知層次：應用　建議作答 90 秒

核心公式／定理：(x-h)^2 + (y-k)^2 = r^2、r^2 = d^2 + (L/2)^2

提示 1（啟發）
圓心為 (h,k)，代入標準式 $(x-h)^2 + (y-k)^2 = r^2$，先確定一次項係數與常數項的初步關係。
提示 2（知識）
圓與 x 軸相交，弦 PQ 位於 y=0 直線上。利用直角三角形關係：半徑 $r$、弦長一半 $12$、及圓心到 x 軸距離 $|-5|$ 構成勾股定理。
提示 3（破題）
計算出 $r^2$ 後，將所有項移至左邊整理成一般式 $x^2+y^2+Dx+Ey+F=0$，並檢查常數項是否與選項吻合。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　符號錯誤

圓心 (7,-5) 代入一般式時，x 係數應為 -2h=-14，y 係數應為 +2k=-10。選項 B x 係數為 +14 且 y 係數為 -10，符號全錯。
C

計算粗心　常數項計算錯誤

圓心坐標導致 x,y 一次項係數正確，但半徑平方 r^2=145 時，常數項應為 -95。選項 C 常數項寫成 -119，可能是算錯 d 或 L/2。
D

概念錯誤　圓心坐標混淆

此選項同時犯了 B 的符號錯誤與 C 的常數項錯誤，代表學生未正確處理 (x-h)^2+(y-k)^2 展開時的符號規則。

速解策略：利用圓心坐標定一次項係數，用勾股定理求半徑平方，展開即得答案。
