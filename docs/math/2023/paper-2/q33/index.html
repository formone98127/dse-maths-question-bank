題目

已知$\log_8y$為$\log_4x$的線性函數。該線性函數的圖像在垂直軸上的截距及在水平軸上的截距分別為5及3。下列何者必為正確？

  • A. $x^5y^2=8^{10}$
  • B. $x^6y^5=8^{20}$
  • C. $x^{10}y^3=8^{20}$
  • D. $x^9y^{10}=8^{30}$

深度分析

對數與線性函數　認知層次：分析　建議作答 90 秒

核心公式／定理：$\log_a b = \frac{\log_c b}{\log_c a}$、$y - y_1 = m(x - x_1)$ 或 $\frac{x}{a} + \frac{y}{b} = 1$

提示 1（啟發）
提示 1：利用變換基底公式，將 $\log_8 y$ 與 $\log_4 x$ 統一為同一基底（如自然對數或常用對數），觀察它們之間的線性關係式。
提示 2（知識）
提示 2：設 $u = \log_4 x$，$v = \log_8 y$，根據截距 $(3,0)$ 與 $(0,5)$ 寫出 $v$ 與 $u$ 的直線方程式，並整理成 $v = mu + c$ 的形式。
提示 3（破題）
提示 3：將直線方程式代回原對數表達式，利用指數定義消去對數符號，比較兩邊指數與係數，即可驗證哪一選項符合條件。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　截距係數計算錯誤

學生成功建立對數關係，但在將截距 $5,3$ 轉化為直線方程式時，未正確處理變數係數，導致指數比例失衡。
C

概念錯誤　基底轉換應用不當

學生混淆了 $\log_8 y$ 與 $\log_4 x$ 的係數關係，錯誤地假設兩者基底差異直接對應指數倍數，忽略變換後的斜率計算。
D

審題不清　截距意義解讀偏差

學生誤將垂直軸截距 $5$ 視為 $y$ 的係數，水平軸截距 $3$ 視為 $x$ 的係數，而未考慮對數函數轉換後的斜率影響。

速解策略：統一基底得 $\log_8 y = \frac{1}{2}\log_4 x + c$，代入截距求斜率與常數項，再轉回指數形式比對選項。
