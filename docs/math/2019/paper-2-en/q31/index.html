Question

It is given that $\log_{9}y$ is a linear function of $\log_{3}x$. The intercepts on the vertical axis and on the horizontal axis of the graph of the linear function are 7 and 8 respectively. Which of the following must be true?

  • A. $x^{4}y^{7}=3^{56}$
  • B. $x^{7}y^{4}=3^{56}$
  • C. $x^{7}y^{8}=3^{56}$
  • D. $x^{8}y^{7}=3^{56}$

Answer

Correct answer: B. x^{7}y^{4}=3^{56}

深度分析

對數法則與線性函數　認知層次：分析　建議作答 90 秒

核心公式／定理：$\log_{a^n} b = \frac{1}{n}\log_a b$、$y - y_0 = m(x - x_0)$、$\log_b a^k = k \log_b a$

提示 1（啟發）
提示 1：觀察題目，令 $u = \log_3 x$ 且 $v = \log_9 y$，將對數關係轉化為兩個新變數 $u, v$ 之間的線性方程式。
提示 2（知識）
提示 2：利用底數換算公式 $\log_{9} y = \frac{1}{2}\log_{3} y$，建立 $v$ 與 $\log_3 y$ 的關係，並結合直線截距式 $\frac{X}{a} + \frac{Y}{b} = 1$。
提示 3（破題）
提示 3：將 $u, v$ 代回原變數 $x, y$，注意指數係數的變化，最後整理成選項中的形式即可驗證。

誘答項逆向工程

A

概念錯誤　混淆 x 與 y 的係數關係

學生可能錯誤地將截距 8 對應到 y 的指數，7 對應到 x 的指數，未考慮變數替換後的斜率影響。
B　✓ 正確答案
C

計算粗心　斜率計算錯誤導致指數比例不對

學生在設定直線方程式時，可能算錯斜率 m，導致 x 與 y 的係數比例 (7:4) 變成 (7:8)。
D

策略錯誤　未進行變數底數轉換

學生直接將題目中的 log 視為普通線性關係，忽略底數 9 與 3 的換算，導致係數完全錯誤。

速解策略：令 $u=\log_3 x, v=\log_9 y$，設直線為 $v=m(u-u_0)$，代入截距求斜率與係數關係。
