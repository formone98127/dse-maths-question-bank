溫習要點同常見題型

基本經濟概念考稀少性、機會成本、生產可能性曲線（PPC）、基本經濟問題，同唔同經濟制度。選擇題常見陷阱係把會計成本當成機會成本，忽略隱含成本。

PPC 題要分清沿曲線移動同整條曲線向外或向內移，前者係選擇，後者先至係生產力或資源改變。
