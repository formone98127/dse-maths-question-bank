題目

下面的幹葉圖顯示某袋子內的信件的重量（以克為單位）的分佈。

幹（十位） 葉（個位）

5 0 w

已知上述分佈的分佈域為其四分位數間距的三倍。

(a) 求 $w$。

(b) 若從該袋子中隨機抽取一信件，求所抽取的信件的重量不少於該分佈的眾數的概率。

深度分析

積分法　認知層次：應用　建議作答 300 秒

核心公式／定理：$\int_a^b f(x) dx = F(b) - F(a)$、$\text{Trapezoidal Rule: } \frac{h}{2}[y_0 + 2y_1 + ... + 2y_{n-1} + y_n]$

提示 1（啟發）
Recall that the Trapezoidal Rule over-estimates when the curve is concave down ($f'' < 0$) and under-estimates when concave up ($f'' > 0$).
提示 2（知識）
For $B(t)$, try substitution $u = 3^{2t}$ to simplify the integral.
提示 3（破題）
Remember to calculate the percentage based on the total number of adults as the denominator.

速解策略：先算梯形法數值，再求二階導數定誤差方向；對 $B(t)$ 代換後積分，最後比較百分比。
