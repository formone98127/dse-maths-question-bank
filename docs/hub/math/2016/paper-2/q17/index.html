題目

圖中，$ABCD$ 為一平行四邊形。$E$ 為 $CD$ 上的一點使得 $BE = CE$。若 $\angle ADC = 114^\circ$，則 $\angle ABE =$

  • A. $48^\circ$
  • B. $57^\circ$
  • C. $62^\circ$
  • D. $66^\circ$

深度分析

平行四邊形性質與等腰三角形　認知層次：應用　建議作答 45 秒

核心公式／定理：\angle A = \angle C (平行四邊形對角相等)、\angle ADC + \angle DAB = 180^\circ (同側內角互補)、等腰三角形底角相等

提示 1（啟發）
平行四邊形中，相鄰兩角互補，即 \angle ADC + \angle DAB = 180^\circ。
提示 2（知識）
平行四邊形的對角相等，因此 \angle C = \angle A = \angle DAB。
提示 3（破題）
在 \triangle BCE 中，利用等腰三角形性質求出 \angle CBE，再結合 \angle ABC = \angle ADC 即可求得 \angle ABE。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　角度計算錯誤

算出 \angle C = 66^\circ 後，誤將等腰三角形底角算成 (180-66)/2=57^\circ，忘記 \angle ABE 是頂角的一部分而非整個頂角。
C

概念錯誤　混淆平行四邊形對角

誤以為 \angle C = \angle ADC = 114^\circ，導致後續計算完全錯誤。
D

審題不清　讀圖錯誤

誤以為 \angle ABE 是等腰三角形 \triangle BCE 的頂角，直接計算 (180-66)/2=57^\circ 後又加錯或選錯。

速解策略：先求 \angle C=66^\circ，再利用等腰三角形求 \angle CBE=57^\circ，最後由 \angle ABC=114^\circ 減去 \angle CBE 得 \angle ABE=57^\circ。
