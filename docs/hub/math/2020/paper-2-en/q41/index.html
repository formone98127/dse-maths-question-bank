Question

Find the range of values of $c$ such that the circle $x^2 + y^2 - 6x + cy - 7 = 0$ and the straight line $x - y + 9 = 0$ intersect.

  • A. $-56 \leq c \leq 8$
  • B. $-8 \leq c \leq 56$
  • C. $c \leq -56$ or $c \geq 8$
  • D. $c \leq -8$ or $c \geq 56$
Share on WhatsAppShare on Telegram

Answer

Correct answer: D. c \leq -8 or c \geq 56

深度分析

圓與直線的相交條件　認知層次：分析　建議作答 120 秒

核心公式／定理：$ (x-h)^2 + (y-k)^2 = r^2 $、$ d = \frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}} $

提示 1（啟發）
將圓的一般式配方，找出圓心 $(h,k)$ 與半徑 $r$ 的表達式。
提示 2（知識）
回憶點到直線距離公式，並理解相交條件為「圓心到直線距離不大於半徑」。
提示 3（破題）
建立關於 $c$ 的不等式 $d \le r$，解出 $c$ 的範圍即可。

誘答項逆向工程

A

計算粗心　圓心坐標計算錯誤

將 $-6x$ 配對時，誤認為圓心橫座標是 $+3$ 或符號搞反，導致圓心 $(3, -c/2)$ 算錯，進而距離公式代入出錯。
B

計算粗心　半徑平方計算錯誤

圓心坐標正確但半徑 $r$ 算成 $\sqrt{7}$，未將常數項移到右邊配對，導致 $d \le r$ 時不等式邊界數值完全錯誤。
C

概念錯誤　相交條件邏輯混淆

正確算出圓心與半徑，但誤以為「相交」代表圓在直線兩側（距離大於半徑），搞反了 $d \le r$ 的含義。
D　✓ 正確答案

速解策略：配方得圓心 $(3, -c/2)$、半徑 $\sqrt{16+c^2/4}$；代入距離公式並解不等式。
