題目

According to the figure, which of the following must be true?

  • A. $p+q-r=90^\circ$
  • B. $p-r+s=180^\circ$
  • C. $p+q-r+s=270^\circ$
  • D. $p+q+r-s=540^\circ$

深度分析

多邊形內角和與外角性質　認知層次：分析　建議作答 90 秒

核心公式／定理：n 邊形內角和 = (n-2) \times 180^\circ、\triangle ABC: \angle A + \angle B + \angle C = 180^\circ

提示 1（啟發）
觀察圖形，找出包含 p, q, r, s 的四邊形或相關三角形。
提示 2（知識）
回憶 n 邊形內角和公式：(n-2)\times 180^\circ，並確認圖中多邊形的邊數。
提示 3（破題）
將所有內角用已知角度 p,q,r,s 表示，注意外角與內角的互補關係。

誘答項逆向工程

A

概念錯誤　忽略多邊形內角和

學生可能只考慮三角形局部關係，誤以為 p,q,r 直接相加或相減即可得到常數，忽略了四邊形頂點 s 的貢獻及外角定義。
B

概念錯誤　錯誤組合角度

學生試圖建立線性關係但選錯了符號與係數，可能混淆了內角與外角的轉換公式，導致 s 的係數或符號錯誤。
C

計算粗心　計算結果偏差

學生正確列出四邊形內角和公式 (360^\circ) 或三角形關係，但在代入 p,q,r,s 時算術出錯，導致常數項變成 270^\circ。
D　✓ 正確答案

速解策略：利用四邊形內角和為360度及對頂角性質，建立等式消去未知量。
