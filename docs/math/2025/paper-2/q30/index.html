題目

考慮以下數據： α β -4 -3

1   1   1   4

將以上數據的眾數及中位數分別記為 s 及 t。若以上數據的平均值及分佈域分別為 0 及 10，則下列何者正確？ I. s = 1 II. t = -1 III. α + β = 0

  • A. 只有 I 及 II
  • B. 只有 I 及 III
  • C. 只有 II 及 III
  • D. I、II 及 III 乙部

深度分析

統計量 (眾數，中位數，平均值，分佈域)　認知層次：分析　建議作答 90 秒

核心公式／定理：\bar{x} = \frac{\sum x}{n}、\text{Range} = \max(x) - \min(x)

提示 1（啟發）
先將數據按大小排序，並確認總共有多少個數據點 (n)。
提示 2（知識）
利用分佈域公式找出最大值與最小值的關係，結合平均值公式建立 \alpha+\beta 的方程。
提示 3（破題）
根據 n 的大小確定中位數的位置，並代入已知條件驗證各陳述式是否成立。

誘答項逆向工程

A

概念錯誤　誤判中位數位置

學生可能將排序後第 2 個數據 (-3) 當作中位數，或錯誤認為 s=1 時 t=-1 成立而忽略 III。
B　✓ 正確答案
C

概念錯誤　誤判眾數與中位數

學生可能計算出 s=1 但錯誤推導 t，或忽略平均值條件導致無法驗證 III。
D

計算粗心　誤算分佈域關係

學生可能正確算出 s 與 t，但錯誤計算 \alpha+\beta=0 或誤以為 III 不成立。

速解策略：排序數據找眾數 s；利用 Range=10 定極值；用 Avg=0 求 \alpha+\beta；再找中位數 t。
