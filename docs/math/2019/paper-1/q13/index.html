題目

圖 1 中，$O$ 為圓 $ABCDE$ 的圓心。$AC$ 為該圓的一直徑。$BD$ 與 $OC$ 相交於點 $F$。已知 $\angle AED = 115^\circ$。

(a) 求 $\angle CBF$。

(b) 假定 $BC \parallel OD$ 及 $OB = 18\, \text{cm}$。扇形 $OBC$ 的周界是否少於 $60\, \text{cm}$？試解釋你的答案。

深度分析

圓的性質　認知層次：應用　建議作答 180 秒

核心公式／定理：$\text{圓周長} = 2\pi r$、$\text{扇形弧長} = \frac{\theta}{360} \times 2\pi r$、$\text{扇形周界} = \text{弧長} + 2r$

提示 1（啟發）
Hint1: $AC$ 是直徑，所以 $\angle ABC = 90^\circ$。
提示 2（知識）
Hint2: $\angle AED$ 與 $\angle ABC$ 是同弧所對的圓周角嗎？不，它們關係需透過互補角或同弧分析。
提示 3（破題）
Hint3: 扇形周界 = 弧長 + 2 條半徑，不要只算弧長！

速解策略：先求 $\angle ABC=90^\circ$，再得 $\angle BOC$。利用平行線得 $\angle CBF$。最後計算 $L = \text{弧} + 2r$ 並比較。
