版權同使用說明：呢啲筆記用自己嘅措辭整理公開課程常見概念同應試方法，方便溫習。正式考試請同時核對考評局當年評核大綱，以及試卷提供嘅公式或資料。本站唔會轉載官方試題、評卷參考、考試報告、課程指引原文，亦唔會刊登指定文言篇章全文。需要原文或官方樣本時，請行下面官方連結。

公式表聲明：呢份係原創溫習清單，用自己嘅措辭整理常見關係同應試注意。正式考試請同時核對試卷或考評局提供嘅官方公式表，符號同適用條件以當年卷面為準。記得：有公式都要寫出代入過程，唔好只抄最後答案。

代數

  • 數學歸納法：先寫要證命題 P(n) 同起始值；再假設 P(k)，推出 P(k+1)；最後用一句話收束「由起始值同歸納步驟，對所有指定正整數成立」。假設要用得明顯，唔好跳步。
  • 矩陣：加法同標量乘法按元素進行；乘法要檢查前一個嘅列數等如後一個嘅行數。乘法無交換律，唔好隨便調位。單位矩陣扮演 1 嘅角色；逆矩陣存在先可以解某類方程組。
  • 行列式（二階或課程範圍內嘅階數）：可用嚟判斷可逆同計算面積或體積相關量，但要跟課程允許嘅方法。
  • 向量：用分量加減、標量乘法同位置向量去描述點同線。點積可以判斷垂直同求夾角；要分清向量平行同垂直嘅條件。三維範圍以大綱為準。

微積分

  • 標準導數：多項式、指數、對數、三角同反三角（若在範圍內）要熟，並且會用鏈法則。
  • 積分：除基本形式外，常見技巧包括代換、分部積分同三角恆等變形。定積分仍然要寫上下限轉換。
  • 應用：切線法線、率變、最值、面積、弧長或體積等，以課程列明者為準。先寫關係式，再先運算。

應試提醒

代數題要有推論句；微積分題要有函數同定義域意識。更完整說明見單元二筆記。
