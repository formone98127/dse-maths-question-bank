題目

圖中，$\frac{AD}{AB}=$

  • A. $\cos\alpha\tan\beta$
  • B. $\sin\alpha\tan\beta$
  • C. $\frac{\cos\alpha}{\tan\beta}$
  • D. $\frac{\sin\alpha}{\tan\beta}$

深度分析

三角函數與相似三角形　認知層次：分析　建議作答 45 秒

核心公式／定理：\cos\alpha = \frac{AC}{AB}、\tan\beta = \frac{BC}{AC}

提示 1（啟發）
觀察圖形，找出包含角 \alpha 和角 \beta 的兩個直角三角形。
提示 2（知識）
分別用 \cos\alpha 與 \tan\beta 表示出線段 AC 與 BC 的關係。
提示 3（破題）
將所得關係式相乘並化簡，看看能否得到 \frac{AD}{AB}（註：圖中 D 點應為 C 點或題目意指 AC/AB，依標準解法推導）

誘答項逆向工程

A　✓ 正確答案
B

概念錯誤　混淆餘弦與正切定義

學生誤以為 \cos\alpha 應為斜邊 \frac{AB}{AC}，導致分子分母顛倒或選錯三角函數組合。
C

計算粗心　代數變換錯誤

學生在將 \cos\alpha 與 \tan\beta 相乘時，錯誤地將分母 \cos\alpha 保留或處理成除法關係。
D

概念錯誤　選錯正弦函數

學生混淆了 \cos\alpha 與 \sin\alpha 的定義，錯誤地使用對邊 \frac{BC}{AB} 來代表 \cos\alpha。

速解策略：利用 \cos\alpha = \frac{AC}{AB} 與 \tan\beta = \frac{BC}{AC}，相乘後消去 AC 即可。
