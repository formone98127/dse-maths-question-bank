題目

定義 $g(x) = x^3 + 5x^2 - 12x - 1$。設 $h(x) = 3x^4 + ax^3 - 16x^2 + bx + c$，其中 $a$、$b$ 及 $c$ 均為常數。當 $h(x)$ 除以 $g(x)$ 時，商式與餘式相等。

(a) 求當 $h(x)$ 除以 $g(x)$ 時的商式。 (3 分)

(b) 方程 $h(x) = 0$ 有多少個有理根？試解釋你的答案。 (4 分)

深度分析

多項式除法與餘式定理　認知層次：分析　建議作答 180 秒

核心公式／定理：$h(x) = g(x) \cdot q(x) + r(x)$、$\text{商式} = \frac{h(x)-r(x)}{g(x)}$

提示 1（啟發）
提示 1：若 $h(x)$ 除以 $g(x)$ 餘式等於商式，且 $\deg(h)=4, \deg(g)=3$，則商式必為一次多項式。
提示 2（知識）
提示 2：有理根定理指出若有理數 $p/q$ 為根，則 $p$ 整除常數項，$q$ 整除最高次項係數。
提示 3（破題）
提示 3：將求得的商式代回除法公式，可幫助理解 $a,b,c$ 的約束條件（雖此題 (b) 部分可能不需具體求出 a,b,c）。

速解策略：先設商式為 $Ax+B$，比較 $x^4$ 與 $x^3$ 係數定 $A,B$；再用有理根定理列候選並代入驗證。
