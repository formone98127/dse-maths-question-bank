題目

求 $k$ 值的範圍使得圓 $x^2+y^2+2x-4y-13=0$ 與直線 $x-y+k=0$ 相交於兩相異點。

  • A. $-9<k<3$
  • B. $-3<k<9$
  • C. $k<-9$ 或 $k>3$
  • D. $k<-3$ 或 $k>9$

深度分析

圓與直線的相交條件　認知層次：分析　建議作答 180 秒

核心公式／定理：圓心 $(h,k)$ 與半徑 $r$：$(x-h)^2+(y-k)^2=r^2$、點 $(x_0,y_0)$ 到直線 $Ax+By+C=0$ 距離：$d = \frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}$

提示 1（啟發）
Hint 1 啟發：將圓的方程式配方成標準式，找出圓心坐標與半徑長度。
提示 2（知識）
Hint 2 知識：利用「圓心到直線的距離小於半徑」作為相交條件，寫出 $d < r$ 的不等式，並注意分母為 $\sqrt{1^2+(-1)^2}$。
提示 3（破題）
Hint 3 破題：解絕對值不等式 $|k-3| < \text{某數值}$ 時，記得拆成兩個同向不等式（小於號），而非大於號或並集。

誘答項逆向工程

A

計算粗心　符號取反錯誤

在計算圓心 $(-1,2)$ 到直線距離時，分子絕對值內算出 $|-3+k|$，但在後續不等式處理或代入數值時，將 $k-3$ 的係數弄錯，導致上下界互換（將 $-3$ 與 $9$ 的位置顛倒），最終得出 $-9<k<3$
B　✓ 正確答案
C

概念錯誤　不等號方向混淆

正確算出距離範圍後，誤以為「相交」對應的是距離大於半徑（這通常是相離的條件），或者在解 $|k-3| < 10$ 時，錯誤地將不等式展開為 $k-3 > 10$ 或 $k-3 < -10$ 的並集，導致得到「或」的區間且數值大小顛倒
D

計算粗心　半徑計算錯誤

在將圓的一般式 $x^2+y^2+2x-4y-13=0$ 配方時，常數項處理出錯。正確應為 $(-1)^2+(2)^2-r^2=-13 \Rightarrow r^2=18$，但學生可能算成 $r^2=9$（即 $r=3$）。若用錯誤的半徑 $3$ 代入距離公式 $\frac{|k-3|}{\sqrt{2}} < 3$，解得 $|k-3|<6 \Rightarrow -3<k<9$

速解策略：配方得圓心$(-1,2)$半徑$\sqrt{18}$，距離公式化簡得$|k-3|<6$，解得$-3<k<9$
