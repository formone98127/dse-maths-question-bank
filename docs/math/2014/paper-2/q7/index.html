題目

$-3x<6<2x$ 的解為

  • A. $x>-2$。
  • B. $x>0$。
  • C. $x>3$。
  • D. $-2<x<3$。

深度分析

不等式解法　認知層次：應用　建議作答 45 秒

核心公式／定理：若 a < b < c，則需滿足 a < x 且 x < c

提示 1（啟發）
複合不等式 $A < Bx < C$ 需同時滿足左邊與右邊兩個條件。
提示 2（知識）
解不等式時，若兩邊除以負數，不等號方向必須改變。
提示 3（破題）
將題目拆成 $-3x < 6$ 與 $6 < 2x$ 分別求解後取交集。

誘答項逆向工程

A

審題不清　忽略右邊不等式

只解 -3x < 6 得 x > -2，完全忘記處理 6 < 2x 這部分條件。
B

計算粗心　除數處理錯誤

解右邊得 x > 3，但左邊算成 -3x/6=x>0.5 或混淆數字，選出中間值。
C　✓ 正確答案
D

策略錯誤　未合併解集

正確算出 x > -2 與 x > 3，但誤以為要取交集卻寫成並集或邏輯混亂。

速解策略：分拆為兩個不等式：解 -3x<6 得 x>-2；解 6<2x 得 x>3，取交集得 x>3。
