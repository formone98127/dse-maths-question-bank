題目

設 $k$ 為一常數。若 $f(x)=2x^2-5x+k$，則 $f(2)-f(-2)=$

  • A. $-20$。
  • B. $0$。
  • C. $16$。
  • D. $2k$。

深度分析

一元二次函數的代數運算　認知層次：應用　建議作答 45 秒

核心公式／定理：$f(a) - f(b)$ 的直接代入計算、$x^2$ 項為偶函數部分，$-5x$ 項為奇函數部分

提示 1（啟發）
提示 1：請先分別寫出 $f(2)$ 和 $f(-2)$ 的表達式，注意代入 $-2$ 時 $x^2$ 與 $x$ 的變化。
提示 2（知識）
提示 2：觀察函數結構，將 $f(x)$ 拆分為 $2x^2$（偶部）與 $-5x+k$（奇部 + 常數），思考相減時哪些項會保留。
提示 3（破題）
提示 3：執行具體數字代入，計算 $(8-10+k) - (8+10+k)$，化簡後即可得到答案。

誘答項逆向工程

A　✓ 正確答案
B

概念錯誤　誤認偶函數差值為零

學生認為 $f(x)$ 是二次函數，故 $f(2)-f(-2)$ 應像奇函數那樣抵消為 0，忽略了 $x^2$ 項在相減時會變成 $4a - 4a = 0$ 但常數與一次項未完全抵消的誤判，或是混淆了 $f(x)-f(-x)=0$ 的條件。正確應為 $(2(4)-10+k)-(2(4)+10+k) = 8-10+8+10 = -20$。
C

計算粗心　符號處理錯誤

計算 $f(2)$ 時得 $8-10+k=-2+k$，計算 $f(-2)$ 時得 $8+10+k=18+k$。相減時應為 $(-2+k)-(18+k)=-20$。學生可能算成 $(8-10)-(8+10)= -2-18 = -20$ 但誤記符號，或將 $-5(-2)$ 算錯導致結果偏差至 16。
D

概念錯誤　誤解常數項影響

學生認為 $f(2)-f(-2)$ 的結果會包含 $k$，忘記了相減時 $+k$ 與 $-k$ 會互相抵消。這是對線性組合中常數項性質的誤解。

速解策略：直接代入 $x=2$ 與 $x=-2$，展開後消去 $k$ 並合併同類項。
