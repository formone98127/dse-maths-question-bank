Question

深度分析

畢氏定理與直角三角形　認知層次：應用　建議作答 45 秒

核心公式／定理：$c = \sqrt{a^2 + b^2}$ (畢氏定理)、距離公式 $d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$

提示 1（啟發）
觀察圖形，找出連接 $A$ 與 $H$ 的線段構成了哪一個直角三角形的斜邊？
提示 2（知識）
量出或數出該直角三角形兩條直角邊的長度各是多少單位？
提示 3（破題）
將兩直角邊的長度平方後相加，再開根號即可求得答案。

誘答項逆向工程

A

計算粗心　平方計算錯誤

學生可能將 $3^2=9$ 與 $4^2=16$ 加總後，誤算 $\sqrt{25}$ 為 $6$ (混淆了 $6^2=36$)，或是單純口算錯誤。
B

概念錯誤　誤用勾股數

學生可能看到直角邊為 3 和 4，直接回憶常見勾股數 $(6,8,10)$ 或 $(3,4,5)$ 的倍數關係，但錯誤地將斜邊長度猜測為 $8$ (可能是 $3-4-5$ 三角形的 $2$ 倍誤植)。
C

審題不清　讀圖誤解

學生可能將圖形中的單位長度看錯，例如認為水平距離是 $2$ 格而非 $3$ 格，或是垂直距離為 $5$ 而非 $4$，導致計算出錯誤的斜邊長。
D　✓ 正確答案

速解策略：識別直角三角形直角邊為 $3$ 與 $4$，運用畢氏定理計算斜邊。
