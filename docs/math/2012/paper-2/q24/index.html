喺題庫開啟呢題 · 返回 2012 卷二 全卷

題目

若 $P$ 為直角坐標平面上的一動點使得 $P$ 與點 $(20,12)$ 之間的距離等於 5，則 $P$ 的軌跡為一

  • A. 圓。
  • B. 正方形。
  • C. 拋物線。
  • D. 三角形。

深度分析

平面幾何與距離公式　認知層次：理解　建議作答 45 秒

核心公式／定理：兩點間距離公式：$d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$、圓的標準方程式：$(x-h)^2 + (y-k)^2 = r^2$

提示 1（啟發）
Hint 1 啟發：回想一下，在平面上所有與某個固定點距離相等的點，會形成什麼樣的圖形？
提示 2（知識）
Hint 2 知識：設圓心為 $(h,k)$，半徑為 $r$，則圓上任意一點 $(x,y)$ 滿足的方程式為 $(x-h)^2 + (y-k)^2 = r^2$。本題中固定點即為圓心，定長即為半徑。
提示 3（破題）
Hint 3 破題：將題目給定的坐標 $(20,12)$ 視為圓心，距離 $5$ 視為半徑，代入上述方程式觀察其圖形特徵，即可排除其他選項。

誘答項逆向工程

A　✓ 正確答案
B

概念錯誤　誤將軌跡視為固定圖形

學生可能混淆了「滿足條件的點集」與「由這些點組成的封閉多邊形」，錯誤地認為所有滿足條件的點會連成正方形，或是將焦點與準線的概念錯置應用於此情境。
C

概念錯誤　混淆拋物線定義

學生可能將「到一點距離等於定長」誤記為「到一點與一直線距離相等」的拋物線定義，或是因為看到軌跡問題就直覺聯想到二次曲線中的拋物線。
D

概念錯誤　誤解點集形狀

學生可能認為滿足條件的點只有有限個（例如只考慮整數座標），進而將這些離散點錯誤地連結成三角形，或是完全無法想像連續軌跡的概念。

速解策略：到定點距離為定長的點的軌跡定義即為圓。
