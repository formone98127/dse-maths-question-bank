題目

圖中，$ABCD$ 為一長方形。若 $E$ 為 $AC$ 上的一點使得 $AE=30\text{ cm}$，則 $DE=$

  • A. $3\sqrt{65}\text{ cm}$
  • B. $5\sqrt{29}\text{ cm}$
  • C. $\sqrt{641}\text{ cm}$
  • D. $\sqrt{697}\text{ cm}$
WhatsApp 分享Telegram 分享

深度分析

幾何：長方形與直角三角形　認知層次：應用　建議作答 90 秒

核心公式／定理：$a^2 + b^2 = c^2$、$\frac{Area}{Base} = Height$

提示 1（啟發）
提示 1：觀察長方形 $ABCD$ 與對角線 $AC$，確認 $E$ 點位於哪條直線上。
提示 2（知識）
提示 2：利用直角三角形面積公式 $Area = \frac{1}{2} \times Base \times Height$，思考如何將 $DE$ 視為高來建立關係式。
提示 3（破題）
提示 3：先計算對角線 $AC$ 的全長，再根據 $AE=30$ 求出 $EC$，最後在 $\triangle DEC$ 中應用畢氏定理求解 $DE$

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　坐標設定錯誤導致距離計算偏差

學生可能將 $E$ 點誤設為 $(30,0)$ 而非在斜邊上，或計算 $AC$ 長度時出錯，導致最終結果變成 $5\sqrt{29}$。
C

概念錯誤　誤解直角三角形面積公式應用

學生嘗試用勾股定理但忽略了 $E$ 點在斜邊上的限制，直接假設 $DE$ 為高或誤算斜邊投影關係。
D

審題不清　單位或數值讀取錯誤

學生可能看錯圖中 $AB$ 或 $BC$ 的長度，將 $30\text{ cm}$ 誤讀為其他數值，導致計算結果偏離正確答案。

速解策略：利用面積法求高 $DE$：先算 $AC$ 長，得 $EC$，再用勾股定理於 $\triangle DEC$。
