常見問題

DSE Hub 係咪免費？

係，免費查閱香港中學文憑試歷屆試題索引同題目，唔使報名，亦唔使信用卡。

而家有邊啲科目？

而家有數學（必修部分）、經濟、化學、生物同物理。每科已上線嘅年份同卷別，以資料庫實際內容為準，科目頁會列出全部已有卷。

可唔可以按課題溫習？

可以。喺上面揀「按課題」，先揀科目再揀課題，就會列出相關題目，方便集中操同一類型。

呢度係咪官方原卷檔案庫？

站內主要提供索引、題目同課題標籤，方便溫習；部分卷另有 PDF 連結。內容以資料庫已有項目為準，並唔取代考試及評核局官方刊物。

站內只放索引、連結同課題標籤，唔存放試卷原卷 · 只顯示資料庫已有內容
