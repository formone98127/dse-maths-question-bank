題目

$3m^2 - 5mn + 2n^2 + m - n =$

  • A. $(m - n)(3m - 2n + 1)$
  • B. $(m - n)(3m + 2n + 1)$
  • C. $(m + n)(3m - 2n - 1)$
  • D. $(m + n)(3m + 2n - 1)$

深度分析

因式分解　認知層次：分析　建議作答 60 秒

核心公式／定理：(a+b)(c+d+e) = ac + ad + ae + bc + bd + be

提示 1（啟發）
先專注於二次項 $3m^2 - 5mn + 2n^2$，嘗試用十字相乘法將其分解為兩個一次因式的乘積。
提示 2（知識）
觀察原式中的線性項 $+m-n$，思考如何將它們分配到已分解出的兩個括號中，使得展開後符號吻合。
提示 3（破題）
選定一個選項進行快速展開驗證：計算 $(m-n)(3m-2n+1)$ 是否等於原式左邊。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　符號錯誤

分解二次項得 $(m-n)(3m-2n)$，但展開時將 $-2n \times m$ 誤算為 $+2mn$
C

概念錯誤　一次項符號混淆

正確分解出 $(m-n)$ 與 $(3m-2n)$，但在處理 $+m-n$ 時，誤將 $-n$ 對應到括號內變成 $-1$
D

概念錯誤　一次項符號混淆

正確分解出 $(m-n)$ 與 $(3m-2n)$，但在處理 $+m-n$ 時，誤將 $-n$ 對應到括號內變成 $-1$

速解策略：先分解二次項得 $(m-n)(3m-2n)$，再調整一次項分配，最後展開 A 選項驗證符號全對。
