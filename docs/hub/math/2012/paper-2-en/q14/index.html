Question

The length of a piece of thin string is measured as $ 25 \text{ m} $ correct to the nearest $ \text{m} $. If the string is cut into $ n $ pieces such that the length of each piece is measured as $ 5 \text{ cm} $ correct to the nearest $ \text{cm} $, find the greatest possible value of $ n $.

  • A. 445
  • B. 566
  • C. 567
  • D. 650
Share on WhatsAppShare on Telegram

Answer

Correct answer: B. 566

深度分析

誤差分析與極值問題　認知層次：分析　建議作答 90 秒

核心公式／定理：若長度 $ L $ 測得為 $ x $ 正確至單位 $ u $，則實際長度範圍為 $ (x - 0.5u) \leq L < (x + 0.5u) $

提示 1（啟發）
Hint 1 啟發: 要得到最大數量 $ n $，我們需要原繩子的長度取什麼極限值？同時每一小段的長度又應該取什麼極限值？
提示 2（知識）
Hint 2 知識: 根據誤差定義，若測得 $25$ m（正確至 $1$ m），實際長度範圍是 $[24.5, 25.5)$；若測得 $5$ cm（正確至 $1$ cm），實際長度範圍是 $[4.9, 5.1)$。請將單位統一為公分 (cm)。
提示 3（破題）
Hint 3 破題: 將原繩子的最大可能長度除以每一小段的最小可能長度，計算結果後需確認是否滿足「正確至」的條件（即總和落在允許範圍內），但此處主要關注極值邊界。

誘答項逆向工程

A

概念錯誤　忽略上限長度

學生正確計算出原繩子最小長度為 $24.5$ m，但錯誤地將最大長度仍視為 $25$ m（或 $25.5$ m 但未考慮極端情況），導致使用較小的分母計算出較小的 $ n $ 值。
B　✓ 正確答案
C

計算粗心　單位換算錯誤

學生正確識別出要最大化 $ n $ 需用原繩子最大長度除以單段最小長度，但在計算時將 $25.5$ m 誤算為 $2550$ cm（正確），卻將 $4.9$ cm 誤算成其他數值（如 $5$ cm 或 $4.8$ cm 的近似），或者在除法 $2550 \div 4.9$ 時計算錯誤得出 $567$。
D

策略錯誤　未考慮誤差範圍

學生完全忽略「正確至」的含義，直接使用標稱值 $25$ m 和 $5$ cm 進行計算，即 $2500 \div 5 = 500$，然後可能隨意調整或誤讀題目導致選出 $650$（例如將 $25.5$ m 當作 $255$ dm 再除以錯誤的單位數），或是單純猜測大數字。

速解策略：取原長最大值 $25.5$ m ($2550$ cm) 除以單段最小值 $4.9$ cm，計算 $2550 \div 4.9 \approx 520.4$。注意：此處需重新校對邏輯。正確邏輯是：原長範圍 $[24.5, 25.5]$，單段範圍 $[4.9, 5.1]$。要 $n$ 最大，分子取大 ($2550$)，分母取小 ($4.9$)。$2550/4.9 = 520.4$。等等，題目答案給的是 B (566)。讓我重新檢查誤差定義。
