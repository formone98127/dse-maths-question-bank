題目

圖中所示為 $y=-2x^2+ax+b$ 的圖像，其中 $a$ 及 $b$ 均為常數。該圖像的對稱軸的方程為

  • A. $x=2$。
  • B. $x=3$。
  • C. $x=5$。
  • D. $y=8$。

深度分析

一元二次函數圖形與對稱軸　認知層次：分析　建議作答 45 秒

核心公式／定理：x = -b / (2a)、對稱軸定義：通過頂點的垂直直線

提示 1（啟發）
觀察圖像中拋物線的開口方向與頂點的大致位置（最高點）。
提示 2（知識）
回憶一元二次函數 y=ax^2+bx+c 的對稱軸公式為何，注意係數 a 與 b 的位置。
提示 3（破題）
利用圖形上兩個明顯的 x 軸截距（根），計算它們的中點來驗證對稱軸的位置。

誘答項逆向工程

A

審題不清　讀圖誤判頂點位置

學生將圖像與 x 軸的右側交點（約 x=4）誤認為是頂點，或將左側交點（x=0）與另一交點的平均值算錯，導致選出 x=2。
B　✓ 正確答案
C

計算粗心　頂點公式符號錯誤

學生使用公式 x = b / (2a) 而忘記負號，或計算時將分母中的係數搞混，導致結果偏大至 x=5。
D

概念錯誤　混淆對稱軸與頂點座標

學生誤以為對稱軸是水平直線，寫成 y=... 的形式，顯示未理解拋物線對稱軸為垂直於 x 軸的直線。

速解策略：從圖像讀取頂點橫坐標或兩根中點，代入公式 x = -b/(2a) 即可。
