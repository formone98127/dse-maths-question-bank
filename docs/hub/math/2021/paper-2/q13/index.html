題目

圖中，第 1 個圖案包含 3 粒點子。對任意正整數 $ n $，第 $ (n+1) $ 個圖案是由第 $ n $ 個圖案加上 $ (2n+3) $ 粒點子所組成。求第 8 個圖案的點子數目。

  • A. 63
  • B. 75
  • C. 80
  • D. 99

深度分析

數列遞迴, 等差級數　認知層次：分析　建議作答 90 秒

核心公式／定理：a_{n+1} = a_n + (2n+3)、S_n = \sum_{k=1}^{n-1} (2k+3) + a_1

提示 1（啟發）
根據題目描述，列出前兩個圖案的點子數目，觀察數列規律。
提示 2（知識）
將遞迴關係式寫成 a_{n+1} - a_n = 2n + 3，思考如何從首項推到第 8 項。
提示 3（破題）
利用累加法，計算 \sum_{k=1}^{7} (2k+3) 並加上首項 3，即可得出答案。

誘答項逆向工程

A

計算粗心　首項計算錯誤

學生可能將 n=1 時的增量 (2*1+3)=5 當作總數，或誤算 a_2=3+5=8, a_3=8+7=15... 累加時漏掉首項 3 或計算錯誤導致結果偏小。
B

策略錯誤　遞迴步數遺漏

學生正確列出公式但未算到第 8 項，可能只算到 a_7 就停止，或誤以為題目問的是增量而非總和。
C　✓ 正確答案
D

概念錯誤　理解遞迴關係錯誤

學生可能誤解題目，將第 n 個圖案的增量公式應用於錯誤的起始點，或完全忽略首項 3 直接對 (2n+3) 求和。

速解策略：由 a_1=3 開始，依序遞迴計算至 a_8，或利用等差級數求和公式直接計算總增量再加首項。
