題目

圓 $ C $ 的方程為 $ 5x^2 + 5y^2 - 30x + 10y + 6 = 0 $ 。下列何者正確？

  • A. 原點位於 $ C $ 以內。
  • B. $ C $ 位於第二象限內。
  • C. $ C $ 的圓周少於 $ 20 $ 。
  • D. $ C $ 的圓心的坐標為 $ (15, -5) $ 。

深度分析

圓的標準式與一般式轉換　認知層次：應用　建議作答 90 秒

核心公式／定理：$x^2+y^2+Dx+Ey+F=0 \Rightarrow (x-h)^2+(y-k)^2=r^2$、$r = \sqrt{h^2+k^2-F}$、$C = 2\pi r$

提示 1（啟發）
將圓的一般式方程 $Ax^2+Ay^2+Bx+Cy+D=0$ 兩邊同除以 $A$ 以化為標準形式。
提示 2（知識）
利用配方法將 $x^2-6x$ 與 $y^2+2y$ 分別補全平方，找出圓心 $(h,k)$ 與半徑平方 $r^2$。
提示 3（破題）
計算出半徑後，使用 $C=2\pi r$ 估算圓周長是否小於 $20$

誘答項逆向工程

A

概念錯誤　點與圓位置關係誤判

學生未將原點座標代入圓方程左側，或算出 $F > 0$ 後誤以為原点在圓外。正確應為 $5(0)^2+5(0)^2-30(0)+10(0)+6 = 6 > 0$，因 $r^2=4$，故原點在圓外。
B

概念錯誤　象限判斷錯誤

學生算出圓心 $(3, -1)$ 位於第四象限，卻誤選第二象限。或學生忽略半徑大小，以為整個圓都在某象限，未考慮圓與軸的交點。
C　✓ 正確答案
D

計算粗心　配方係數計算錯誤

學生在配方時，將 $-30x$ 視為 $(x-15)^2$ 展開後的項，忘記除以 $5$ 的係數。正確應為 $5(x^2-6x) \Rightarrow (x-3)^2$，故圓心為 $(3, -1)$。

速解策略：配方得圓心 $(3,-1)$、半徑 $r=2$，故圓周 $4\pi \approx 12.56 < 20$
