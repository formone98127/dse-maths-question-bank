Question

Let ( f(x) = 2x^2 + 4mx + 8x + 2m^2 + 8m + n ), where ( m ) and ( n ) are real constants such that ( mn < 0 ). Denote the vertex of the graph of ( y = f(x) ) by ( P ).

(a) Using the method of completing the square, express the coordinates of ( P ) in terms of ( m ) and ( n ). (2 marks)

(b) Describe the geometric meaning represented by transforming ( f(x) ) to ( f\left(\frac{x}{5}\right) + 7 ). (2 marks)

(c) Denote the vertex of the graph of ( y = f\left(\frac{x}{5}\right) + 7 ) by ( Q ). Let ( (a_1, b_1) ) and ( (a_2, b_2) ) be the coordinates of ( P ) and ( Q ) respectively. It is given that ( a_1, 1 + n, a_2 ) is an arithmetic sequence and ( b_1, 4 - m, b_2 ) is a geometric sequence.

(i) Find the coordinates of ( P ) and ( Q ). (4 marks)

(ii) The coordinates of the points ( R ) and ( S ) are ( (3t + 27, t) ) and ( (3t + 3, 2t - 3) ) respectively, where ( t ) is a real number. Is it possible that ( PQRS ) is a rhombus? Explain your answer. (8 marks)

深度分析

二次函數與圖形變換　認知層次：分析　建議作答 480 秒

核心公式／定理：$y = a(x-h)^2 + k \Rightarrow V(h,k)$、$f\left(\frac{x}{k}\right) \text{ 表示 } x \text{ 軸方向縮放 } k \text{ 倍}、$a_1, a, a_2 \text{ 等差} \Rightarrow a = \frac{a_1+a_2}{2}$、$b_1, b, b_2 \text{ 等比} \Rightarrow b^2 = b_1 b_2$、$\text{菱形條件：四邊相等或對角線互相垂直平分}$

提示 1（啟發）
先完成 (a)(b) 確保頂點坐標表達式正確，這是後續計算基礎。
提示 2（知識）
等差數列取中間項等於兩端項平均，等比數列中間項平方等於兩端項乘積。
提示 3（破題）
菱形判定可選「對角線互相垂直平分」或「四邊相等」，建議用中點與斜率較簡便。

速解策略：先配方法得 P(m, n+m^2+4m)，變換後 Q(5m, n+m^2+4m+7)。利用等差等比列方程解 m,n，再驗證菱形條件（中點重合且斜率垂直）。
