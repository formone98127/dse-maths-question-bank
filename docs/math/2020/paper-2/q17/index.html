題目

圖中，$P$ 及 $Q$ 均為 $OR$ 上的點而 $U$ 及 $T$ 均為 $OS$ 上的點使得 $OP=PQ=QR$ 且 $PU\parallel QT\parallel RS$ 。梯形 $PQTU$ 的面積與梯形 $QRST$ 的面積之比為

  • A. $1:2$
  • B. $2:3$
  • C. $3:5$
  • D. $4:9$

深度分析

幾何相似與面積比　認知層次：分析　建議作答 90 秒

核心公式／定理：\text{梯形面積} = \frac{1}{2}(上底 + 下底) \times 高、\text{相似比} = k \Rightarrow \text{面積比} = k^2

提示 1（啟發）
觀察 PU // QT // RS，這意味著 \triangle OPU \sim \triangle OQT \sim \triangle ORS。
提示 2（知識）
利用相似三角形的面積比等於對應邊長比的平方，先求出三個相似三角形 \triangle OPU, \triangle OQT, \triangle ORS 的面積比。
提示 3（破題）
梯形 PQTU 的面積等於 \triangle OQT 減去 \triangle OPU；梯形 QRST 的面積等於 \triangle ORS 減去 \triangle OQT，再求兩者的比值。

誘答項逆向工程

A

計算粗心　誤用線段比為面積比

學生可能直接將 OP:PQ:QR = 1:2:3 當作梯形高度或底邊的比例，錯誤地認為面積比等於線段長度比 (1+2):(2+3) 或其他簡單加總，忽略了相似圖形面積比是平方關係。
B

概念錯誤　混淆梯形與三角形面積比

學生嘗試將整個大三角形 O-R-S 視為基準，計算出 PQTU 與 QRST 的面積後，可能錯誤地將 PQTU 的面積算作小三角形 OPQ 與 OPQ+PQR 的差，導致比例分母錯誤。
C　✓ 正確答案
D

計算粗心　相似比計算錯誤

學生可能正確識別出相似三角形，但算錯了相似比。例如，將 OP=1, OR=3 視為相似比 k=1/3，卻忘記了 QRST 對應的是中間部分而非頂端，導致面積比算成 (1/3)^2=1:9 或類似錯誤，這裡選 D 可能是誤以為底邊比為 2:3。

速解策略：設 OP=1, PQ=2, QR=3，則相似比 k 分別為 1, 2, 4（相對於 O 點），面積比為 1:4:16，梯形面積分別為 3 與 12，比值為 1:4？等等，重新檢查：OP:PQ:QR=1:2:3。OT/OR = (1+2)/(1+2+3) = 3/6 = 1/2? 不，OP=1, OQ=3, OR=6。相似比 k1=1/6, k2=3/6=1/2, k3=1。面積比 (k1)^2 : (k2)^2 : (k3)^2 = 1/36 : 9/36 : 36/36 = 1:9:36。梯形 PQTU = 9-1=8。梯形 QRST = 36-9=27。比值 8:27? 不對，題目是 OP=PQ=QR，所以 OP=x, PQ=x, QR=x。OQ=2x, OR=3x。相似比 OQ/OR = 2/3。\triangle OQT \sim \triangle ORS，比例 2:3。面積比 4:9。梯形 PQTU = S_{ORS} - S_{OQT} = 9k - 4k = 5k。梯形 QRST? 不，題目是 PQTU vs QRST。PQTU 對應 OQ 與 OP 之間？不，PQTU 是中間那個梯形。QRST 是最下面的梯形。\triangle OPS (頂部) : \triangle OQT (中間) : \triangle ORS (底部)。OP=1, OQ=2, OR=3 (單位長度 x)。相似比 1:2:3。面積比 1:4:9。梯形 PQTU = 4-1=3。梯形 QRST = 9-4=5。比值 3:5。
