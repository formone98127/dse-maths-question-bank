題目

圖中，$O$ 為圓 $ABC$ 的圓心。$DE$ 為圓在 $A$ 的切線。若 $\angle BAD = 68^\circ$ 及 $\angle BCO = 26^\circ$，則 $\angle ABC =$

  • A. $42^\circ$
  • B. $48^\circ$
  • C. $54^\circ$
  • D. $64^\circ$

深度分析

圓的性質與切線　認知層次：應用　建議作答 120 秒

核心公式／定理：弦切角等於其所夾弧對應之圓周角、半徑與切線垂直 ($\angle OAE = 90^\circ$)、三角形內角和 $180^\circ$、等腰三角形底角相等

提示 1（啟發）
回憶圓心與切線的幾何關係，以及弦切角定理的定義。
提示 2（知識）
在 $\triangle AOE$ 中利用內角和求出 $\angle AOE$，並注意 $\triangle OBC$ 為等腰三角形。
提示 3（破題）
連結圓周角 $\angle ABC$ 與圓心角 $\angle AOC$ 的數值關係（$\angle AOC = 2 \angle ABC$）。

誘答項逆向工程

A

計算粗心　角度運算錯誤

計算出 $\angle AOE = 180 - 68 - 26 = 86$ 後，誤以為 $\angle ABC$ 是圓心角的一半直接除以 2 得到 $43$，四捨五入或口算錯誤成 $42$。
B　✓ 正確答案
C

概念錯誤　混淆弦切角與圓周角關係

誤以為 $\angle BAD$ 直接等於 $\angle ABC$，忽略 $\angle BCO$ 的條件，或錯誤認為 $\angle AOE = 2 \times \angle ABC$ 但計算時未扣除 $\angle OAE$ 的補角關係。
D

審題不清　誤讀角度位置

將 $\angle BCO = 26^\circ$ 誤認為是 $\angle OCB$ 的補角或其他位置，導致在等腰三角形 $\triangle OBC$ 中算出錯誤的底角，進而影響最終結果。

速解策略：利用弦切角定理求 $\angle AOE$，再經等腰三角形性質得 $\angle BCO$，最後由圓周角定理算出 $\angle ABC$
