題目

定義 $ z_1 = \dfrac{2 + ki}{1 + i} $ 及 $ z_2 = \dfrac{k + 5i}{2 - i} $，其中 $ k $ 為一實數。若 $ z_1 $ 的虛部等於 $ z_2 $ 的虛部，則 $ z_1 - z_2 = $

  • A. $-20$。
  • B. $0$。
  • C. $3$。
  • D. $10$。

深度分析

複數運算與虛部概念　認知層次：應用　建議作答 120 秒

核心公式／定理：$\dfrac{a+bi}{c+di} = \dfrac{(a+bi)(c-di)}{c^2+d^2}$、$z = x + yi$ 的虛部為 $y$

提示 1（啟發）
提示 1：先將 $z_1$ 和 $z_2$ 分別進行分母有理化，寫成標準形式 $a+bi$。
提示 2（知識）
提示 2：根據題目條件「虛部相等」，建立關於 $k$ 的方程式並求解 $k$ 的值。
提示 3（破題）
提示 3：將求得的 $k$ 代回原式計算出 $z_1$ 與 $z_2$ 的具體數值，最後執行減法運算。

誘答項逆向工程

A

計算粗心　符號處理錯誤

計算 $z_1$ 虛部時，忘記分母有理化後分子展開的交叉項符號，導致虛部數值算錯，進而影響後續減法結果。
B

概念錯誤　誤解複數性質

誤以為兩虛部相等則兩複數必相等，忽略實部可能不同的情況，直接得出差為 0。
C　✓ 正確答案
D

計算粗心　實部計算失誤

正確求出虛部相等條件後，在計算 $z_1$ 與 $z_2$ 的實部差值時，分母平方項或展開式符號處理錯誤。

速解策略：先化簡兩複數得虛部含 $k$ 之式，令其相等解得 $k=3$，再代回求差值。
