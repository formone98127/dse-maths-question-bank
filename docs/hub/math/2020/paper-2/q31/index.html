題目

B000000000000030_{16} =

  • A. 10×2^{60}+48
  • B. 11×2^{60}+48
  • C. 10×2^{64}+768
  • D. 11×2^{64}+768

深度分析

進位制轉換與指數運算　認知層次：應用　建議作答 90 秒

核心公式／定理：16^n = (2^4)^n = 2^{4n}、十六進制數值轉十進制公式：\sum d_i \times 16^i

提示 1（啟發）
提示 1：十六進制的每一位代表該位數乘以 16 的次方，請先將 B0_{16} 展開為 \sum d_i \times 16^i。
提示 2（知識）
提示 2：關鍵在於將底數 16 轉換為 2 的冪次，利用公式 16 = 2^4，因此 16^{60} 應等於多少？
提示 3（破題）
提示 3：請分別計算 B_{16} 與 0_{16} 對應的十進制數值，再結合上述指數轉換結果進行加總。

誘答項逆向工程

A

計算粗心　底數轉換錯誤

學生知道十六進制轉十進制，但計算時將 16^{60} 誤算為 2^{60}，忽略了 16=2^4 的關係，導致指數未乘 4。
B　✓ 正確答案
C

計算粗心　指數與係數混淆

學生正確將 16^{60} 轉為 2^{240}，但可能誤以為題目是 16^64 或計算 10_{16} 時出錯，導致出現 2^{64} 且係數為 10。
D

計算粗心　底數轉換與係數雙重錯誤

學生同樣誤將 16^{60} 視為 2^{64}（或混淆指數），且正確計算了 B0_{16} 的十進制值為 11\times 16^{60}，但後續轉換步驟出錯。

速解策略：將 B0_{16} 展開為 B\times 16^{60} + 0，並將 16^{60} 換算成 2^{240}，最後計算 B 的十進制值。
