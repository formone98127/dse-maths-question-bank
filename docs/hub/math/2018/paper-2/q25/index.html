題目

直線 $ L_1 $ 及直線 $ L_2 $ 的方程分別為 $ 3x - y + 7 = 0 $ 及 $ 12x - 4y - 11 = 0 $ 。設 $ P $ 為直角坐標平面上的一動點使得由 $ P $ 至 $ L_1 $ 的垂直距離等於由 $ P $ 至 $ L_2 $ 的垂直距離。求 $ P $ 的軌跡的方程。

  • A. $ 8x - 24y - 17 = 0 $
  • B. $ 8x - 24y + 17 = 0 $
  • C. $ 24x - 8y - 17 = 0 $
  • D. $ 24x - 8y + 17 = 0 $

深度分析

直線距離公式與平行線系　認知層次：應用　建議作答 120 秒

核心公式／定理：d = |Ax + By + C| / sqrt(A^2 + B^2)

提示 1（啟發）
提示 1：兩直線距離相等意味著 P 點位於這兩條平行線的垂直平分線上。
提示 2（知識）
提示 2：首先將 L_2 的方程除以 4，使其與 L_1 具有相同的 x, y 係數以確認平行關係。
提示 3（破題）
提示 3：計算兩平行線的中間位置（常數項取平均值），即可得到軌跡方程。

誘答項逆向工程

A

計算粗心　符號錯誤

學生算出平行線係數比正確，但在合併常數項時，將 -17 與 +17 搞混，選了錯誤的符號組合。
B

計算粗心　平行線判定失敗

學生未將 L2 化為最簡式，直接比較係數導致斜率判斷錯誤，選出與題目不符的平行線。
C

計算粗心　常數項計算錯誤

學生正確找出平行線方向，但在計算兩直線間距中點或垂直平分線截距時，算術運算出錯。
D　✓ 正確答案

速解策略：化簡 L2 為 3x-y-11/4=0，求兩線中間的常數項平均值得到 -17/8，整理即得答案。
