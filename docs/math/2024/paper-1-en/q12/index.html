Denote the origin by ( O ).

(a) ( A ) and ( B ) are points lying on the positive ( x )-axis such that the ( x )-coordinate of ( A ) is greater than the ( x )-coordinate of ( B ). A vertical line which passes through ( B ) cuts the straight line ( y = mx ) at the point ( C ) such that ( AB = BC ), where ( m ) is a positive constant. Let ( D ) be a point such that ( ABCD ) is a square. Express the slope of ( OD ) in terms of ( m ). (3 marks)

Let ( P ) and ( Q ) be points lying on ( OM ) and ( MN ) respectively while ( R ) and ( S ) be points lying on the ( x )-axis. 深度分析

微分方程　認知層次：分析　建議作答 450 秒

核心公式／定理：\int \frac{f'(x)}{f(x)} dx = \ln|f(x)| + C、\lim_{t \to \infty} (0.8)^{2t+3} = 0

提示 1（啟發）
Hint1: 觀察 \frac{dR}{dt} 的分母結構，其導數是否等於分子？
提示 2（知識）
Hint2: 回憶 \int \frac{u'}{u} dx = \ln|u| + C 的積分公式。
提示 3（破題）
Hint3: 對於指數衰減項 (0.8)^{kt}，當 t 很大時其行為如何？

速解策略：先簡化 \frac{dR}{dt} 為對數導數形式，再積分；接著處理利潤差值積分，最後取極限。
