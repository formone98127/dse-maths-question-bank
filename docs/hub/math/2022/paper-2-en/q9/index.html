Question

Let $g(x) = x^2 + ax + b$, where $a$ and $b$ are constants. If $g(x)$ is divisible by $x + 2a$, find the remainder when $g(x)$ is divided by $x - 2a$.

  • A. $-2a^2$
  • B. 0
  • C. $2a^2$
  • D. $4a^2$
Share on WhatsAppShare on Telegram

Answer

Correct answer: D. 4a^2

深度分析

多項式除法與餘數定理　認知層次：應用　建議作答 90 秒

核心公式／定理：$P(x)$ 除以 $(x-c)$ 的餘數為 $P(c)$、$g(x) = (x - r_1)(x - r_2)$

提示 1（啟發）
回顧餘數定理：多項式 $g(x)$ 除以 $(x-c)$ 的餘數等於 $g(c)$。
提示 2（知識）
利用「$g(x)$ 能被 $x+2a$ 整除」這一條件，求出常數項 $b$ 與係數 $a$ 的關係。
提示 3（破題）
將 $x=2a$ 代入 $g(x)$ 並化簡，即可得到所求餘數。

誘答項逆向工程

A

概念錯誤　符號處理錯誤

算出餘數為 $2a^2$ 後，因混淆「除以 $x+2a$」與「除以 $x-2a$」的係數關係，隨意變號選 A。
B

概念錯誤　誤解可除性條件

認為既然能被 $x+2a$ 整除，那麼對稱的 $x-2a$ 也應該能被整除（餘數為 0），忽略係數不對稱。
C

計算粗心　代入計算錯誤

正確算出 $b = -2a^2$，但在計算 $g(2a) = (2a)^2 + a(2a) + (-2a^2)$ 時，加法運算出錯。
D　✓ 正確答案

速解策略：由 $g(-2a)=0$ 得 $b=-2a^2$；再算 $g(2a)=(2a)^2+a(2a)+b=4a^2$
