Question

In the figure, the straight line $L$ shows the relation between $\log_{4}x$ and $\log_{4}y$. It is given that $L$ passes through the points $(1,2)$ and $(9,6)$. If $y=kx^{a}$, then $k=$

[FIGURE Q33: 直角坐標系，橫軸標 $\log_{4}x$、縱軸標 $\log_{4}y$，直線 L 由左下向右上，通過 (1,2)、(9,6)；標 O]

  • A. $\dfrac{1}{2}$
  • B. $\dfrac{3}{2}$
  • C. $2$
  • D. $8$

Answer

Correct answer: D. 8

深度分析

指數與對數函數　認知層次：分析　建議作答 120 秒

核心公式／定理：$\log_b(xy) = \log_b x + \log_b y$、$y = kx^a \iff \log_a y = a \log_a x + \log_a k$

提示 1（啟發）
提示 1：觀察題目給出的關係式 $y=kx^a$，若對兩邊取以 4 為底的對數，會變成什麼形式的直線方程式？
提示 2（知識）
提示 2：將點 $(1,2)$ 與 $(9,6)$ 代入上述直線方程式，先求出斜率 $a$ 與截距 $c$（其中 $c = \log_4 k$）。
提示 3（破題）
提示 3：已知截距 $c = -\frac{1}{3}$，請利用指數定義 $k = 4^c$ 計算最終答案。

誘答項逆向工程

A

計算粗心　常數項計算錯誤

學生算出斜率 a=2/3 後，代入點 (1,2) 求截距時，將 log4(k) 誤算為 -1/2 而非 -1/3，導致 k=1/2。
B

計算粗心　截距符號處理錯誤

學生正確求得 log4(k) = -1/3，但在計算 4^(-1/3) 時，誤將其化為 (1/2)^2 或類似錯誤數值。
C

概念錯誤　忽略底數轉換

學生未將 log4(k) 轉換為指數形式，或誤以為截距直接等於 k，故選 2 (即截距的相反數)。
D　✓ 正確答案

速解策略：取對數轉直線式 $Y=aX+c$，代入點求 $c$，再算 $k=4^c$
