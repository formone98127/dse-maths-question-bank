2021 DSE 數學 P1 Q17 答案＋詳解

題目（中文卷）

設 $A(n)$ 為一等差數列的第 $n$ 項。已知 $A(5)=26$ 及 $A(12)=61$。

(a) 求 $A(1)$。

(b) 假定對任意正整數 $n$，$\log_{2}G(n)=A(n)$。求 $k$ 的最大值使得 $\log_{8}(G(1)G(2)G(3)\cdots G(k))<999$。

English version（英文卷題目）

Let ( A(n) ) be the ( n )th term of an arithmetic sequence. It is given that ( A(5) = 26 ) and ( A(12) = 61 ).

(a) Find ( A(1) ). (2 marks)

(b) Suppose that ( \log_2 G(n) = A(n) ) for any positive integer ( n ). Find the greatest value of ( k ) such that ( \log_8 \left( G(1) G(2) G(3) \cdots G(k) \right) < 999 ). (5 marks)

官方評卷參考（Marking Scheme）

考評報告

（a）良好。大約65%考生能求得A(1)。部分考生混淆了等差數列與等比數列,因此他們未能求得A(1)。 （b）平平。很多考生誤以等比數列的求和公式處理 G(1)G(2)G(3)...G(k),因此他們未能求得k的最大值使得 $\log_{8}(G(1)G(2)G(3)\cdots G(k))$&lt;999。
