2014 DSE 數學 P1 Q12 答案＋詳解

題目（中文卷）

圓 $C$ 通過點 $A(6,11)$ 且 $C$ 的圓心為點 $G(0,3)$。

(a) 求 $C$ 的方程。

(b) $P$ 為直角坐標平面上的一動點使得 $AP=GP$。將 $P$ 的軌跡記為 $\Gamma$。

(i) 求 $\Gamma$ 的方程。

(ii) 描述 $\Gamma$ 與線段 $AG$ 之間的幾何關係。

(iii) 若 $\Gamma$ 與 $C$ 相交於 $Q$ 及 $R$，求四邊形 $AQGR$ 的周界。

English version（英文卷題目）

The circle ( C ) passes through the point ( A(6,11) ) and the centre of ( C ) is the point ( G(0,3) ).

(a) Find the equation of ( C ). (2 marks)

(b) ( P ) is a moving point in the rectangular coordinate plane such that ( AP = GP ). Denote the locus of ( P ) by ( \Gamma ).

(i) Find the equation of ( \Gamma ). (3 marks)

(ii) Describe the geometric relationship between ( \Gamma ) and the line segment ( AG ). (2 marks)

(iii) If ( \Gamma ) cuts ( C ) at ( Q ) and ( R ), find the perimeter of the quadrilateral ( AQGR ). (5 marks)

官方評卷參考（Marking Scheme）

考評報告

良好。部分考生誤以為C的圓心為點A(6,11)而非點G(0,3)。良好。很多考生能求得Γ的方程,雖然部分考生知道Γ垂直於線段AG,但他們誤以為Γ的斜率為-4/3。良好。很多考生能指出Γ垂直於線段AG,但部分考生誤以為Γ為線段AG的角平分線。甚差。大部分考生未能察覺四邊形AQGR為一菱形,因而未能得出四邊形AQGR的周界。
