題目

設 $\alpha$ 及 $\beta$ 均為實數使得 $\begin{cases} \beta = 5\alpha - 18 \ \beta = \alpha^2 - 13\alpha + 63 \end{cases}$

(a) 求 $\alpha$ 及 $\beta$ 。 (2 分)

(b) 某等差數列的第 1 項及第 2 項分別為 $\log\alpha$ 及 $\log\beta$ 。求 $n$ 的最小值使得該數列的首 $n$ 項之和大於 888 。 (4 分)

深度分析

代數化簡　認知層次：應用　建議作答 180 秒

核心公式／定理：S_n = \frac{n}{2}[2a + (n-1)d]、\log(xy) = \log x + \log y

提示 1（啟發）
先將兩個關於β的表達式相等，整理成標準一元二次方程形式。
提示 2（知識）
記得檢查α與β是否滿足對數定義域（大於0）。
提示 3（破題）
等差數列求和公式S_n = n/2(2a+(n-1)d)，注意d為logβ-logα。

速解策略：聯立方程解出α,β後，直接代入等差求和公式，化簡成An+B形式不等於888即可解得n。
