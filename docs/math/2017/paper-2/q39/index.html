題目

圖中，$AD$ 為立於水平地面 $BCD$ 上的鉛垂柱。若 $AB=25\text{ m}$、$AD=15\text{ m}$、$BC=29\text{ m}$ 及 $CD=21\text{ m}$，求 $AB$ 與平面 $ACD$ 間的交角準確至最接近的度。

  • A. $53^\circ$
  • B. $54^\circ$
  • C. $69^\circ$
  • D. $70^\circ$

深度分析

空間幾何與線面夾角　認知層次：應用　建議作答 120 秒

核心公式／定理：$\cos \theta = \frac{\text{投影長}}{\text{斜線長}}$、$c^2 = a^2 + b^2 - 2ab \cos C$

提示 1（啟發）
線面夾角的定義：斜線與其在平面上的投影所成的角。
提示 2（知識）
利用勾股定理求出 $AC$ 的長度，並確認 $AD \perp BC$ 的關係以確定投影位置。
提示 3（破題）
在 $\triangle ABC$ 中應用餘弦定理求 $\cos \angle BAC$，再換算成角度。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　餘弦定理計算誤差

在三角形 $ACD$ 中算出 $AC^2=836$，但後續求 $\cos \angle CAD$ 時將 $AD$ 當作底邊或角度對應邊搞混，導致算出約 $54.1^\circ$
C

概念錯誤　混淆線面夾角定義

誤以為所求為 $AB$ 與地面 $BCD$ 的夾角，直接算 $\sin \theta = AD/AB = 15/25$ 得到 $37^\circ$ 後錯選或誤讀，或是算出 $AC$ 後直接用 $BC$ 當作投影。
D

審題不清　四捨五入判斷錯誤

正確算出角度約為 $53.16^\circ$，但學生因題目要求「最接近」而猶豫，或誤將 $53.16$ 看錯成 $70$（極少見），更可能是計算錯誤導至 $69$ 附近。

速解策略：先由 $Rt\triangle ADC$ 得 $AC=\sqrt{AD^2+CD^2}$，再由 $Rt\triangle ABC$ 得 $BC=\sqrt{AB^2-AC^2}$（錯），應直接求 $AC$ 後，在 $\triangle ABC$ 中用餘弦定理求 $\angle BAC$。
