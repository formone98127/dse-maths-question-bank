題目

下面的圓形圖顯示 $X$ 文具店及 $Y$ 文具店在某月從銷售文具所得的盈利的分佈。下列何者必為正確？

  • A. 在該月，$X$ 文具店從銷售鉛筆所得的盈利與 $Y$ 文具店相同。
  • B. 在該月，$X$ 文具店從銷售原子筆和筆記簿所得的總盈利少於該店從銷售間尺和鉛筆所得的總盈利。
  • C. $k=14$
  • D. $\theta=36^\circ$

深度分析

圓形圖解讀與比例推理　認知層次：分析　建議作答 90 秒

核心公式／定理：扇形角度 = 360^\circ \times 百分比、總盈利 = 單項盈利 / 該項百分比

提示 1（啟發）
提示 1：圓形圖中的扇形大小代表該店「總盈利」的一定比例，而非絕對金額。
提示 2（知識）
提示 2：比較兩店同一項商品時，需考慮兩店總銷售額是否相等。
提示 3（破題）
提示 3：利用 X 店已知數據（原子筆、筆記簿、間尺）的百分比和，推導出鉛筆的百分比以驗證選項 B。

誘答項逆向工程

A

審題不清　混淆絕對值與相對比例

誤以為兩店鉛筆扇形角度相同代表銷售金額相同，忽略了兩店總銷售額（圓面積）可能不同。
B　✓ 正確答案
C

計算粗心　誤算未知數 k 的百分比

錯誤假設 Y 店總和為 100% 直接減去已知項，未考慮 X 店的數據或誤讀圖表標註。
D

概念錯誤　角度與百分比轉換錯誤

將 Y 店鉛筆的百分比誤用為 X 店的角度計算，或忘記 360^\circ 的總和係數。

速解策略：計算 X 店各項目百分比總和，若原子筆 + 筆記簿 < 間尺 + 鉛筆則選 B；檢查 Y 店數據排除 C、D。
