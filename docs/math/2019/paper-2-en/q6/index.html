Question

If $0.06557 < x < 0.06564$, which of the following is true?

  • A. $x=0.065$ (correct to 2 decimal places).
  • B. $x=0.065$ (correct to 2 significant figures).
  • C. $x=0.0656$ (correct to 3 decimal places).
  • D. $x=0.0656$ (correct to 3 significant figures).
Share on WhatsAppShare on Telegram

Answer

Correct answer: D. x=0.0656 (correct to 3 significant figures)

有效數字與四捨五入　認知層次：理解　建議作答 45 秒

核心公式／定理：有效數字定義：從第一個非零數字開始計數

提示 1（啟發）
回憶有效數字的定義：從第一個非零數字開始計算。
提示 2（知識）
觀察範圍上下限，確定 x 的可能值落在哪個區間。
提示 3（破題）
比較各選項的表述是否與 x 的實際取值範圍一致。

誘答項逆向工程

A

審題不清　混淆小數位數與有效數字

學生認為只要看最後一位小數，0.06557 四捨五入到二位小數是 0.066，但題目選項寫 0.065，學生可能誤以為直接截斷或計算錯誤。
B

概念錯誤　誤解有效數字起始點

學生忘記前導零不算有效數字，將 0.065 視為兩位有效數字（實際是三位：6,5,7...），或認為只有 6 和 5 算。
C

計算粗心　四捨五入方向錯誤

學生計算 0.06557 四捨五入到三位小數時，看到第四位是 7，應進位成 0.0656，但選項 C 寫的是正確數值卻標註為「三位小數」，學生可能誤以為這是唯一正確表達。
D　✓ 正確答案

速解策略：確認 0.0656 為三位有效數字且涵蓋整個區間。
