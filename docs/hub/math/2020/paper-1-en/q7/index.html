Question

Let ( p(x) = 4x^2 + 12x + c ), where ( c ) is a constant. The equation ( p(x) = 0 ) has equal roots. Find

(a) ( c ),

(b) the ( x )-intercept(s) of the graph of ( y = p(x) - 169 ).

(5 marks)

深度分析

一元二次方程　認知層次：應用　建議作答 180 秒

核心公式／定理：$b^2 - 4ac = 0$、$y = ax^2 + bx + c$

提示 1（啟發）
等根意味著圖形與 x 軸只有一個交點，即 $\Delta = 0$。
提示 2（知識）
平移後的函數形式為 $y = 4(x+k)^2 + m$，令 $y=0$ 即可求截距。
提示 3（破題）
x 截距是圖像與 x 軸的交點，務必令 $y=0$ 求解。

速解策略：先由 $\Delta=0$ 得 $c=-9$；再寫出 $y=4x^2+12x-9-169$，令 $y=0$ 解方程即得兩個 x 截距。
