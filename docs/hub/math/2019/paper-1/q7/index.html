題目

在某遊樂場，成人數與小童數之比為 $13:6$。若 $9$ 名成人和 $24$ 名小童進入該遊樂場，則成人數與小童數之比為 $8:7$。求在該遊樂場原本的成人數。（4 分）

深度分析

比率與比例　認知層次：應用　建議作答 180 秒

核心公式／定理：\frac{n_1}{n_2} = \frac{a}{b}

提示 1（啟發）
提示 1：原本成人與小童比例為 $13:6$，意味著他們人數成比例，可設原本成人 $13k$、小童 $6k$。
提示 2（知識）
提示 2：加入後總人數變化，但內部比例改變，利用新比例建立等式。
提示 3（破題）
提示 3：將已知數字代入方程，解出 $k$ 即可得原本成人數。

速解策略：設原本成人 $13k$、小童 $6k$，加入後比為 $8:7$，列式 \frac{13k+9}{6k+24} = \frac{8}{7}$ 解 $k$。
