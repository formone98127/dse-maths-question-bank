題目

圖中，$\angle ABD=\angle ADC=\angle BCD=90^\circ$。若 $AB=\ell$，則 $CD=$

  • A. $\ell\sin\theta$。
  • B. $\ell\cos\theta$。
  • C. $\ell\sin\theta\tan\theta$。
  • D. $\dfrac{\ell\tan\theta}{\cos\theta}$。

深度分析

三角函數與幾何圖形　認知層次：應用　建議作答 45 秒

核心公式／定理：$\sin A = \frac{對邊}{斜邊}$、$\cos A = \frac{鄰邊}{斜邊}$、$\tan A = \frac{對邊}{鄰邊}$

提示 1（啟發）
觀察圖形中 $\triangle ABD$ 與 $\triangle BCD$ 的角度標記，找出哪兩個三角形共享角度 $\theta$。
提示 2（知識）
回憶在直角三角形中，正弦函數定義為「對邊比斜邊」，並確認 $\theta$ 在哪個三角形內。
提示 3（破題）
將 $AB=\ell$ 視為已知斜邊或鄰邊，直接建立 $CD$ 與 $\ell$ 及 $\theta$ 的簡潔等式。

誘答項逆向工程

A　✓ 正確答案
B

概念錯誤　混淆正弦與餘弦定義

學生誤以為 $CD$ 是 $\theta$ 的鄰邊，直接套用 $\cos\theta = \frac{CD}{AB}$ 而忽略圖中角度位置。
C

計算粗心　無意義的三角函數乘法

學生可能試圖將 $\sin$ 與 $\tan$ 相乘來「補足」角度關係，但未理解單位長度與角度的直接比例。
D

策略錯誤　過度複雜化表達式

學生先求 $\tan\theta$ 再除以 $\cos\theta$，這是將簡單關係誤解為需要多重轉換的錯誤策略。

速解策略：在 $\triangle ABD$ 中利用 $\sin\theta = \frac{BD}{AB}$ 得 $BD=\ell\sin\theta$，再於 $\triangle BCD$ 中發現 $CD=BD\cos(90^\circ-\theta)=BD\sin\theta$ 或直接觀察角度關係得出結果。
