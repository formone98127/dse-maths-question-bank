題目

若 $x = \log_{2} y - 2$ 及 $(\log_{2} y)^{2} = 5 \log_{2} y + x - 7$ ，則 $y=$

  • A. 1
  • B. 8
  • C. 1 或 3
  • D. 3 或 8

深度分析

對數方程式　認知層次：應用　建議作答 90 秒

核心公式／定理：$\log_{a} b = c \iff a^c = b$、$x^2 - bx + c = 0$

提示 1（啟發）
提示 1：觀察兩個方程式中均出現 $\log_{2} y$，考慮將其視為一個整體變量進行替換簡化。
提示 2（知識）
提示 2：令 $u = \log_{2} y$，並將第一個式子中的 $x$ 也用 $u$ 表示，代入第二個方程式形成關於 $u$ 的一元二次方程。
提示 3（破題）
提示 3：解出 $u$ 後，務必將每個 $u$ 值代回原式驗證是否滿足所有條件，特別注意對數函數的定義域與等式一致性。

誘答項逆向工程

A

概念錯誤　忽略變量替換後的二次方程解

學生可能只注意到 $x=\log_2 y - 2$，若直接猜測 $y=1$ 則 $\log_2 y=0, x=-2$。代入第二式：$0 = 5(0) + (-2) - 7 \Rightarrow 0 = -9$ 不成立，但學生可能未仔細驗證或誤以為是解之一而選單個值。
B　✓ 正確答案
C

計算粗心　未驗證解的合理性即列出所有根

學生解出 $t^2 - 5t + 3 = 0$ 或類似錯誤代數操作，得到兩個解後直接對應回 $y$，卻忽略其中一個解在原始方程中導致矛盾（如分母為零或對數定義域問題，此題實為代入後不等式成立性檢查）。
D

策略錯誤　混淆變量替換與原始變量關係

學生設 $u = \log_2 y$，得 $u^2 = 5u + (u-2) - 7 = 6u - 9$，解得 $u=3, u=1/3$？錯誤。正確應為 $u^2 - 5u - (u-2) + 7 = 0 \Rightarrow u^2 - 6u + 9 = 0 \Rightarrow (u-3)^2=0$？不對，重算：$u^2 = 5u + x - 7$，且 $x=u-2$，故 $u^2 = 5u + (u-2) - 7 = 6u - 9 \Rightarrow u^2 - 6u + 9 = 0 \Rightarrow (u-3)^2=0 \Rightarrow u=3$。所以只有 $u=3$，即 $\log_2 y = 3 \Rightarrow y=8$。選項 D 包含 3，表示學生誤解 $u=1/3$ 或計算錯誤導致多餘解。

速解策略：令 $u=\log_2 y$，代入消去 $x$ 得 $(u-3)^2=0\Rightarrow u=3\Rightarrow y=8$
