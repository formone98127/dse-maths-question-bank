Question

The graph in the figure shows the linear relation between $\log_3 x$ and $\log_3 y$. Which of the following must be true?

  • A. $x^2 y^3 = 729$
  • B. $x^3 y^2 = 729$
  • C. $x^2 + y^3 = 729$
  • D. $x^3 + y^2 = 729$

Answer

Correct answer: A. x^2 y^3 = 729

深度分析

對數函數與線性關係　認知層次：分析　建議作答 90 秒

核心公式／定理：$\log_a(xy) = \log_a x + \log_a y$、$\log_a(x^n) = n\log_a x$

提示 1（啟發）
觀察圖形：當 $\log_3 x = 0$ 與 $\log_3 y = 0$ 時，對應的點分別在哪裡？
提示 2（知識）
利用對數性質將 $\log_3 x + \log_3 y$ 合併為單一的對數式，再轉化為指數形式。
提示 3（破題）
代入圖形上的兩個明顯坐標點（如截距點），驗證哪個選項成立。

誘答項逆向工程

A　✓ 正確答案
B

概念錯誤　指數係數混淆

將 $x$ 與 $y$ 的斜率係數搞反，認為 $x$ 對應較大的指數，忽略了截距對應的常數項。
C

概念錯誤　誤用加法法則

忘記對數乘法變加法，卻錯誤地將指數與底數直接相加，混淆了 $\log(xy)$ 與 $(\log x)(\log y)$。
D

計算粗心　截距計算錯誤

正確識別係數關係，但在將截距值 $3$ 代入時，誤算為 $3^2+3^3$ 或其他錯誤組合。

速解策略：由圖得 $\log_3 x + \log_3 y = k$，合併後取指數得 $xy^k=3^k$，再對齊係數與常數項。
