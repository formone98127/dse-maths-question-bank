Question

If $a$ is a real number, then the real part of $\dfrac{4+i^{5}}{a+i}-i^{6}$ is

  • A. $\dfrac{4a+1}{a^{2}-1}$
  • B. $\dfrac{4a+1}{a^{2}+1}$
  • C. $\dfrac{a^{2}+4a+2}{a^{2}-1}$
  • D. $\dfrac{a^{2}+4a+2}{a^{2}+1}$

Answer

Correct answer: D. \dfrac{a^{2}+4a+2}{a^{2}+1}

深度分析

複數運算　認知層次：應用　建議作答 90 秒

核心公式／定理：$i^2=-1$, $i^3=-i$, $i^4=1$、$\frac{z_1}{z_2}=\frac{z_1\bar{z_2}}{|z_2|^2}$、$z=x+yi$ 的實部為 $x$

提示 1（啟發）
先利用 $i^2=-1$ 化簡分子中的 $i^5$ 與 $i^6$，將表達式整理為 $\frac{4+i}{a+i}-1$。
提示 2（知識）
處理分式時，請務必將分母有理化：分子分母同乘 $(a-i)$，並記得 $|a+i|^2=a^2+1$。
提示 3（破題）
將化簡後的結果寫成 $x+yi$ 形式，題目僅要求實部 $x$，請檢查選項中分母是否為 $a^2+1$

誘答項逆向工程

A

計算粗心　分母處理錯誤

分子化簡正確，但在將分母有理化時，誤將 $a+i$ 的共軛複數 $(a-i)$ 乘入後，分母計算成 $a^2-1$ 而非 $a^2+(-1)^2=a^2+1$。
B

概念錯誤　虛部處理疏漏

成功將分母化為 $a^2+1$，但在合併分子時，忽略了原式中的 $-i^6$（即 $-1$）與分母有理化後產生的虛部項未正確歸類或抵消。
C

審題不清　分母符號混淆

完全忽略了複數分母有理化時，分母會變成 $a^2+1$ 的規則，錯誤地沿用了實數除法或平方差公式 $(a+i)(a-i)=a^2-1$。
D　✓ 正確答案

速解策略：化簡虛數單位 -> 有理化分母 -> 合併分子 -> 提取實部
