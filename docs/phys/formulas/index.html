公開評核同課題範圍

以 2027 年大綱為例，物理公開考試包括涵蓋必修部分嘅卷一（選擇同傳統題）同涵蓋選修部分嘅卷二（由若干選修課題中選答指定數目），學校考生另有實驗為本嘅校本評核。必修溫習通常環繞熱同氣體、力和運動、波動、電磁，以及放射同核能等主題；選修可包括原子世界、能量使用、醫學物理或天文學等，以當年大綱為準。

下面係原創溫習清單，符號以常見課堂寫法表示。考試時要以卷面公式表同題目定義為準。

力學

  • 勻加速直線：位移、初速、末速、加速度、時間五個量，揀一條只用已知量嘅關係，避免循環代入。
  • 力同運動：合力等於質量乘加速度，對象要畫自由體圖，分清重量同質量、張力、摩擦力方向。
  • 動量：碰撞前後總動量在無外力（或外力可忽略）時守恆。彈性同非彈性要另外檢查動能係唔係守恆。
  • 功同能：功係力同位移在力方向上嘅貢獻。機械能守恆只在沒有非守恆力做功（或已計算其功）時使用。
  • 圓周或萬有引力相關題：先寫向心力來源，再先套關係。唔好把任何彎曲路徑都當成勻速圓周。

詳見力學筆記。

熱、波、電磁、放射

  • 熱：溫升用熱容量或比熱容關係；物態變化用潛熱，過程中溫度可以保持不變。氣體題要分清等壓、等體、等溫，同埋溫度必須用熱力學溫標去入某些關係。
  • 波：波速等於頻率乘波長。反射、折射、衍射同干涉要先判斷波現象，先再寫條件（例如光程差）。
  • 電：電流、電位差、電阻之間嘅關係，串聯分壓、並聯分流。電功率要分清用邊組已知量。磁場對電流或運動電荷嘅力，要同時講大小同方向法則。
  • 放射：半衰期描述尚未衰變核嘅統計行為。活度、衰變常數同核反應質量能關係，要按題目給出嘅量去用，並注意安全同屏蔽係概念題常客。

答題格式

列出已知、所用關係、代入、單位同方向。圖像題先讀斜率同面積代表咩。估算題要寫合理假設。選修題見各選修課堂筆記，本站必修課題頁由力學去到能量。
