題目

設 $k$ 為一常數。解方程 $(x-k)^2=4k^2$。

  • A. $x=3k$
  • B. $x=5k$
  • C. $x=-k$ 或 $x=3k$
  • D. $x=-3k$ 或 $x=5k$
WhatsApp 分享Telegram 分享

深度分析

一元二次方程式　認知層次：應用　建議作答 60 秒

核心公式／定理：\sqrt{x^2} = |x|、(a-b)^2 = a^2 - 2ab + b^2

提示 1（啟發）
思考：對兩邊開平方時，記得考慮正負兩種情況嗎？
提示 2（知識）
提示：sqrt(4k^2) 等於多少？是單純的 2k 還是與 k 的符號有關？
提示 3（破題）
引導：分別解 x-k=2k 和 x-k=-2k，看看能得到哪兩個解。

誘答項逆向工程

A

概念錯誤　忽略負根

學生開平方後只取正根 x-k=2k，解得 x=3k，忘記了另一種情況 x-k=-2k。
B

計算粗心　符號運算錯誤

學生可能將方程誤讀為 (x-k)^2=4k^2+2k(x-k) 或其他複雜變形，導致計算出 5k。
C　✓ 正確答案
D

概念錯誤　混淆平方根定義

學生錯誤認為 sqrt(4k^2)=2k 且忽略了絕對值，或將 x-k=-2k 誤算為 x=-3k。

速解策略：兩邊開平方得 x-k = pm 2k，移項合併同類項即可。
