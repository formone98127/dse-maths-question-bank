題目

設 $a$、$b$ 及 $c$ 均為非零的數。若 $3a=4b$ 及 $a:c=2:5$，則 $\frac{a+3b}{b+3c}=$

  • A. $\frac{5}{3}$
  • B. $\frac{13}{33}$
  • C. $\frac{30}{53}$
  • D. $\frac{75}{38}$

深度分析

比例與代數式化簡　認知層次：應用　建議作答 60 秒

核心公式／定理：$a:b = k \Rightarrow a=kb, b=kc$、$\frac{x}{y}$ 的運算規則

提示 1（啟發）
提示 1：觀察題目給出的兩個條件 $3a=4b$ 和 $a:c=2:5$，思考如何將所有變數用同一個參數（如 $k$）表示。
提示 2（知識）
提示 2：由 $3a=4b$ 可得 $a = \frac{4}{3}b$；由 $a:c=2:5$ 可得 $c = \frac{5}{2}a$。試著將目標式子中的 $a, b, c$ 全部換成只含 $b$ 的表達式。
提示 3（破題）
提示 3：代入化簡後，你會得到形如 $\frac{\text{數字}}{\text{數字}}$ 的結果，請仔細檢查分子分母的約分步驟，避免計算錯誤。

誘答項逆向工程

A

計算粗心　忽略 c 的係數影響

學生算出 a=4k, b=3k。代入時，分母誤將 3c 視為 0 或忽略比例關係，直接計算 (4k+9k)/(3k) = 13/3，未考慮 c=5/2 k 的轉換，導致數值錯誤。
B　✓ 正確答案
C

審題不清　混淆連比順序

學生正確算出 a=4k, b=3k。但在處理 a:c=2:5 時，誤將 c 視為與 b 相同比例或讀錯題目，導致分母計算成 (3k+15k) 或其他錯誤組合，最終得到 18/18 等簡化錯誤。
D

概念錯誤　比例轉換錯誤

學生試圖用連比 a:b:c，但誤解 3a=4b 與 a:c=2:5 的關係。可能將 a:c=2:5 誤讀為 c:a=2:5，導致 c 的係數變為 1/2.5 而非 2.5，計算結果完全偏差。

速解策略：將 a, c 皆用 b 表示，代入原式化簡即可。令 a=4k, b=3k, c=10k。
