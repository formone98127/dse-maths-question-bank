溫習要點同常見題型

呢部分考離子鍵同共價鍵、電子圖、分子形狀（VSEPR）、極性，以及分子間引力（包括氫鍵）。把分子間引力當成化學鍵，或者分唔清電子對排佈同分子形狀，都係典型混淆。

畫電子圖時記得標孤對電子；講極性要同時考慮鍵極性和分子形狀。

下面索引可以由「分子形狀」同「氫鍵」入手，對照電子圖題有冇畫齊結構。
