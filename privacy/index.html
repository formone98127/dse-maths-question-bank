私隱政策 / Privacy Policy

最後更新：2026-11-20

本網站 DSE Hub（hkdse.exampaper.cloud）提供香港中學文憑（DSE）歷屆試題及相關學習資料。我們重視你的私隱，以下說明本站如何處理資料。

1. 我們收集的資料

  • 瀏覽統計：本站使用 Google Analytics 4（GA4）以匿名／彙總方式了解流量（例如瀏覽頁數、裝置類型、大概地區）。不會用來識別你個人。
  • Cookie：GA4 及瀏覽器可能設定分析用 Cookie；你可於瀏覽器停用 Cookie。
  • 錯誤回報：如你主動使用「回報」功能，只會收到你填寫的內容，用於改善網站。
  • 本站不需要註冊，亦不會要求你提供姓名、電話等個人資料。

2. Google API 的使用（YouTube Data API）

  • 我們使用 YouTube Data API v3，將我們自己製作的 DSE 教學影片上傳到我們自己的 YouTube 頻道（品牌頻道「dr. hkdse」）。
  • 此用途只涉及我們自己的 Google 帳戶，不會讀取、收集或存取任何網站使用者的 Google／YouTube 資料。
  • 我們不會透過 Google API 取得你的個人資料，亦不會代你發佈任何內容。
  • 本應用對 Google API 取得資料的使用，遵從 Google API Services User Data Policy（包括 Limited Use 要求）。

3. 資料分享

我們不會出售、出租或交換你的個人資料。除法律要求外，不會向第三方披露。

4. 第三方服務

本站使用 Google Analytics（Google LLC）及 YouTube（Google LLC）之嵌入／API。其資料處理受 Google 私隱政策約束。

5. 你的選擇

你可於瀏覽器封鎖或刪除 Cookie；亦可使用 Google 的 Analytics 停用工具。

6. 兒童

本站為學習資源，並非針對 13 歲以下兒童收集個人資料。

7. 聯絡我們

如對本政策有任何查詢：dr.hkdse@gmail.com
