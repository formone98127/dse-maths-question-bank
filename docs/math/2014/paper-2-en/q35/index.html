Question

Let $f(x) = 3x^2 - 6x + k$, where $k$ is a constant. If the $y$-coordinate of the vertex of the graph of $y = f(x)$ is 7, then $k =$

  • A. 1.
  • B. 3.
  • C. 4.
  • D. 10.

Answer

Correct answer: D. 10

深度分析

一元二次函數頂點坐標　認知層次：應用　建議作答 90 秒

核心公式／定理：$y = ax^2 + bx + c$、$y_{vertex} = c - \frac{b^2}{4a}$

提示 1（啟發）
二次函數 $y=ax^2+bx+c$ 的頂點橫坐標公式為 $x = -\frac{b}{2a}$，請先求出頂點的 $x$ 值。
提示 2（知識）
將求得的頂點 $x$ 值代入原方程式 $f(x)$，即可得到該頂點的 $y$ 座標表達式（含常數 $k$）。
提示 3（破題）
題目已知頂點的 $y$ 坐標為 $7$，請建立等式求解未知數 $k$。

誘答項逆向工程

A

計算粗心　頂點 y 坐標計算錯誤

學生可能算出 a=3, b=-6, c=k。代入公式時，誤將 -b²/4a 算成 -(36)/12 = -3，然後 k-3=7 解得 k=10，卻不小心漏掉負號或計算錯誤變成 k+3=7 -> k=4 (選 C)；若直接代入頂點 x=1 到原式 f(1)=3-6+k=k-3，令其等於 7 時算錯成 k=1。
B

計算粗心　頂點 y 坐標計算錯誤

學生正確找到頂點 x=1，代入得 f(1)=k-3。若誤認為頂點 y 值為 k+3，則 k+3=7 -> k=4 (選 C)。或是在計算 -b²/4a 時，將分母 4a=12 與分子 b²=36 相除得 3，忘記負號，導致方程變成 k+3=7，解出 k=4。若學生算錯成 k-9=7 -> k=16 無選項。另一可能：學生將頂點 y 坐標公式記錯為 c+b²/4a，則 k+3=7->k=4 (選 C)。若學生誤以為頂點 y 是 -b/2a = 1，然後代入 f(1)=7 算錯。
C

計算粗心　頂點 y 坐標計算錯誤

學生正確找到頂點 x=1，代入得 f(1)=k-3。若誤將公式記為 $y = c + \frac{b^2}{4a}$，則 $k + \frac{36}{12} = k+3 = 7$，解得 $k=4$。這是常見的符號記憶錯誤。
D　✓ 正確答案

速解策略：先求頂點 x=-b/2a=1，代入 f(1)=3-6+k=k-3，令 k-3=7，解得 k=10。
