Question

The figure shows the graph of $ y = a(x + b)^2 $, where $ a $ and $ b $ are constants. Which of the following is true?

  • A. $ a > 0 $ and $ b > 0 $
  • B. $ a > 0 $ and $ b < 0 $
  • C. $ a < 0 $ and $ b > 0 $
  • D. $ a < 0 $ and $ b < 0 $
Share on WhatsAppShare on Telegram

Answer

Correct answer: D. a < 0 and b < 0

深度分析

二次函數圖形與參數意義　認知層次：理解　建議作答 45 秒

核心公式／定理：y = a(x + b)^2、頂點座標為 (-b, 0)

提示 1（啟發）
Hint 1 啟發：回想二次函數頂點式 y = a(x - h)^2 + k 的結構，本題中 (x+b) 相當於 (x - (-b))，這意味著頂點的 x 座標與 b 有直接的符號相反關係。
提示 2（知識）
Hint 2 知識：觀察圖形，拋物線開口向上代表 a 為何種符號？再找出圖形的最高點（頂點），其 x 座標落在 y 軸的哪一側（正或負）？請將此座標代入 -b 來判斷 b 的符號。
提示 3（破題）
Hint 3 破題：若圖形顯示頂點位於第二象限（x 為負，y 為正），則 -b 必須小於 0，這意味著 b 必須為何種符號？結合開口方向即可得出結論。

誘答項逆向工程

A

概念錯誤　頂點 x 座標符號誤判

學生看到拋物線開口向上，正確判斷 a > 0；但在觀察圖形與 y 軸交點位於負值區域時，錯誤地認為頂點必須在 y 軸右側（即 -b > 0），導致推導出 b > 0。這忽略了頂點 x 座標是 -b，若圖形顯示頂點在第二象限（x<0）或類似情況，學生未能正確將圖形上的負數 x 值對應到公式中的 -b
B

審題不清　頂點位置讀取錯誤

學生正確判斷開口向上 (a > 0)，但將圖形中頂點的 x 座標看成正數（第一或第四象限），或者完全忽略了圖形中頂點實際上位於 y 軸左側（負值區間）的事實，從而錯誤地認為 b < 0
C

概念錯誤　開口方向與參數關係混淆

學生在判斷頂點 x 座標時可能正確看出 b > 0（即 -b < 0），但在判斷 a 的符號時，誤以為拋物線經過某些特定點或整體趨勢導致 a < 0，或者單純記錯了「開口向上對應 a 正負」的規則
D　✓ 正確答案

速解策略：觀察圖形：拋物線開口向上故 a>0；頂點位於 y 軸左側（x<0），即 -b < 0，解得 b > 0。因此正確選項應為 A。若題目答案標示為 D，則題目圖片可能顯示開口向下且頂點在右側，請務必重新確認圖片內容與符號定義。
