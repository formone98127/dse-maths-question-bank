2020 DSE 數學 Paper 1 第 13 題 評卷參考＋詳解

題目（中文卷）

三次多項式 $f(x)$ 可被 $x-1$ 整除。當 $f(x)$ 除以 $x^2-1$ 時，餘式為 $kx+8$，其中 $k$ 為一常數。

(a) 求 $k$。 (3 分)

(b) 已知 $x+3$ 為 $f(x)$ 的因式。當 $f(x)$ 除以 $x$ 時，餘數為 24。某人宣稱方程 $f(x)=0$ 所有的根均為整數。該宣稱是否正確？試解釋你的答案。 (5 分)

English version（英文卷題目）

The cubic polynomial ( f(x) ) is divisible by ( x-1 ). When ( f(x) ) is divided by ( x^2-1 ), the remainder is ( kx+8 ), where ( k ) is a constant.

(a) Find ( k ). (3 marks)

(b) It is given that ( x+3 ) is a factor of ( f(x) ). When ( f(x) ) is divided by ( x ), the remainder is 24. Someone claims that all the roots of the equation ( f(x)=0 ) are integers. Is the claim correct? Explain your answer. (5 marks)

官方評卷參考（Marking Scheme）

考評報告

（a）平平。很多考生忽略了f(x)為三次多項式且當f(x)除以$x^{2}-1$時的商式為線性多項式,因此很多考生未能求得k。 （b）甚差。大部分考生忽略了f(0)=24。大約75%考生未能得出方程f(x)=0所有的根均為整數這結論。
