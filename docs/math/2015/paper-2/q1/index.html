題目

$(x+1)(x^2+x+1)=$

  • A. $x^3+1$
  • B. $(x+1)^3$
  • C. $x^3+x^2+x+1$
  • D. $x^3+2x^2+2x+1$

深度分析

多項式乘法　認知層次：應用　建議作答 45 秒

核心公式／定理：(a+b)(c+d) = ac + ad + bc + bd

提示 1（啟發）
提示 1：回想多項式乘法的定義，即每個括號內的項都要與另一個括號內的每一項相乘。
提示 2（知識）
提示 2：先計算 x * (x^2+x+1)，再計算 1 * (x^2+x+1)，將兩部分結果相加。
提示 3（破題）
提示 3：合併同類項後，檢查 x^2 與 x 的係數是否為 2。

誘答項逆向工程

A

概念錯誤　誤用立方和公式

學生看到 (x+1) 與 (x^2+x+1)，錯誤地認為這是立方和公式 a^3+b^3=(a+b)(a^2-ab+b^2) 的變體，直接寫出 x^3+1。
B

概念錯誤　混淆冪運算與乘法

學生誤以為兩個因式相乘等於將括號內各項分別立方，即 (x+1)^3，完全忽略了多項式乘法的本質。
C

計算粗心　漏算交叉項

學生在展開時，正確計算了 x*x^2 與 1*1 等部分，但遺漏或錯誤合併了 x*x 與 1*x^2 的係數，導致結果簡化錯誤。
D　✓ 正確答案

速解策略：展開 (x)(x^2+x+1) + 1(x^2+x+1)，合併同類項得 x^3+2x^2+2x+1。
