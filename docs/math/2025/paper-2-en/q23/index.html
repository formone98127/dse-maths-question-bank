Question

The figure shows the quadrilateral $ABCD$. If $\angle ABC + \angle ADC = \angle ACD = \angle BAC = 90^\circ$, which of the following must be true?

  • A. $\tan \angle ACB = \dfrac{AB}{AD}$
  • B. $\tan \angle ACB = \dfrac{AB}{CD}$
  • C. $\tan \angle ADC = \dfrac{BC}{AD}$
  • D. $\tan \angle ADC = \dfrac{BC}{CD}$

Answer

Correct answer: C. \tan \angle ADC = \dfrac{BC}{AD}

深度分析

幾何相似與三角比　認知層次：分析　建議作答 120 秒

核心公式／定理：$\tan \theta = \frac{對邊}{鄰邊}$、$\triangle ABC \sim \triangle CAD$

提示 1（啟發）
觀察題目條件：$\angle ABC+\angle ADC=90^\circ$ 且 $\angle ACD=\angle BAC=90^\circ$，這暗示了兩個直角三角形之間可能存在相似關係。
提示 2（知識）
確認 $\triangle ABC$ 與 $\triangle CAD$（注意頂點順序）是否相似？若相似，請寫出對應的邊比例式。
提示 3（破題）
利用正切定義：在直角三角形中，某角的正切值等於對邊除以鄰邊。將相似比代入即可驗證選項。

誘答項逆向工程

A

概念錯誤　混淆相似比對應邊

學生可能認為 $\tan \angle ACB$ 在 $\triangle ABC$ 中為 $AB/AC$，但題目選項給出 $AD$。若誤判相似比例關係，會將 $AC$ 錯換成 $AD$
B

概念錯誤　混淆斜邊與直角邊

學生正確算出 $\tan \angle ACB = AB/AC$，但誤以為 $AC=CD$ 或因圖形直觀誤判 $AC$ 與 $CD$ 長度關係而選此項
C　✓ 正確答案
D

計算粗心　相似三角形對應邊寫錯

學生能推導出 $\tan \angle ADC = AC/CD$，但在將比例式轉換時計算錯誤，或誤以為 $BC/CD$ 是正確比例

速解策略：證明 $\triangle ABC \sim \triangle CAD$，得對應邊比例 $\frac{BC}{AD}=\frac{AC}{CD}$，而 $\tan \angle ADC=\frac{AC}{CD}$，故選 C。
