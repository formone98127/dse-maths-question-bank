Question

Let ( f(x) = 4x^3 - 5x^2 - 18x + c ), where ( c ) is a constant. When ( f(x) ) is divided by ( x - 2 ), the remainder is (-33).

(a) Is ( x + 1 ) a factor of ( f(x) )? Explain your answer.

(b) Someone claims that all the roots of the equation ( f(x) = 0 ) are rational numbers. Do you agree? Explain your answer. (5 marks)

深度分析

多項式　認知層次：應用　建議作答 120 秒

核心公式／定理：P(a) = 0 \iff (x-a)\text{是}P(x)\text{的因式}、有理數定義：可表示為\frac{p}{q}\text{之整數比}

提示 1（啟發）
先由 f(2)=-33 解出 c 的數值。
提示 2（知識）
因式定理：若 x=a 是根，則 (x-a) 是因式；反之亦然。
提示 3（破題）
有理數包含所有整數及有限小數、循環小數（如 -3/4）。

速解策略：先求 c，再代 x=-1 驗算因式；解方程得根後檢查分母是否為 0 且分子分母整除。
