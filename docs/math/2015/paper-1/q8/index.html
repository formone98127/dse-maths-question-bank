題目

圖 1 中，$ABCD$ 為一圓。$E$ 為 $AC$ 上的一點使得 $BC=CE$。已知 $AB=AD$、$\angle ADB=58^\circ$ 及 $\angle CBD=25^\circ$。

求 $\angle BDC$ 及 $\angle ABE$。

深度分析

圓的性質　認知層次：應用　建議作答 240 秒

核心公式／定理：圓內接四邊形對角互補：$\angle A + \angle C = 180^\circ$、等腰三角形底角相等、同弧所對圓周角相等

提示 1（啟發）
提示 1：先由 $AB=AD$ 和圓內接四邊形性質推導 $\angle C$ 的數值。
提示 2（知識）
提示 2：在 $\triangle BCD$ 中，已知兩角可求第三角 $\angle BDC$。
提示 3（破題）
提示 3：注意題目給的是 $BC=CE$，故 $\triangle BCE$ 是等腰三角形，頂點為 $C$

速解策略：先由 $AB=AD$ 得 $\angle ABD = \angle ADB = 58^\circ$，再求 $\angle A$ 及 $\angle C$；接著在 $\triangle BCD$ 求 $\angle BDC$；最後利用 $BC=CE$ 求 $\angle CBE$，再由圓內接四邊形外角性質得 $\angle ABE$
