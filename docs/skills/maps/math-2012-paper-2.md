# 2012 數學卷二 · 技能地圖

由已掛好嘅 `skills` 編號統計。唔係學生答題紀錄——係「呢一卷出題人預埋嘅陷阱地圖」。

- 題數：**45**
- 錯選項（陷阱）總數：**135**（平均每題 3.0 個）
- 預計作答時間：最短 45 秒 · 中位 60 秒 · 最長 180 秒 · 平均 69 秒

## 一眼睇完

1. **最多題嘅課題**：數系（5）、統計（4）、求積法（4）、圓形幾何（4）。
2. **錯選項最常指向嘅能力**：代數變形、計算仔細度、睇條件——合共佔大多數陷阱。
3. **錯選項最常踩中嘅知識點**：二次函數頂點與開口、平面圖形面積、展開與合併、不等式、弧長與扇形。
4. **錯誤類型**：概念 62、計算 50、睇題 15、方法 8（一個錯選項一個類型）。
5. **大多數題疊 2 個知識點**（29 題）；淨用 1 個嘅有 14 題；3 個嘅只有 2 題。
