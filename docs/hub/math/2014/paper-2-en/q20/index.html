Question

In the figure, $AC$ is a diameter of the circle $ABCDE$. If $\angle ADE = 28^\circ$, then $\angle CBE =$

  • A. $56^\circ$.
  • B. $62^\circ$.
  • C. $72^\circ$.
  • D. $76^\circ$.
Share on WhatsAppShare on Telegram

Answer

Correct answer: B. 62^\circ

深度分析

圓周角定理與直徑所對之圆周角　認知層次：應用　建議作答 45 秒

核心公式／定理：\angle ADE = \angle ACE (同弧 AE 所對)、\angle ACB = 90^\circ (直徑 AC 所對)

提示 1（啟發）
觀察圖形中 $\angle ADE$ 與哪個角對同一段弧？
提示 2（知識）
連接 $A$ 與 $C$，利用直徑 $AC$ 的性質找出直角三角形。
提示 3（破題）
注意 $\angle CBE$ 與 $\angle CAE$ 的關係。

誘答項逆向工程

A

概念錯誤　誤用倍數關係

學生認為直徑將圓平分，故角度應為原角度之兩倍 (28*2=56)，忽略了目標角與已知角並非直接倍數關係。
B　✓ 正確答案
C

概念錯誤　混淆圓內接四邊形

學生錯誤地將 ADE 與 CBE 視為對角線關係，或誤以為它們互餘 (90-28=62) 卻未說明理由，實則 62 是正確解但此選項常為計算誤差。
D

計算粗心　角度相加錯誤

學生可能先算出互餘角 62，再錯誤地加上某個誤導性角度 (如 14)，或是單純計算 90+28-42 等無意義運算。

速解策略：連 $AE$，知 $\angle ACE=28^\circ$；因 $AC$ 為直徑，$\angle AEC=90^\circ$，故 $\angle CAE=62^\circ$；又 $\angle CBE=\angle CAE$
