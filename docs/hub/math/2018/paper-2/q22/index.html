題目

圖中，$ABCD$ 為一圓。$AD$ 的延線與 $BC$ 的延線相交於點 $E$。已知 $BD = DE$、$\angle BAC = 66^\circ$ 及 $\angle ABD = 30^\circ$。求 $\angle CED$。

  • A. $20^\circ$
  • B. $28^\circ$
  • C. $36^\circ$
  • D. $42^\circ$

深度分析

圓的性質與三角形幾何　認知層次：分析　建議作答 90 秒

核心公式／定理：等腰三角形底角相等、圓內接四邊形外角等於內對角、三角形內角和為 180°

提示 1（啟發）
觀察圖形中 $BD = DE$，這意味著 $\triangle BDE$ 是什麼種三角形？
提示 2（知識）
在圓 $ABCD$ 中，$\angle CED$ 是四邊形的哪個角的外角？它與哪個內角相等？
提示 3（破題）
先利用等腰三角形求出 $\angle EDB$，再結合圓內接性質求出 $\angle CED$

誘答項逆向工程

A

計算粗心　角度計算錯誤

算出∠ADB=78°後，誤以為∠CED=180-78-66=36°（錯用三角形內角和），或將 78-66 算成 20°。
B　✓ 正確答案
C

概念錯誤　混淆圓內接性質

誤以為∠CED 直接等於∠ABD 的餘角，或錯誤應用圓內接四邊形外角定理，導致算出 36°。
D

審題不清　忽略已知條件

只注意到∠BAC=66°與∠ABD=30°，完全忽略 BD=DE 這個關鍵等腰條件，直接猜測或亂算。

速解策略：由 $BD=DE$ 得 $\triangle BDE$ 為等腰；由圓內接性質得 $\angle CED = \angle ABD$。
