Question

The solution of $\dfrac{1-x}{2} \ge 4$ or $7+5x \le -3$ is

  • A. $x \le -7$.
  • B. $x \le -2$.
  • C. $-7 \le x \le -2$.
  • D. $x \le -7$ or $x \ge -2$.
Share on WhatsAppShare on Telegram

Answer

Correct answer: B. x \le -2

深度分析

一元一次不等式　認知層次：應用　建議作答 45 秒

核心公式／定理：$\frac{a}{b} \geq c \implies a \geq bc$ (當 $b>0$)、$A \text{ 或 } B \iff A \cup B$

提示 1（啟發）
請先單獨解開第一個不等式 $\frac{1-x}{2} \geq 4$，求出 $x$ 的範圍。
提示 2（知識）
接著請單獨解開第二個不等式 $7 + 5x \leq -3$，同樣找出 $x$ 的範圍。
提示 3（破題）
題目中的「或」代表集合的並集（Union），請將上述兩個範圍合併寫出最終答案。

誘答項逆向工程

A

計算粗心　忽略第二個不等式解集

學生正確解出 $x \leq -7$，但完全遺漏處理 $7+5x \leq -3$ 這部分，導致只寫下其中一個解集。
B　✓ 正確答案
C

概念錯誤　混淆「或」與「且」的邏輯

學生誤以為不等式由「或」連接時，解集應取交集（$\cap$），將兩個範圍重疊起來寫成 $-7 \leq x \leq -2$。
D

審題不清　誤解「或」的集合意義

學生正確算出兩個解集，但錯誤地認為「或」意味著必須將答案寫成「A 或 B」的文字形式，而非數學上的並集符號。

速解策略：分別解兩邊不等式得 $x \leq -7$ 與 $x \leq -2$，取兩者之並集即為 $x \leq -2$
