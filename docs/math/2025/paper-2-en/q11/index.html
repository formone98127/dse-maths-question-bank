題目

If $ \alpha $, $ \beta $ and $ \gamma $ are non-zero constants such that $ (\alpha + 2\beta) : (\beta + 2\gamma) : (\gamma + 2\alpha) = 4 : 9 : 5 $, then $ \alpha : \beta = $

  • A. $2 : 5$
  • B. $5 : 2$
  • C. $128 : 149$
  • D. $149 : 128$

深度分析

比例與代數方程式　認知層次：分析　建議作答 90 秒

核心公式／定理：\frac{a}{b} = \frac{c}{d}、k(\alpha + 2\beta) = 4k

提示 1（啟發）
設\alpha + 2\beta = 4k, \beta + 2\gamma = 9k, \gamma + 2\alpha = 5k，將三個式子視為線性系統。
提示 2（知識）
觀察變量\gamma出現在第二、第三式，嘗試用前兩式消去\gamma以建立\alpha與\beta的關係。
提示 3（破題）
將得到的\alpha與\beta關係式化簡為最簡整數比，並檢查是否符合題目給定的比例條件。

誘答項逆向工程

A　✓ 正確答案
B

概念錯誤　比例倒置誤解

學生可能混淆了\alpha:\beta與\beta:\alpha的順序，或是將4:9與5:2錯誤配對導致比值得出反號。
C

計算粗心　計算錯誤

在消去\gamma或解聯立方程式時，學生可能將9與5相乘或加法運算出錯，導致數值偏差。
D

計算粗心　計算錯誤

學生可能正確列出方程式但解\alpha與\beta時，分母分子顛倒或符號處理不當。

速解策略：設參數k，列三元一次方程式組，消去\gamma後解\alpha:\beta之比值。
