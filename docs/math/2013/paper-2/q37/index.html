題目

考慮以下的不等式組：

$\begin{cases}x\ge 2\ y\ge 0\ x+4y\le 22\ 4x-y\le 20\end{cases}$

設 $D$ 為表示以上的不等式組的解之區域。若 $(x,y)$ 為 $D$ 中的一點，則 $3y-4x+15$ 的最大值為

  • A. $3$。
  • B. $17$。
  • C. $22$。
  • D. $30$。

深度分析

線性規劃　認知層次：應用　建議作答 90 秒

核心公式／定理：直線方程式 $Ax + By = C$、兩直線交點座標公式、目標函數 $Z = 3y - 4x + 15$

提示 1（啟發）
線性規劃問題中，目標函數的最大值通常出現在可行域的頂點上。
提示 2（知識）
請先繪製或描繪出由四個不等式所圍成的多邊形區域 $D$。
提示 3（破題）
找出該多邊形的所有頂點座標，並分別代入目標函數 $3y-4x+15$ 計算。

誘答項逆向工程

A

審題不清　忽略常數項影響

學生算出頂點座標後，僅計算 $3y-4x$ 部分（如得 -12），忘記加上 +15，或誤以為最大值為 0。
B

計算粗心　頂點代入錯誤

正確找出區域頂點 $(5,4)$，但在計算 $3(4)-4(5)+15$ 時算錯，例如 $12-20+15=7$ 或 $12-20=-8$ 加錯了。
C　✓ 正確答案
D

概念錯誤　誤解最大值位置

學生錯誤認為目標函數係數絕對值較大者對應的頂點（$x$ 軸方向）才是最大值，忽略斜率影響。

速解策略：繪製可行域找頂點，代入 $3y-4x+15$ 比較大小。
