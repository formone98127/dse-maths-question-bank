Question

The graph in the figure shows the linear relation between $x$ and $\sqrt{y}$. Which of the following must be true? [FIGURE Q33: Cartesian coordinate system graph. Axes labeled x and y. Points marked: (0, √8) and (4, 0). No dashed lines, right-angle marks, or shading.]

  • A. $y = x^2 - 4x + 8$
  • B. $y = x^2 + 4x + 8$
  • C. $y =4x^2 - 32x + 64$
  • D. $y =4x^2 + 32x + 64$

Answer

Correct answer: C. y =4x^2 - 32x + 64

深度分析

函數圖形與二次方程式　認知層次：分析　建議作答 120 秒

核心公式／定理：若 $ u = \sqrt{y} $ 與 $ x $ 成線性，則 $ u = mx + c $

提示 1（啟發）
觀察題目敘述：$ x $ 與 $ \sqrt{y} $ 成線性關係，這意味著它們滿足一次函數的形式 $ \sqrt{y} = mx + c $。
提示 2（知識）
從圖形中找出兩個清晰的點（例如截距點和另一個整數點），計算出斜率 $ m $ 與 $ y $ 軸截距 $ c $ 的數值。
提示 3（破題）
將求得的 $ m $ 與 $ c $ 代入 $ \sqrt{y} = mx + c $，接著對等式兩邊平方並展開，即可得到 $ y $ 關於 $ x $ 的二次方程式。

誘答項逆向工程

A

計算粗心　符號錯誤

學生算出斜率為 -4，但截距計算錯誤。將 $x=0$ 代入圖形得 $\sqrt{y}=2$，卻誤算成其他數值，導致常數項不對。
B

概念錯誤　斜率符號混淆

學生正確讀取截距為 2，但看錯圖形趨勢，將負斜率誤認為正斜率，因此選出 $+4x$ 的選項。
C　✓ 正確答案
D

計算粗心　截距計算錯誤

學生算出斜率正確為 -4，但將圖形中 $x=0$ 時的 $\sqrt{y}$ 值誤讀或誤算為 8，導致常數項變成 64。

速解策略：由圖得 $\sqrt{y}=-4x+8$，兩邊平方即得答案。
