題目

圖中，$AB$ 為立於水平地面 $BCD$ 上的鉛垂柱，其中 $\angle CBD=90^\circ$。若平面 $ACD$ 與水平地面間之交角為 $\theta$，則 $\tan\theta=$

  • A. $\dfrac{8}{15}$。
  • B. $\dfrac{15}{8}$。
  • C. $\dfrac{15}{17}$。
  • D. $\dfrac{17}{15}$。

深度分析

三維幾何與平面夾角　認知層次：應用　建議作答 90 秒

核心公式／定理：$\tan \theta = \frac{對邊}{鄰邊}$

提示 1（啟發）
二面角的平面角是由兩個半平面內分別垂直於交線且相交於一點的兩條射線所成的角。
提示 2（知識）
在 $\triangle ACD$ 中，需從點 $A$ 向交線 $CD$ 作垂線，設垂足為 $E$，則 $\angle AED$ 即為所求平面角 $\theta$。
提示 3（破題）
利用三維坐標系或空間想像：因 $AB \perp$ 地面，故 $BE$ 為 $A$ 在底面的射影；由三垂線定理逆定理，$AE \perp CD$ 時，$BE \perp CD$。

誘答項逆向工程

A

概念錯誤　混淆二面角與線面夾角

誤將 $\triangle ABC$ 中的 $\tan C = \frac{AB}{BC} = \frac{8}{15}$ 當作答案，忽略了需作垂線找平面角。
B

概念錯誤　混淆二面角與線面夾角

同樣計算了 $\triangle ABC$ 的 $\tan C = \frac{8}{15}$，但選項給成倒數或誤讀比例關係。
C

計算粗心　勾股定理計算錯誤

正確識別需作垂線，但在計算 $AD$ 長度時算錯，例如誤以為 $AD=17$ 是鄰邊或計算斜邊出錯。
D　✓ 正確答案

速解策略：作 $AE \perp CD$ 於 $E$，連 $BE$。因 $AB \perp$ 地面，由三垂線定理知 $BE \perp CD$。在 Rt$\triangle BCE$ 中求 $BE$，再在 Rt$\triangle ABE$ 中求 $AE$，最後 $\tan \theta = AE/BE$
