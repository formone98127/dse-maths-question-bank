題目

若 $\alpha$ 及 $\beta$ 均為常數使得 $(x-8)(x+\alpha)-6\equiv(x-9)^2+\beta$，則 $\beta=$

  • A. $-26$
  • B. $-10$
  • C. $-7$
  • D. $-6$

深度分析

恆等式展開與係數比較　認知層次：分析　建議作答 45 秒

核心公式／定理：(x-a)(x+b) = x^2 + (b-a)x - ab、(x-c)^2 = x^2 - 2cx + c^2

提示 1（啟發）
提示 1：恆等式兩邊展開後，對應次數的係數必須相等，請先將左邊與右邊分別展開成 $x^2 + bx + c$ 的形式。
提示 2（知識）
提示 2：利用完全平方公式 $(x-9)^2 = x^2 - 18x + 81$，比較兩邊的 $x$ 係數可求出 $\alpha$ 的值。
提示 3（破題）
提示 3：將求得的 $\alpha$ 代入左邊展開式，再與右邊常數項比較，即可解出 $eta$。

誘答項逆向工程

A

計算粗心　展開符號錯誤

將 (x-8)(x+alpha) 展開時，把 -6 錯加到常數項或完全平方展開時 x^2 係數算錯，導致最終 beta 值偏差過大。
B

計算粗心　忽略 -6 的影響

正確展開兩邊後，忘記了左邊的 -6，直接比較常數項，導致 beta 比正確值小 6。
C　✓ 正確答案
D

審題不清　看錯題目符號

將題目中的 -6 看成正 6，或者在比較常數項時，誤以為 beta 是絕對值差而非代數和。

速解策略：展開兩邊，比較 $x$ 係數得 $\alpha=-10$，再比較常數項：$-80-6 = 81 + eta$
