題目

求常數 $k$ 使得圓 $x^2+y^2+2x-6y+k=0$ 與直線 $x+y+4=0$ 只相交於一點。

  • A. $-16$
  • B. $-8$
  • C. $8$
  • D. $16$
WhatsApp 分享Telegram 分享

深度分析

圓與直線的相切條件　認知層次：應用　建議作答 90 秒

核心公式／定理：$ (x-h)^2 + (y-k)^2 = r^2 $、$ d = \frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}} $

提示 1（啟發）
將圓的一般方程式配方成標準式 $(x-h)^2+(y-k)^2=r^2$，找出圓心與半徑平方。
提示 2（知識）
回憶圓與直線相交於一點的條件：圓心到直線的距離等於半徑。
提示 3（破題）
建立等式 $d^2 = r^2$ 並解出常數 $k$，注意半徑必須為正實數。

誘答項逆向工程

A

計算粗心　符號錯誤導致距離平方誤算

學生算出圓心到直線距離為 $\sqrt{16}$，但將 $k$ 代入時忘記了圓半徑平方公式中 $-2k$ 的係數關係，或混淆了 $d^2=r^2$ 與 $d^2=r^2-k$ 的關係，導致算出 $-16$
B　✓ 正確答案
C

概念錯誤　忽略圓心座標的正負號影響

學生正確算出距離平方為 16，但未能將圓半徑 $r^2 = 8-k$ 與距離平方等式聯立時，正確處理 $k$ 的符號，誤以為 $k=8$
D

審題不清　未將圓方程式配方即直接使用係數

學生直接取 $x^2+y^2+2x-6y+k=0$ 中的 $k$ 當作半徑平方，忽略配方後常數項變化，且計算距離時未考慮圓心 $( -1, 3)$ 的符號

速解策略：配方得圓心 $(-1,3)$，半徑平方 $8-k$；計算距離平方等於半徑平方即得 $k=-8$
