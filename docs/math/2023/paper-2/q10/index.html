題目

下列有關 $y=5+(x-3)^2$ 的圖像之敘述，何者正確？

  • A. 該圖像開口向下。
  • B. 該圖像的 $x$ 截距為 $3$。
  • C. 該圖像的 $y$ 截距為 $5$。
  • D. 該圖像通過點 $(3,5)$。

深度分析

二次函數圖形性質　認知層次：理解　建議作答 45 秒

核心公式／定理：$y=a(x-h)^2+k$、$x$ 截距：令 $y=0$ 解 $x$、$y$ 截距：令 $x=0$ 解 $y$

提示 1（啟發）
二次函數頂點式 $y=a(x-h)^2+k$ 中，參數 $a$ 決定開口方向與寬窄。
提示 2（知識）
$y$ 截距是圖形與 $y$ 軸交點，需令 $x=0$；$x$ 截距是圖形與 $x$ 軸交點，需令 $y=0$。
提示 3（破題）
將 $x=3$ 代入方程式中，觀察計算結果是否等於 $5$，即可驗證該點是否在圖形上。

誘答項逆向工程

A

概念錯誤　係數符號誤判

學生看到平方項 $(x-3)^2$，忽略 $a=1$ 為正數，誤以為任何二次函數開口皆向下或混淆了 $y=-x^2$ 的形式。
B

計算粗心　解方程錯誤

學生令 $y=0$ 得 $(x-3)^2=-5$，誤判無實根或隨意猜測 $x=3$ 是截距，未計算出實際 $x$ 截距為 $3 \pm \sqrt{5}$。
C

審題不清　代入值錯誤

學生直接將 $x=0$ 代入時，忽略括號內的 $-3$，誤算為 $y=5+(0)^2=5$，未計算 $(0-3)^2=9$。
D　✓ 正確答案

速解策略：比較頂點式參數與選項描述，直接代入特殊點 $(3, k)$ 或令 $x=0$ 驗證截距。
