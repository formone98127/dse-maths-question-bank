題目

點 $A$ 及點 $B$ 的坐標分別為 $(-3,4)$ 及 $(9,-9)$。$A$ 繞原點逆時針方向旋轉 $90^\circ$ 至 $A'$。$B'$ 為 $B$ 對 $x$ 軸的反射影像。

(a) 寫出 $A'$ 及 $B'$ 的坐標。

(b) 證明 $AB$ 垂直於 $A'B'$。 (4 分)

深度分析

微分法　認知層次：應用　建議作答 300 秒

核心公式／定理：$f'(x) = 12x^2 + 2mx + n$、$f''(x) = 24x + 2m$

提示 1（啟發）
Hint1: 轉折點處切線水平，故 $f'(x)=0$。
提示 2（知識）
Hint2: 記得將點座標代入原函數求 $y$ 值關係。
提示 3（破題）
Hint3: 二階導數大於零為極小，小於零為極大。

速解策略：先求導令 $f'(6)=0$ 得一方程，再代點入原函數得另一方，聯立解出係數後判別極值。
