Question

If $h=3-\dfrac{5}{k+4}$, then $k=$

  • A. $\dfrac{4h-7}{3-h}$.
  • B. $\dfrac{4h-17}{3-h}$.
  • C. $\dfrac{4h-7}{3+h}$.
  • D. $\dfrac{4h-17}{3+h}$.

Answer

Correct answer: A. \dfrac{4h-7}{3-h}

深度分析

一元一次方程式變形　認知層次：分析　建議作答 45 秒

核心公式／定理：$a - \frac{b}{c} = d \Rightarrow a-d = \frac{b}{c}$、$\frac{x}{y} = z \Rightarrow x = zy$

提示 1（啟發）
提示 1：首先嘗試將等式左邊的 $h$ 移到右邊，或是將分數項單獨處理。
提示 2（知識）
提示 2：觀察分母 $(k+4)$，若要解出 $k$，下一步應消除分母，兩邊同時乘以 $(k+4)$。
提示 3（破題）
提示 3：整理後的式子形如 $A = \frac{B}{C}$，請將 $C$ 乘到左邊，並小心處理 $h$ 的符號變化。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　分母符號處理錯誤

移項後將 $3-h$ 視為 $(3-h)$，但在乘回時忘記了 $h$ 的負號應變為正，導致分子最後一項變成 $-17$
C

計算粗心　分母符號處理錯誤

移項後將 $3-h$ 視為 $(3+h)$，在乘回時完全搞錯 $h$ 的符號方向，導致分母變成加號
D

計算粗心　分母符號處理錯誤

同時犯下分母與分子符號錯誤，既將 $3-h$ 視為 $(3+h)$ 又算錯分子常數項

速解策略：移項得 $k+4=\frac{5}{3-h}$，再乘分母整理分子即得答案。
