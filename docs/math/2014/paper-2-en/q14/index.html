Question

Let $a_n$ be the $n$th term of a sequence. If $a_2 = 7$, $a_4 = 63$ and $a_{n+2} = a_{n+1} + a_n$ for any positive integer $n$, then $a_5 =$

  • A. 56.
  • B. 70.
  • C. 91.
  • D. 119.

Answer

Correct answer: D. 119

深度分析

線性遞迴關係 (Fibonacci 類)　認知層次：應用　建議作答 45 秒

核心公式／定理：$a_{n+2} = a_{n+1} + a_n$

提示 1（啟發）
根據題目給出的遞迴公式 $a_{n+2}=a_{n+1}+a_n$，我們需要找出缺少的中間項 $a_3$。
提示 2（知識）
利用已知條件 $a_4=63$ 和剛求出的 $a_3$，代入公式計算 $a_5 = a_4 + a_3$。
提示 3（破題）
將計算結果與選項比對，確認哪一個數值符合邏輯推導。

誘答項逆向工程

A

計算粗心　錯用 a3=a2+a1 或計算錯誤

學生可能誤以為 a3=7+63=70，然後直接選 B；或是算出 a3 後，求 a5 時跳過步驟直接加錯數值。
B

計算粗心　計算 a3 錯誤或混淆 a4 與 a5

學生算出 a3=70 後，誤以為題目問的就是 a3 的值，或是將 a4 的條件看錯當作答案。
C

概念錯誤　忽略遞迴關係的連續性

學生正確算出 a3=70，但在求 a5 時跳過 a4，錯誤地將 a3 與 a4 相加 (70+63=133) 或其他組合導致 91。
D　✓ 正確答案

速解策略：先由 $a_4=a_3+a_2$ 解出 $a_3=56$，再算 $a_5=a_4+a_3=119$
