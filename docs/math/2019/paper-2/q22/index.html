題目

圖中，$ABCD$ 為一長方形。$E$ 為 $AD$ 上的一點。求 $\frac{CE}{AC}$。

  • A. $\frac{\sin \alpha}{\sin \beta}$
  • B. $\frac{\cos \alpha}{\cos \beta}$
  • C. $\sin \alpha \sin \beta$
  • D. $\cos \alpha \cos \beta$

深度分析

三角函數與幾何相似　認知層次：應用　建議作答 90 秒

核心公式／定理：$\cos \theta = \frac{\text{鄰邊}}{\text{斜邊}}$、$\sin \theta = \frac{\text{對邊}}{\text{斜邊}}$

提示 1（啟發）
提示 1：觀察長方形 $ABCD$ 的性質，找出與 $\alpha$、$\beta$ 相關的直角三角形。
提示 2（知識）
提示 2：分別用 $AC$ 和 $CE$ 表示出它們在各自直角三角形中的餘弦值（鄰邊比斜邊）。
提示 3（破題）
提示 3：將 $\frac{CE}{AC}$ 寫成兩個分數的比值，並利用長方形對邊相等的性質消去公共邊長。

誘答項逆向工程

A

概念錯誤　混淆正弦與餘弦定義

學生可能誤以為 $\frac{CE}{AC}$ 是對邊比斜邊，直接套用 $\sin$。但 $E$ 在 $AD$ 上，$\triangle ACE$ 中 $AE$ 是 $\angle C$ 的對邊而非 $\alpha, \beta$ 的直接對應關係，導致選錯分母或分子組合。
B　✓ 正確答案
C

計算粗心　錯誤相乘而非比對

學生可能將兩個三角函數值直接相乘，誤認為長度比例等於正弦或餘弦的積。這通常發生在沒有先建立 $CE$ 與 $AC$ 各自表達式的情況下。
D

審題不清　誤讀圖形角度標註

學生可能看錯 $\alpha$ 與 $\beta$ 的位置，將它們視為互餘角或同一角的補角，導致在構造相似比時選錯了三角函數類型（如把餘弦當成正弦）。

速解策略：在 $\triangle ACE$ 中，$AE = AC \cos \alpha$；在 $\triangle CDE$ 中，$DE = CD \sin \beta = AB \sin \beta$。利用 $AD=BC$ 及相似比構造關係。
