Question

The solution of $\dfrac{1-2x}{3}\ge x-3$ or $4x+9<1$ is

  • A. $x<-2$
  • B. $x>-2$
  • C. $x\le 2$
  • D. $x\ge 2$
Share on WhatsAppShare on Telegram

Answer

Correct answer: C. x\le 2

深度分析

一元一次不等式與集合運算　認知層次：分析　建議作答 90 秒

核心公式／定理：$ \frac{a}{b} \geq c \Rightarrow a \geq bc $ (當 $ b > 0 $)、$ A \cup B = \{ x | x \in A \text{ 或 } x \in B \} $

提示 1（啟發）
請先分別解開這兩個獨立的不等式，各得到一個解集範圍。
提示 2（知識）
注意題目中的「或」字代表解集是兩個範圍的並集（Union），而非交集。
提示 3（破題）
將兩個解集合併後，觀察哪個選項涵蓋了所有可能的 $ x $ 值。

誘答項逆向工程

A

策略錯誤　忽略不等號方向變化

解第一個不等式時，移項後忘記將 $ x $ 移到右邊或處理負數係數時未改變不等號，導致範圍錯誤。
B

計算粗心　計算誤差

正確解出第一個不等式為 $ x \leq 2 $，但將「或」關係誤解為交集，且計算第二個不等式時算錯邊界值。
C　✓ 正確答案
D

概念錯誤　混淆並集與交集

將「或」誤認為是求兩個解集的交集，且解第一個不等式時方向搞反，導致選出 $ x \geq 2 $。

速解策略：分步求解兩不等式，取並集即可。
