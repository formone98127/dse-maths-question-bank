Question

It is given that ( f(x) ) is partly constant and partly varies as ( x^2 ). Suppose that ( f(10) = 62 ) and ( f(15) = 122 ).

(a) Find ( f(5) ). (3 marks)

(b) Suppose that ( U(0, u) ) and ( V(5, v) ) are points lying on the graph of ( y = f(x) ). The horizontal line passing through ( V ) cuts the ( y )-axis at the point ( W ). Denote the circle which passes through ( U ), ( V ) and ( W ) by ( C ). Express the circumference of ( C ) in terms of ( \pi ). (4 marks) Please stick the barcode label here.

核心公式／定理：$y = ax^2 + c$、$r = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2}$

提示 1（啟發）
提示 1：題目說「一部分為常數」，代表形式必為 y = ax^2 + c。
提示 2（知識）
提示 2：將兩個已知點代入方程，得到關於 a 和 c 的二元一次方程組。
提示 3（破題）
提示 3：解出 a 和 c 後，直接代回 x=5 即可求得答案。

速解策略：設 f(x)=ax^2+c，代入 (10,62) 和 (15,122) 解得 a=4, c=-38，再求 f(5)。
