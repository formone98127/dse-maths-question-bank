呢頁程式點用

呢度收錄嘅係一套短小、同 DSE 必修部分最常手算出錯嘅課題對應嘅程式：聯立二元一次方程、二次方程、圓嘅圓心同半徑、直線與圓相交、等差同等比數列，以及已知三邊解三角形。每條程式都由基本代數從頭推導，並用獨立數值例子測試過。

程式最穩陣嘅用法，係做完列式之後先核對答案，或者喺卷二加快重複嘅算術。卷一長題仍然要寫出方法同步驟；答中數值但步驟唔全，一樣可以失分。下面亦有一個瀏覽器核對器，方便你輸入程式前後對答案——佢只供練習，唔係准用計算機。

相關課題頁：方程與不等式 · 坐標幾何：圓 · 數列 · 三角學與解三角形

考試用計算機注意

  • 只可以用考評局最新准用名單上嘅型號，而且機身要有「H.K.E.A.A. APPROVED」或「H.K.E.A. APPROVED」墊印標籤，否則有機會被扣分。帶未獲准、又可以讀取預存資料嘅計算機，甚至可能被取消資格。
  • Casio fx-50FH、fx-50FH II、fx-3650P 同 fx-3650P II 都列喺 2026 年香港中學文憑考試計算機通告（PDF） 嘅准用名單。之後年份請返 考評局網站 查最新通告，唔好沿用過期名單。
  • 准用名單包括可編程計算機。預先輸入程式係咪符合你應考嗰年嘅規則，請自己對照當年通告同《考生手冊》「考生須知」，唔好單靠呢頁嘅摘要。
  • 除姓名、班別、學號、電話等個人資料外，計算機上面唔可以寫其他字或貼標貼；套要除低放喺椅下或袋入面。
  • 電池沒電、重設或者更換電池之後，程式有可能會消失。一定要識手計方法，唔好把成場考試押喺記憶體度。

二次方程同圓心半徑另外提供，需要時可以同上面其中一條對調。二次方程嘅兩根可以用內置 FMLA 01 計，但呢頁嘅版本會一併輸出頂點同判別式。字節數係按每個指令、變數或數字大約佔 1 字節來估算，實際以機面顯示嘅剩餘容量為準。

點樣輸入、執行同刪除

以下步驟以 Casio fx-50FH II 為準，fx-3650P II 嘅程式模式擺位大致相同。若你部機嘅選單字眼同下面唔完全一樣，以機面同原廠說明書為準。

輸入新程式

  1. 按 MODE，再按 6 進入 PRGM。若第一個 MODE 畫面只有 COMP、CMPLX 等而未見 PRGM，再撳一次 MODE 睇第二頁（通常有 SD、REG、PRGM），然後按 6。
  2. 按 1（EDIT），再揀 P1、P2、P3 或 P4。新程式要揀未用過嘅空位。
  3. 揀執行模式：按 1 選 COMP。除非程式要用複數，否則不要揀 CMPLX。執行模式一經指定就不能改；要改就要刪除個位再開過。
  4. 依下面程式表輸入。換行只係為咗方便閱讀，唔使另外輸入換行符號。
  5. 完成後按 AC，或者返回 PRGM 選單。可以再睇一次實際用咗幾多字節，同下面嘅約數核對。

常用符號

  • ? 提示輸入，→ 存入變數，: 或 」 分隔指令，◢ 顯示一個數值並暫停，⇒ 條件成立先執行後面嗰句。
  • 以上符號多數喺程式指令選單輸入（P-CMD；通常係 SHIFT 3，然後按對應編號）。
  • 編輯時撳 EXE，有啲機款會插入 ◢，有啲會插入分隔符 :。若插入嘅唔係你要嘅符號，改由 P-CMD 選單揀。
  • 分隔符 : 喺部分機款可以用 a b/c 鍵輸入（螢幕或會顯示為 」）。
  • 呢幾款機只有 A、B、C、D、X、Y、M 七個字母變數，冇 E 或 F。第二條方程嘅係數要改用 D、X、Y 來裝。
  • 程式入面如果睇唔清係負號定減號，用減號鍵輸入就可以。
  • 最後一個結果通常會自動顯示，所以好多程式唔使喺最尾再加 ◢。

執行

按 MODE、6、2（RUN），揀程式位，再按 EXE。見到 ? 就輸入對應數值，每次撳 EXE。幾個輸出會按程式寫明嘅次序逐個出現，繼續撳 EXE 睇下一個。

刪除

按 MODE、6、3（DEL 或 DELETE），再揀要清空嘅程式位。刪除後不能復原。若螢幕再問確認，跟機上提示做。官方說明書亦係喺 PRGM 選單揀刪除，再指定程式區編號。

先用內置功能，唔好浪費程式位

喺 COMP 模式按 FMLA，再輸入兩位編號，已經有現成公式。下面呢幾條同必修數學最相關，無需再佔 P1–P4：

  • FMLA 01：二次方程實根。冇實根會 Math ERROR。
  • FMLA 02：餘弦公式，已知兩邊及其夾角求第三邊。
  • FMLA 03：希羅公式，已知三邊求面積。
  • FMLA 04、05：標準常態分佈嘅 P(x)、Q(x)，有時會喺延伸數學單元一用到。呢頁冇另外寫統計程式。

另外，內置 Pol( 同 Rec( 已經可以做極坐標同直角坐標互換，唔使再寫一條程式做同樣嘅事。

程式目錄

聯立二元一次 二次方程 圓心與半徑 直線與圓相交 等差／等比數列 三邊解三角形 三點求圓（選用）

聯立二元一次（2-unknown linear）

  • 約 55 字節
  • COMP
  • 建議 P1

解 A x + B y = C 同 D x + X y = Y。第二條方程用 D、X、Y，因為冇 E 呢個變數。方法係克拉默法則：分母為 A X − B D。先輸出 x，再輸出 y。

若兩條直線平行或重疊，分母為 0，計算機會顯示 Math ERROR。呢個時候要返返去用手判斷係無解定無限多組解，程式唔會代你分類。

?→A:?→B:?→C:?→D:?→X:?→Y:
(CX-BY)÷(AX-BD)◢
(AY-CD)÷(AX-BD)

輸入次序：A、B、C、D、X、Y。輸出次序：x，然後 y。

例子 1： 3x + 2y = 7，x + y = 3。輸入 3、2、7、1、1、3。輸出 x = 1，y = 2。

例子 2： 2x + 3y = 8，x − y = 1。輸入 2、3、8、1、−1、1。輸出 x = 2.2，y = 1.2。

第二個例子嘅 X 係 −1；若睇唔清符號，用減號鍵輸入。

二次方程：頂點、判別式同兩根（Quadratic）

  • 約 66 字節
  • COMP
  • 可選，替代 FMLA 01

解 A x² + B x + C = 0（A ≠ 0）。輸出次序：頂點橫坐標 −B／(2A)，頂點縱坐標 −Δ／(4A)，判別式 Δ = B² − 4AC，然後兩條小數根 (−B ± √Δ)／(2A)，先取正號再取負號。

若 Δ < 0，顯示到 Δ 之後，開方會 Math ERROR，呢個表示冇實根。若 Δ = 0，兩根相同。根式化簡（例如寫成 (p ± √q)／r）請自己用手做，呢條程式只輸出小數，避免自動約簡出錯。

?→A:?→B:?→C:B²-4AC→D:
-B÷(2A)◢
-D÷(4A)◢
D◢
(-B+√(D))÷(2A)◢
(-B-√(D))÷(2A)

輸入次序：A、B、C。√(D) 用開方鍵，會帶一對括號。

例子 1： x² − 5x + 6 = 0。輸入 1、−5、6。輸出頂點 (2.5, −0.25)，Δ = 1，根 3 同 2。

例子 2： 2x² + 3x − 2 = 0。輸入 2、3、−2。輸出頂點 (−0.75, −3.125)，Δ = 25，根 0.5 同 −2。

圓嘅圓心與半徑（Circle centre and radius）

  • 約 51 字節
  • COMP
  • 可選

由一般式 A x² + A y² + B x + C y + D = 0 求圓心同半徑。注意 x² 同 y² 嘅係數要相同，都係 A。圓心為 (−B／(2A), −C／(2A))，半徑為 √((B² + C² − 4AD)／(4A²))，亦即係非負嘅那個值。

若根號入面係負數，冇實圓，機會顯示 Math ERROR。若半徑為 0，只係一個點。

?→A:?→B:?→C:?→D:
-B÷(2A)◢
-C÷(2A)◢
√((B²+C²-4AD)÷(4A²))

輸入次序：A、B、C、D。輸出次序：圓心橫坐標 h，縱坐標 k，然後半徑 r。

例子 1： x² + y² − 4x + 6y − 3 = 0。輸入 1、−4、6、−3。輸出圓心 (2, −3)，半徑 4。

例子 2： 2x² + 2y² + 8x − 4y + 6 = 0。輸入 2、8、−4、6。輸出圓心 (−2, 1)，半徑 √2 ≈ 1.414213562。

直線與圓相交（Line–circle intersection）

  • 約 129 字節
  • COMP
  • 建議 P2

求直線同圓嘅交點。因為冇 E、F 兩個變數，約定如下：

  • 直線：A x + B y + C = 0
  • 圓：x² + y² + D x + X y + Y = 0（呢度嘅 X、Y 相當於一般式入面嘅 E、F）

做法係先求圓心到直線嘅垂足，再沿直線方向移一段 √(r² − h²)。呢個代入對垂直線、水平線都適用。輸出兩個交點，每個點先 x 後 y。

若直線同圓相切，√(r² − h²) = 0，兩個點會重複出現。若不相交，根號入面為負，顯示 Math ERROR。若 A、B 同時為 0，亦會因為除以 0 而出錯，因為嗰時唔成一條直線。

?→A:?→B:?→C:?→D:?→X:?→Y:
√(A²+B²)→M:
(-AD-BX+2C)÷(2M)→C:
-D÷2→D:
-X÷2→X:
√(D²+X²-Y-C²)→Y:
D-(CA+YB)÷M◢
X-(CB-YA)÷M◢
D-(CA-YB)÷M◢
X-(CB+YA)÷M

輸入次序：A、B、C、D、X、Y。輸出次序：第一點 (x, y)，第二點 (x, y)。兩個點邊個先出現唔影響正確性，核對時只要兩個座標都對得上就得。程式中段會改寫 C、D、X、Y、M，所以睇完結果若要再跑一次，要重新執行程式。

例子 1（兩個交點，垂直線）： 圓 x² + y² = 25，直線 x = 3，即 1·x + 0·y − 3 = 0。輸入 1、0、−3、0、0、−25。輸出 (3, 4) 同 (3, −4)。

例子 2（相切）： 同一圓，直線 x = 5。輸入 1、0、−5、0、0、−25。兩個輸出都係 (5, 0)。

例子 3（不相交）： 同一圓，直線 x = 6。輸入 1、0、−6、0、0、−25。開方時 Math ERROR。

例子 4（斜線，整數點）： 圓 x² + y² = 25，直線 x + y − 5 = 0。輸入 1、1、−5、0、0、−25。輸出 (0, 5) 同 (5, 0)（次序或會對調；由於捨入，0 有時會顯示成極細小數，可視作 0）。

等差／等比數列（AP / GP）

  • 約 98 字節（合併）
  • COMP
  • 建議 P3

第一個輸入 M 用來揀類型：M = 0 做等差數列，M = 1 做等比數列。之後一律輸入首項 A、公差或公比 B、項數 C（正整數 n）。

  • 等差：輸出通項 Tn = A + (C − 1)B，再輸出前 n 項和 Sn = C(2A + (C − 1)B)／2。
  • 等比：輸出 Tn = A × BC−1，再輸出 Sn = A(BC − 1)／(B − 1)。若 |B| < 1，再輸出無窮和 S∞ = A／(1 − B)；若 |B| ≥ 1，唔會顯示 S∞。

若公比 B = 1，等比求和嗰步會除以 0 而 Math ERROR。呢個情況 Sn = n A，用手計，或者改用等差程式並設公差為 0。

?→M:?→A:?→B:?→C:
M=0⇒A+(C-1)B◢
M=0⇒C(2A+(C-1)B)÷2◢
M=1⇒A×B^(C-1)◢
M=1⇒A(B^C-1)÷(B-1)◢
M=1⇒Abs(B)<1⇒A÷(1-B)

B^(C−1) 用次方鍵（xy）。Abs( 係絕對值。最後一行係巢狀條件；若你部機對呢行顯示異常，可以略過佢，當 |r| < 1 時自己計 A÷(1−B)。

若你只想佔更少字節，可以分拆成下面兩條短程式，但會用兩個程式位。

例子 1（等差）： 首項 3，公差 5，n = 4。合併程式輸入 M = 0，然後 3、5、4。輸出 T4 = 18，S4 = 42。

例子 2（等比，有 S∞）： 首項 2，公比 0.5，n = 4。輸入 M = 1，然後 2、0.5、4。輸出 T4 = 0.25，S4 = 3.75，S∞ = 4。

例子 3（等比，無 S∞）： 首項 3，公比 2，n = 5。輸入 M = 1，然後 3、2、5。輸出 T5 = 48，S5 = 93，唔會再出第三個值。

三邊解三角形（Triangle from three sides）

  • 約 99 字節
  • COMP · Degree
  • 建議 P4

已知三邊 A、B、C（分別對住角 A、B、C），先用希羅公式計面積，再用餘弦定律計三隻角。輸出次序：面積，角 A，角 B，角 C（以度為單位）。

必須先設為 Degree 模式（螢幕出現 D）。角度單位通常喺 SETUP／SHIFT MODE 揀 Deg，實際鍵位以你部機說明書為準。

三邊符合三角形不等式時，SSS 只有一解。呢條程式唔處理 SSA 模糊情況——SSA 可能有兩解，要另外用手分析。若三邊根本唔成三角形，面積嗰步可能 Math ERROR，或者得出 0。

若你只需要面積，用內置 FMLA 03 就夠；呢條程式嘅額外用處係一次過出三隻角。

?→A:?→B:?→C:
(A+B+C)÷2→D:
√(D(D-A)(D-B)(D-C))◢
cos⁻¹((B²+C²-A²)÷(2BC))◢
cos⁻¹((A²+C²-B²)÷(2AC))◢
cos⁻¹((A²+B²-C²)÷(2AB))

cos⁻¹ 用反餘弦（通常 SHIFT cos）。輸入次序：邊 a、邊 b、邊 c。

例子 1： 3、4、5。輸出面積 6，角約 36.86989765°、53.13010235°、90°。

例子 2： 2、2、2。輸出面積 √3 ≈ 1.732050808，三角都係 60°。

三點求圓（選用，Three points to a circle）

  • 約 205 字節
  • COMP
  • 唔入建議四人組，有需要先換入

已知三點 (A, B)、(C, D)、(X, Y)，求外接圓嘅圓心、半徑，以及一般式 x² + y² + P x + Q y + R = 0 嘅係數 P、Q、R。方法係寫出兩條中垂線，用類似克拉默法則嘅公式解圓心，再量去第一點嘅距離。

若三點共線，分母為 0，會 Math ERROR，因為唔存在有限半徑嘅圓。

((A²+B²)(X-C)+(C²+D²)(A-X)+(X²+Y²)(C-A))÷(2(A(D-Y)+C(Y-B)+X(B-D)))→X:
X◢

輸入次序：x1、y1、x2、y2、x3、y3。輸出次序：圓心 h、k，半徑 r，然後一般式係數 P、Q、R。求 k 嗰步會重算一次分母，避免提早改寫變數。

例子 1： (1, 0)、(0, 1)、(−1, 0)。輸出圓心 (0, 0)，半徑 1，一般式係數 0、0、−1，即 x² + y² − 1 = 0。

例子 2： (0, 0)、(2, 0)、(0, 2)。輸出圓心 (1, 1)，半徑 √2 ≈ 1.414213562，係數 −2、−2、0，即 x² + y² − 2x − 2y = 0。

呢頁故意冇收嘅內容

兩點距離同斜率用 √((C−A)²+(D−B)²) 同 (D−B)÷(C−A) 即可，不必佔用程式位。重心、內心、垂心、外心嘅「四心」套裝，以及三次／四次方程、大型矩陣、財務或數論程式，呢頁都冇寫入——要嘛已經超出必修最常用範圍，要嘛未喺同樣嚴格嘅測試下推出，唔值得為完整而犧牲正確。

延伸數學單元一若要用標準常態，優先試內置 FMLA 04、05 同 SD 模式；呢頁冇另外附二項或常態程式。

常見問題

DSE Hub 係咪免費？

係，真正完全免費查閱香港中學文憑試歷屆試題索引同題目，亦包括呢頁嘅計算機程式說明。唔使報名，亦唔使信用卡。

考試可唔可以用預先輸入程式嘅計算機？

考評局准用名單上嘅計算機，包括可編程型號，必須有「H.K.E.A.A. APPROVED」或「H.K.E.A. APPROVED」墊印標籤，先可以帶入試場。fx-50FH、fx-50FH II、fx-3650P 同 fx-3650P II 都列喺 2026 年計算機通告。預先輸入程式係咪符合當年規則，請以最新官方通告同《考生手冊》為準，唔好單靠呢頁摘要。計算機上面除個人資料外唔可以寫字或貼標貼。

呢啲程式可唔可以直接抄去考試用、代替寫步驟？

唔可以當寫步驟嘅替代。程式適合核對卷一長題嘅數值，或者加快卷二嘅算術，但評卷仍然要睇你嘅列式同推理。電池沒電或重設之後，程式亦可能會消失，所以一定要識手計。

網上核對器可唔可以帶入試場？

唔可以。頁面入面嘅核對器只供練習，唔係考評局准用計算機，亦唔可以喺考試使用。

可唔可以按課題操練相關題目？

可以。喺 DSE Hub 揀「按課題」，或者開啟方程與不等式、數列、三角學與解三角形、坐標幾何：圓等課題頁，就會列出相關題目。
