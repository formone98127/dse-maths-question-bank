Question

It is given that $x$ is a real number. If $x$ is rounded down to 3 significant figures, then the result is 345. Find the range of values of $x$.

  • A. $344 < x \leq 345$
  • B. $345 \leq x <346$
  • C. $345 < x \leq 345.5$
  • D. $344.5 \leq x <345.5$
Share on WhatsAppShare on Telegram

Answer

Correct answer: B. 345 \leq x <346

深度分析

有效數字與四捨五入　認知層次：理解　建議作答 45 秒

核心公式／定理：向下取整 (Floor) 定義: $\lfloor x \times 10^k \rfloor / 10^k$、有效數字判斷規則

提示 1（啟發）
思考：當我們將一個數 $x$ 乘以 $10^k$ 後取整數部分再除以 $10^k$，這個過程對應什麼數學運算符號？
提示 2（知識）
提示：對於三位有效數字 $345$，其真實值 $x$ 必須滿足 $\lfloor x \times 100 \rfloor = 34500$。請畫出數軸思考上下界。
提示 3（破題）
引導：若 $x=344.9$，保留三位有效數字是多少？若 $x=345.499...$，結果又是多少？這能幫助你確定邊界是開還是閉。

誘答項逆向工程

A

概念錯誤　混淆向下取整與四捨五入

學生誤以為「向下取整」就是簡單的「小於等於」，忽略了有效數字的精確度邊界，直接將 345 視為上限。
B　✓ 正確答案
C

計算粗心　誤解有效數字位數

學生錯誤地認為第三個有效數字後的小數點位置應在 345.5，混淆了整數與小數的有效數字計數方式。
D

概念錯誤　誤解向下取整的閾值

學生將「向下取整」誤解為標準的四捨五入邏輯，認為下限應是 344.5 而非 345。

速解策略：利用向下取整定義：$\lfloor x \times 100 \rfloor = 34500 \Rightarrow 34500 \le x \times 100 < 34600$
