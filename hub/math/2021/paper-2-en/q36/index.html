Question

If $p, q, r, s$ is a geometric sequence, which of the following must be true? I. $ps=qr$ II. $p+s=q+r$ III. $p<q<r<s$

  • A. I only
  • B. II only
  • C. I and III only
  • D. II and III only
Share on WhatsAppShare on Telegram

Answer

Correct answer: A. I only

深度分析

等比數列性質　認知層次：分析　建議作答 45 秒

核心公式／定理：等比數列定義：$\frac{b}{a}=\frac{c}{b}=r$、等比中項公式：$ac=b^2$

提示 1（啟發）
回想等比數列的定義：後一項除以前一項等於常數公比 $r$。
提示 2（知識）
觀察選項 I 與 II 的形式，思考哪種運算（乘除或加減）能保持比例關係不變。
提示 3（破題）
嘗試代入具體數字驗證：例如取 $2, 4, 8, 16$ 檢查各選項；再取 $16, 8, 4, 2$ 檢驗大小關係是否恆成立。

誘答項逆向工程

A　✓ 正確答案
B

概念錯誤　混淆等差與等比性質

誤以為等比數列滿足 $p+s=q+r$（這是等差數列性質），忽略了公比對加法的非線性影響。
C

概念錯誤　忽略公比範圍限制

假設所有等比數列必為單調遞增，忽略了 $r<1$ 或 $r<0$ 時大小關係可能顛倒的情況。
D

概念錯誤　同時犯下 B 與 C 錯誤

既誤用等差性質 $p+s=q+r$，又錯誤假設數列必遞增，導致排除正確選項 I。

速解策略：利用等比中項性質，由 $\frac{q}{p}=\frac{r}{q}=\frac{s}{r}$ 推導出 $ps=qr$
