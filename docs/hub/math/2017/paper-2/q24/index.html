題目

直線 $ L $ 垂直於直線 $ 9x - 5y + 45 = 0 $ 。若 $ L $ 的 $ x $ 截距為 $-3$ ，則 $ L $ 的方程為

  • A. $ 5x + 9y + 15 = 0 $
  • B. $ 5x + 9y + 27 = 0 $
  • C. $ 9x - 5y + 15 = 0 $
  • D. $ 9x - 5y + 27 = 0 $

深度分析

直線方程式與斜率　認知層次：應用　建議作答 45 秒

核心公式／定理：$ m_{\perp} = -1/m $、$ y-y_1 = m(x-x_1) $

提示 1（啟發）
回憶兩直線垂直時，其斜率 $m_1$ 與 $m_2$ 的乘積關係為何？
提示 2（知識）
將原直線化為斜截式 $y=mx+c$，找出其斜率後，如何設定垂直直線的斜率？
提示 3（破題）
已知 $x$ 截距為 $-3$，代表該點坐標為 $(-3, 0)$，請利用點斜式寫出方程。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　截距計算錯誤

算出斜率 -9/5 後，代入 $x=-3$ 時，誤將 $-(-3)$ 視為減去 3 而非加上 15，導致常數項算成 27。
C

概念錯誤　混淆垂直與平行

誤以為垂直直線的係數只需互換位置，直接沿用原直線 $9x-5y$ 的係數結構，未改變斜率符號關係。
D

概念錯誤　混淆垂直與平行且計算錯誤

同時犯下兩個錯誤：一是沿用原直線係數（視為平行），二是隨意將常數項改為 27，完全忽略截距條件。

速解策略：先求原直線斜率，取負倒數得新斜率，再代入點 $(-3,0)$ 定常數項。
