Question

In the figure, $AB = BC$ and $D$ is a point lying on $AE$ such that $AC = AD$. If $AE \parallel BC$, then $\angle ABC=$ [FIGURE Q18: A geometric figure with labeled points A, B, C, D, E. Angle D is marked 124°. No dashed lines, right-angle marks, or shading. Lines AB, BC, CD, DE, and AC are drawn.]

  • A. $44^\circ$.
  • B. $56^\circ$.
  • C. $62^\circ$.
  • D. $68^\circ$.

Answer

Correct answer: A. 44^\circ

深度分析

等腰三角形性質與平行線角度計算　認知層次：應用　建議作答 90 秒

核心公式／定理：$\triangle ABC$ 中 $AB=BC \Rightarrow \angle BAC = \angle BCA$、$AE // BC \Rightarrow \angle EAC + \angle BCA = 180^\circ$ (同旁內角) 或 $\angle DAE = \angle BCA$ (錯位角，視點而定)、$\triangle ADC$ 中 $AC=AD \Rightarrow \angle ACD = \angle ADC$

提示 1（啟發）
觀察題目中的平行線 $AE // BC$，思考這兩條線被截線 $AC$ 所截時，會產生什麼角度關係？
提示 2（知識）
利用 $AB=BC$ 與 $AC=AD$ 這兩個等腰條件，將圖形中的未知角用同一個變數（例如設 $\angle BCA = x$）表示出來。
提示 3（破題）
在 $\triangle ABC$ 中，三個內角之和為 $180^\circ$，請將前述步驟得到的角度關係代入此公式求解。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　錯算同旁內角關係

學生可能誤以為 $\angle EAC + \angle BCA = 180^\circ$ 時直接將 $x$ 視為互餘而非互補，導致計算出 $56^\circ$。
C

概念錯誤　混淆等腰三角形底角

學生可能將 $AC=AD$ 的等腰三角形誤判為 $AB=AC$，導致設錯未知數關係。
D

策略錯誤　忽略平行線條件

學生可能完全忽略 $AE // BC$ 的條件，僅憑直覺或錯誤圖形想像選出此值。

速解策略：設 $\angle BCA=x$，由平行得 $\angle EAC=180-x$，再由等腰三角形性質列方程解出 $x$。
