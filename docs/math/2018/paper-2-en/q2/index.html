Question

If $\dfrac{\alpha}{1-x}=\dfrac{\beta}{x}$, then $x=$

  • A. $\dfrac{\alpha}{\alpha-\beta}$
  • B. $\dfrac{\alpha}{\alpha+\beta}$
  • C. $\dfrac{\beta}{\alpha-\beta}$
  • D. $\dfrac{\beta}{\alpha+\beta}$

Answer

Correct answer: D. \dfrac{\beta}{\alpha+\beta}

深度分析

比例式與分數運算　認知層次：應用　建議作答 45 秒

核心公式／定理：\frac{a}{b} = \frac{c}{d} \implies ad = bc

提示 1（啟發）
觀察等式兩側，嘗試使用交叉相乘法將分母消除。
提示 2（知識）
展開右側括號後，注意 \beta x 項前面的符號變化。
提示 3（破題）
將所有含 x 的項移到一側，常數項移到另一側後整理係數。

誘答項逆向工程

A

計算粗心　符號處理錯誤

交叉相乘得 \alpha x = \beta(1-x)。移項時將 \beta x 移到左邊變成減號，但分母 \alpha - \beta 未正確對應分子位置，混淆了 \alpha 與 \beta 的係數關係。
B

計算粗心　移項符號錯誤

交叉相乘正確，但在合併 \beta x 與 \alpha x 時，誤將 \beta(1-x) 展開後的負號忽略，導致分母變成 \alpha + \beta，這是常見的符號遺漏。
C

概念錯誤　分子分母顛倒

學生正確解出 x = \frac{\beta}{\alpha-\beta}，但題目要求解的是 x 而非 \frac{1-x}{x}，或是將原式中的 \alpha, \beta 位置搞混，導致選錯分子。
D　✓ 正確答案

速解策略：交叉相乘得 \alpha x = \beta - \beta x，移項合併得 x(\alpha + \beta) = \beta，故 x = \frac{\beta}{\alpha + \beta}。
