題目

點 $P$ 的坐標為 $(7, -5)$。$P$ 對 $y$ 軸作反射至點 $Q$，然後 $Q$ 繞原點順時針方向旋轉 $90^\circ$ 至點 $R$。求 $R$ 的 $x$ 坐標。

  • A. $-7$
  • B. $-5$
  • C. $5$
  • D. $7$

深度分析

座標幾何變換　認知層次：應用　建議作答 60 秒

核心公式／定理：$P(x, y) \xrightarrow{\text{y 軸反射}} P'(-x, y)$、$Q(x', y') \xrightarrow{\text{順時針} 90^\circ} R(y', -x')$

提示 1（啟發）
首先，請寫下點 P(7, -5) 關於 y 軸反射後的坐標 Q 是甚麼？
提示 2（知識）
回憶一下，在平面直角座標系中，順時針旋轉 90 度，點 (x, y) 會變成什麼新的座標 (x', y')？
提示 3（破題）
將上一步得到的 Q 點座標代入旋轉公式，計算出 R 點的 x 坐標即可。

誘答項逆向工程

A

計算粗心　旋轉符號搞錯

算出 Q(-7, -5) 後，直接將 x 坐標取反或忘記旋轉公式中的變換，錯誤地認為 R 的 x 坐標是 -7。
B　✓ 正確答案
C

計算粗心　旋轉後坐標順序混亂

知道要換 x,y，但混淆了順時針與逆時針的座標互換規則，錯誤地將 y 值直接當做 x 值且符號未調整。
D

審題不清　忽略反射步驟

完全跳過反射步驟，直接對 P(7,-5) 進行順時針旋轉，導致 x 坐標變成 -(-5)=5，但此處選 D 代表學生可能算出 R 的 y 坐標或是單純記錯原座標。

速解策略：先反射得 Q(-7,-5)，再順時針轉 90 度變為 (y, -x) 即 (-5, 7)，故 x 為 -5。
