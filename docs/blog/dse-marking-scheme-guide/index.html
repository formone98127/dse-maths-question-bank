DSE 考生最大嘅痛，唔係冇卷做——網度大把卷。最大嘅痛係：做完成份卷，先發現搵唔到 Marking Scheme；搵到之後，又只識用嚟對最後答案。一份評卷參考俾你用成咁，認真嘥。

Marking Scheme 唔係答案紙，係評卷員個腦

你要明白一件事：評卷員改你份卷嘅時候，枱面擺嘅就係呢份 Marking Scheme。佢逐行睇你嘅步驟，逐個分點剔。即係話，Marking Scheme 就係考評局親手寫俾你嘅「攞分說明書」。識用嘅人係偷師，唔識用嘅人只係核對。

三個正確用法

用法一：逐步對分，唔係對答案

做完一條長題，攞住評卷參考，將自己嘅每一步同 MS 嘅每個分點 (M1)、(M2)、(A1) 對照。你會即時見到：邊一步你有寫但 MS 唔俾分（多餘步驟）、邊一步 MS 俾分但你跳咗（白送嘅分）。呢個對照訓練做十次，你寫步驟嘅習慣會完全唔同。

用法二：學官方語言

卷一幾何題要寫理由、統計題要寫單位、三角題要寫搵到嘅角。呢啲「格式分」全部寫晒喺 MS 度。睇得多，你就會識得用考評局鍾意嘅寫法作答——同一個答案，寫法唔同，分可以差一個 grade。

用法三：逆向出題

睇 MS 嘅分佈，你會估到考官重視咩：一條題目原來 (a) 佔 2 分只係熱身，(c) 先係 5 分嘅主菜。下次見到同類題，你就知時間應該分配去邊。識得逆向睇卷，你係同考官對住睇，唔係俾人考。

三個常見誤區

  • 睇完當做完：睇明 MS 點解唔等於你識寫。每條錯題睇完 MS 之後，閂住佢自己由頭寫一次先算數。
  • 只對最後答案：答案啱但步驟跳，考評局照扣方法分；答案錯但方法啱，考評局照俾步驟分。淨睇答案你永遠唔知真相。
  • 背 solution：MS 係俾你學思維，唔係俾你背。背咗舊年嘅寫法，今年轉個問法你就瓜。
