題目

圖中，$ ABC $ 為一等邊三角形及 $ CDE $ 為一等腰三角形且 $ CD = CE $ 。若 $ \angle DCE = 78^\circ $ 及 $ \angle ADC = \angle CAD = 40^\circ $，則 $ \angle CBE = $

  • A. $ 14^\circ $
  • B. $ 19^\circ $
  • C. $ 24^\circ $
  • D. $ 29^\circ $

深度分析

一元二次方程式　認知層次：應用　建議作答 120 秒

核心公式／定理：x = (-b ± sqrt(b^2 - 4ac)) / (2a)、ax^2 + bx + c = 0

提示 1（啟發）
Hint 1: 觀察方程式的係數 a, b, c，確認是否符合求根公式的使用條件。
提示 2（知識）
Hint 2: 計算判別式 D = b^2 - 4ac 的值，判斷解的性質並代入公式。
提示 3（破題）
Hint 3: 仔細檢查每一步運算，特別是符號處理與分數化簡。

誘答項逆向工程

A

計算粗心　符號處理錯誤

學生在代入求根公式時，忽略了 b^2 - 4ac 中 c 為負數導致減負變加，或計算平方根後忘記除以 2a。
B

概念錯誤　解法選擇不當

學生嘗試將方程式整理成 (x-3)(x+2)=0 的形式，但錯誤地認為根為 -3 和 2，忽略了括號內的符號變化。
C

審題不清　題目閱讀疏失

學生誤讀題目中的係數，將 x^2 的係數看錯，導致整個解題方向偏差。
D　✓ 正確答案

速解策略：使用求根公式 x = (-b ± sqrt(b^2 - 4ac)) / (2a) 直接求解並驗證選項。
