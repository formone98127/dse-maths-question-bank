先讀資料，再寫概念

公民科全卷都要根據題目提供嘅資料作答。高分答案通常不是背誦長段課文，而係：準確讀懂資料、用課程概念命名你見到嘅現象，再按題目指令比較、解釋或提出看法。以下框架適合選擇題之外嘅短答同短文章。

  1. 審題動詞：指出、說明、比較、解釋、討論、評鑑，要求嘅深度唔同。「指出」要精準；「評鑑」要有準則同正反。
  2. 標記資料：每則資料用一句话寫「佢主張／顯示咩」。圖表先讀標題、單位、趨勢，先再下判斷。
  3. 對應概念：問自己呢則資料屬於邊個主題、邊個概念（例如法治、權利義務、改革開放、相互依存）。概念名稱要準確。
  4. 引用方法：用「資料 X 顯示…，呢點可以說明…」把證據同概念接起來。只抄資料或只寫概念，兩者都唔夠。
  5. 短文章：用兩至三段，每段一個功能。結論回應題目，唔好突然引入從未討論嘅新例子。

常見失分

  • 忽略資料限制：一張圖只涵蓋某時段或某地，就唔好推成全世界永遠如此。
  • 立場先行：未處理資料就宣示態度，或者把試卷寫成情緒表達。
  • 概念錯配：用錯名稱，或者把不同層次嘅制度概念混為一談。
  • 比較題只寫 A，漏咗 B，或者沒有共同準則。

選擇題同短答

選擇題先排除明顯同資料相反嘅選項，再睇剩餘選項係唔係「講得通但越權推斷」。短答先寫關鍵句，再補一個資料證據，避免空泛形容詞。
