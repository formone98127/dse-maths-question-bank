題目

設 $F(x) = (6x^2 + x + p)(qx^2 + rx - 10)$，其中 $p$、$q$ 及 $r$ 均為常數。$F(x)$ 的常數項為 40。 (a) 寫出 $p$ 的值。 (1 分)

(b) 當 $F(x)$ 除以 $x + 1$ 時，餘數為 -12。已知 $x - 2$ 為 $F(x)$ 的因式。 (i) 求 $q$ 及 $r$。 (7 分) (ii) 方程 $F(x) = 0$ 有多少個無理根？試解釋你的答案。 乙部（35 分）

深度分析

多項式　認知層次：分析　建議作答 300 秒

核心公式／定理：$P(a) = R$ (餘數定理)、$x - c$ 為因式 $\iff P(c) = 0$、$F(x) = (6x^2 + x + p)(qx^2 + rx - 10)$

提示 1（啟發）
Hint1: 常數項是兩個括號內常數項的乘積，注意 $-10$ 的符號。
提示 2（知識）
Hint2: 餘數定理 $F(-1)=-12$ 與因數定理 $F(2)=0$ 提供兩個關於 $q,r$ 的線性方程。
提示 3（破題）
Hint3: 解出 $q,r$ 後，檢查二次因式的判別式 $\Delta$ 以判斷根是否無理。

速解策略：先由常數項定 $p=40$；再代入 $x=-1, 2$ 列方程組解 $q,r$；最後展開分解求根並分類有理/無理。
