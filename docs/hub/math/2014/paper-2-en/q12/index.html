Question

It is given that $\dfrac{4}{5a} = \dfrac{5}{7b} = \dfrac{7}{9c}$, where $a$, $b$ and $c$ are positive numbers. Which of the following is true?

  • A. $a < b < c$
  • B. $a < c < b$
  • C. $b < a < c$
  • D. $b < c < a$
Share on WhatsAppShare on Telegram

Answer

Correct answer: D. b < c < a

深度分析

比例與代數變量大小比較　認知層次：分析　建議作答 45 秒

核心公式／定理：若 \(\frac{x}{y} = k\)，則 \(x = ky\)

提示 1（啟發）
提示 1：設 \(k\) 為這三個相等分數的公共值，將 \(a, b, c\) 用 \(k\) 表示出來。
提示 2（知識）
提示 2：觀察分子與分母的係數關係（\(4,5,7\) 與 \(9,7,5\)），思考當分子變大時，為了保持分數值不變，分母應該如何變化？
提示 3（破題）
提示 3：將 \(a, b, c\) 的表達式寫出後，直接比較它們係數的大小即可得出答案。

誘答項逆向工程

A

概念錯誤　誤以為分子大分母必大

學生看到 \(4<5<7\)，直覺認為分母也應隨之遞增，故猜 \(a<b<c\)。忽略了分數值相等時，分子與分母成反比。
B

計算粗心　交叉相乘順序錯誤

學生試圖比較 \(a\) 與 \(c\)，但計算 \(4/5a = 7/9c\) 時，錯誤地得出 \(36ac = 35ab\) 或類似的係數混淆，導致順序判斷失誤。
C

概念錯誤　忽略 \(b\) 與 \(c\) 關係

學生正確推導出 \(a<c\)，但在比較 \(b\) 時，錯誤地認為 \(5/7b = 7/9c\) 中 \(5<7\) 所以 \(b>c\)，卻忘記了 \(b\) 與 \(a\) 的比較結果。
D　✓ 正確答案

速解策略：設公共比為 k，得 a=4k/5, b=7k/5, c=9k/7；比較係數 0.8, 1.4, 1.28 即可。
