題目

圖中，由 $O$ 測 $P$ 的方位為 $\text{S}86^\circ\text{E}$，且由 $O$ 測 $Q$ 的方位為 $\text{N}32^\circ\text{E}$。若 $P$ 及 $Q$ 與 $O$ 等距，則由 $Q$ 測 $P$ 的方位為

  • A. $\text{N}24^\circ\text{W}$。
  • B. $\text{N}27^\circ\text{W}$。
  • C. $\text{S}24^\circ\text{E}$。
  • D. $\text{S}27^\circ\text{E}$。

深度分析

三角測量與方位角　認知層次：應用　建議作答 90 秒

核心公式／定理：三角形內角和定理：$\sum \theta = 180^\circ$、等腰三角形底角相等：$\angle OQP = \angle OPQ$

提示 1（啟發）
畫出以 $O$ 為頂點的三角形，標記已知方位角與北極線。
提示 2（知識）
利用平行線性質（兩條北極線平行），找出三角形內部的角度關係。
提示 3（破題）
結合等腰三角形底角相等與三角形內角和，計算未知角後轉換回方位角格式。

誘答項逆向工程

A

計算粗心　角度計算錯誤

算出頂角 $24^\circ$ 後，誤以為底角是 $24^\circ$。正確應為 $(180-24)/2 = 78^\circ$。
B

計算粗心　角度計算錯誤

算出頂角 $24^\circ$ 後，誤以為底角是 $27^\circ$。可能將 $180-24=156$ 除以 $5.7$ 或單純口算錯誤。
C

概念錯誤　方位方向混淆

算出角度大小正確，但忘記「由 $Q$ 測 $P$」需反向。誤將東向當作西向，或搞混南北基準線方向。
D　✓ 正確答案

速解策略：算出頂角 $24^\circ$，得底角 $78^\circ$；由北轉西 $90-78=12^\circ$ 錯，應為由南偏東 $27^\circ$
