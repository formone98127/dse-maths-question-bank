Question

The graph in the figure shows the linear relation between $x$ and $\log_9y$. If $y=ab^x$, then $b=$ [FIGURE Q32: Cartesian coordinate system graph with x-axis and y-axis labeled. y-axis labeled "log₉ y". Points marked: (4, 4) and (0, -2). No dashed lines, right-angle marks, or shading.]

  • A. $-2$.
  • B. $\dfrac{1}{81}$.
  • C. $\dfrac{1}{2}$.
  • D. $3$.

Answer

Correct answer: D. 3

深度分析

指數函數與對數的轉換　認知層次：分析　建議作答 90 秒

核心公式／定理：$\log_{a^k} b = \frac{1}{k}\log_a b$、$y = ab^x$ 與 $\log_c y = mx + c$ 的關係

提示 1（啟發）
觀察圖形，$x$ 與 $\log_9 y$ 呈線性關係，這意味著它們符合直線方程式 $L = mx + c$ 的形式。
提示 2（知識）
考慮指數函數 $y=ab^x$ 取對數後的結構：$\log_9(ab^x) = \log_9 a + x\log_9 b$。
提示 3（破題）
比較上述兩式，找出斜率與 $b$ 之間的數值關係，並代入圖中讀出的斜率進行計算。

誘答項逆向工程

A

概念錯誤　斜率符號誤解

學生可能誤以為圖形下降代表底數 $b$ 為負數，或混淆了指數衰減與底數大小關係。
B

計算粗心　對數換底計算錯誤

學生在將 $\log_9 y$ 轉換為 $\log_3 y$ 時，忘記除以係數 2，直接將斜率當作最終答案。
C

概念錯誤　指數與對數關係混淆

學生可能誤認為線性圖形的斜率直接等於 $b$，而忽略了對數底數轉換帶來的係數影響。
D　✓ 正確答案

速解策略：將 $y=ab^x$ 取 $\log_9$ 得線性式，斜率即為 $\log_9 b$，由圖知斜率為 $1/2$，解出 $b$
