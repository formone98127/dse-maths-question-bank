題目

圖中，$ ABCDEFGH $ 為八邊形，其中所有的量度均準確至最接近的 $ \text{cm} $ 。設 $ x \text{cm}^2 $ 為該八邊形的實際面積。求 $ x $ 值的範圍。

  • A. $ 13 < x < 23 $
  • B. $ 13 < x < 27 $
  • C. $ 17 < x < 23 $
  • D. $ 17 < x < 27 $

深度分析

誤差範圍與幾何面積估算　認知層次：應用　建議作答 90 秒

核心公式／定理：梯形/三角形面積公式 $\frac{1}{2}bh$ 或 $\frac{(a+b)h}{2}$、極大極小值原理

提示 1（啟發）
提示 1：題目給出的是「最接近」的測量值，這意味著實際長度是在測量值的 $\pm 0.5$ 範圍內浮動的。
提示 2（知識）
提示 2：要找到面積的範圍，你需要分別計算八邊形的「最小可能面積」和「最大可能面積」。請思考如何調整各邊長以達到這兩個極限。
提示 3（破題）
提示 3：將圖形分割成熟悉的幾何形狀（如矩形、三角形）來計算面積。記得在計算極小值時，所有相關長度應取最小可能值；計算極大值時則取最大可能值。

誘答項逆向工程

A

計算粗心　下限計算錯誤

學生正確算出上限，但在計算最小面積時，可能將某邊長誤讀為整數而非減去 0.5，導致下限偏小（如算成 13）。
B　✓ 正確答案
C

計算粗心　上下限皆錯

學生在計算最小面積時，錯誤地將所有邊長都減去 0.5（甚至更多），導致下限過低；同時上限計算亦有誤。
D

審題不清　讀圖錯誤

學生未能正確識別圖形結構，可能將非直角部分視為直角梯形計算，或誤讀了某個關鍵邊長數值。

速解策略：將多邊形分割為簡單圖形，分別代入邊長的 $(\text{測量值}-0.5)$ 與 $(\text{測量值}+0.5)$ 計算極小與極大面積。
