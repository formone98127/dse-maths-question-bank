Question

Consider the following system of inequalities: $$ \left{ \begin{array}{l} x+3 \geq 0 \ 2x+3y-12 \leq 0 \ 5x-3y+12 \leq 0 \end{array} \right. $$ Let $D$ be the region which represents the solution of the above system of inequalities. Find the range of values of $\beta$ such that the greatest value of $\beta x+6y$ is 24, where $(x, y)$ is a point lying in $D$.

  • A. $\beta \leq -10$
  • B. $\beta \geq -10$
  • C. $\beta \leq 4$
  • D. $\beta \geq 4$

Answer

Correct answer: D. \beta \geq 4

深度分析

線性規劃與不等式組　認知層次：分析　建議作答 180 秒

核心公式／定理：$y = mx + c$、$\max(c_1 x + c_2 y) \text{ 發生於可行域頂點}$

提示 1（啟發）
先畫出由三個不等式圍成的可行域 $D$，並標記出所有的頂點座標。
提示 2（知識）
回憶線性規劃定理：目標函數的最值必發生在可行域的某個頂點上。
提示 3（破題）
將目標函數視為一簇平行直線，當其斜率變化時，觀察哪種情況能讓最大值固定為 24 且僅發生在特定頂點或邊上。

誘答項逆向工程

A

概念錯誤　斜率關係誤判

學生算出兩邊直線斜率後，錯誤認為只要目標函數斜率在兩者之間即可，忽略係數 $\beta$ 與 $y$ 係數比對時需考慮的符號變化。
B

計算粗心　斜率計算錯誤

學生正確找出頂點，但在將目標函數 $\beta x + 6y = 24$ 轉換為斜率形式時，除以 6 後忘記變號或算錯分母，導致範圍偏移。
C

審題不清　不等號方向混淆

學生正確計算出臨界斜率為 -4，但未能理解題目要求的是「最大值」條件下 $\beta$ 的範圍，誤選了包含錯誤邊界的選項。
D　✓ 正確答案

速解策略：找出可行域頂點，比較目標函數在各頂點的價值，利用斜率關係確定 $\beta$ 範圍。
