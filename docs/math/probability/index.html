常見問題

DSE Hub 係咪免費？

係，真正完全免費查閱香港中學文憑試歷屆試題索引同題目，唔使報名，亦唔使信用卡。

可唔可以按課題操練？

可以。喺 DSE Hub 揀「按課題」，或者開啟各課題頁，就會列出相關題目，方便集中操同一類型。

點樣搵某一年嘅 DSE past paper？

喺 DSE Hub 主頁揀「按年份」，再揀科目同年份；或者開啟科目頁，撳對應年份就可以睇嗰年各卷。

有冇英文卷可以操？

有。數學同經濟部分年份提供英文卷；化學、生物、物理而家主要係中文卷。每卷頁會標明語言。
