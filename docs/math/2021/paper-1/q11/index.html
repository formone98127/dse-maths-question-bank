題目

下表顯示在一遊戲中某群小童所獲代幣的數目的分佈。

所獲代幣的數目 1 2 3 4 5 6 7
小童人數 15 9 2 5 4 2 5

(a) 求該分佈的平均值。 (2 分)

(b) 該分佈的中位數與眾數是否相等？試解釋你的答案。 (2 分)

(c) 若再多 ( n ) 名小童參與該遊戲且其中人均獲 5 個代幣，寫出

(i) ( n ) 的值使得該分佈的平均值增加 1；

(ii) ( n ) 的最小值使得該分佈的中位數增加 2；

(iii) ( n ) 的最大值使得該分佈的眾數維持不變。 (3 分)

深度分析

統計　認知層次：應用　建議作答 480 秒

核心公式／定理：\bar{x} = \frac{\sum f x}{N}、\text{Median position} = \frac{N+1}{2}

提示 1（啟發）
先畫出累積頻數表，有助於快速定位中位數。
提示 2（知識）
平均值公式為 \(\frac{\sum fx}{N}\)，加入新數據需更新 N 與 \(\sum fx\)。
提示 3（破題）
眾數不變意味著新增的 5 個代幣不能讓其他數值的頻數超過現有眾數的頻數。

速解策略：先算原平均值；中位數看累積頻數過半位置；眾數看最高頻；加入 n 人後，用方程解平均，用累積頻數變化解中位數，用頻數比較解眾數。
