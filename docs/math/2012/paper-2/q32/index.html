題目

圖中的圖像顯示 $x$ 與 $\log_3 y$ 之間的線性關係。若 $y=mn^x$，則 $n=$

  • A. $\dfrac{1}{81}$。
  • B. $\dfrac{1}{9}$。
  • C. $9$。
  • D. $81$。

深度分析

指數函數與對數轉換　認知層次：分析　建議作答 90 秒

核心公式／定理：$\log_b(a^k) = k \log_b a$、$y = mn^x \iff \log_3 y = x \log_3 n + \log_3 m$

提示 1（啟發）
Hint 1 啟發：觀察圖像，將 $y=mn^x$ 兩邊同時取以 3 為底的對數，思考這會轉化成什麼形式的直線方程式？
提示 2（知識）
Hint 2 知識：利用直線斜率公式 $m = \frac{\Delta y}{\Delta x}$ 計算圖中直線的斜率。注意此處 $y$ 軸代表的是 $\log_3 y$ 的值，且圖像經過 $(0,0)$ 與 $(1,-2)$ 等關鍵點。
提示 3（破題）
Hint 3 破題：由對數性質可知，直線斜率等於 $\log_3 n$。既然算出斜率為 $-2$，請直接計算 $3^{-2}$ 的值即可得到答案。

誘答項逆向工程

A

計算粗心　斜率符號與大小計算錯誤

學生正確識別圖形為直線，但計算斜率時將 $\frac{1}{2}$ 誤算為 $-\frac{1}{2}$（因為圖像向下傾斜），或者在取對數後忘記絕對值。接著解出 $\log_3 n = -\frac{1}{2}$ 時，正確應得 $n=\frac{1}{3^{0.5}}$，但學生可能誤算為 $n=(\frac{1}{3})^4 = \frac{1}{81}$，混淆了平方與四次方的關係，或是將斜率 $-\frac{1}{2}$ 直接當作指數 $-4$ 處理。
B

計算粗心　斜率大小計算錯誤

學生正確識別圖像向下傾斜，得出斜率為負數。但在計算具體數值時，將經過的點誤讀或誤算導致斜率絕對值為 $\frac{1}{2}$ 而非 $2$（或是相反）。若斜率被算成 $-\frac{1}{2}$，則 $n=\sqrt{\frac{1}{3}}$；若學生錯誤認為斜率是 $-2$，則 $n=\frac{1}{9}$。此選項對應於將斜率誤判為 $-2$ 的情況（例如只看垂直變化忽略水平變化）。
C　✓ 正確答案
D

概念錯誤　底數與斜率關係理解錯誤

學生正確算出斜率為 $-2$，但在從 $\log_3 n = -2$ 推導到 $n$ 時，誤以為 $n$ 應該等於 $3^2$（即 $9$）的倒數是 $1/9$ 但選項 D 是 $81$。更可能的錯誤過程是：學生算出斜率為 $-2$，正確得到 $n=\frac{1}{9}$ 後，因為題目問的是 $y=mn^x$，學生可能誤以為 $n$ 必須大於 1 才能構成指數增長，或者在計算 $3^{-2}$ 時算錯成 $3^4=81$。另一個常見錯誤是將斜率 $-2$ 視為 $\log_3 n = 4$（完全搞反符號與運算），導致 $n=81$

速解策略：將 $y=mn^x$ 取 $\log_3$ 得 $\log_3 y = x \log_3 n + \text{const}$。圖中直線斜率為 $-2$，故 $\log_3 n = -2 \Rightarrow n=3^{-2}=1/9$
