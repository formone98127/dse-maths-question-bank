計量同計算框架

  1. 先寫平衡化學方程式，狀態同系數唔好估完就算。
  2. 把已知量全部轉成摩爾。溶液用濃度乘體積（體積要統一單位）；氣體用題目指定嘅摩爾體積或理想氣體關係，唔好混用未聲明嘅條件。
  3. 用系數比找限制反應物，先再算目標物質。過量物質要交代剩餘。
  4. 產率、濃度或氣體體積喺最後先還原，並檢查有效數字同單位。

常見離子同物質分類（溫習用）

下面係學習上常用嘅離子同類別，方便寫方程式同觀察記錄。正式名單同顏色變化，請以課堂實驗同官方教材為準，唔好把呢頁當成完整點名表。

  • 常見陽離子：鈉、鉀、鈣、鎂、鋁、鋅、鐵(II)、鐵(III)、銅(II)、鉛(II)、銀、銨。記嘅時候連測試方法一齊記，例如焰色、沉澱或氣體。
  • 常見陰離子：氯、溴、碘、氫氧、硝酸、硫酸、碳酸、亞硫酸。很多要靠酸化之後放出嘅氣體，或與硝酸銀、氯化鋇等試劑嘅反應去分辨。
  • 寫離子方程式時，只保留真正參與嘅離子，並檢查電荷同原子數平衡。

解釋題點寫

  • 酸鹼：講清楚質子轉移、強弱酸定義，以及稀釋或中和對 pH 同導電性嘅影響，避免只寫「酸性變弱」。
  • 氧化還原：指出邊種物種失電子、邊種得電子，氧化數變化要寫出來。
  • 平衡：用可逆反應同勒沙特列原理時，必須講「已建立平衡之後，改變邊個條件、系統點樣減緩呢個改變」。唔好把速率同平衡位置混為一談。
  • 結構同鍵合：由電子排列講到鍵型，再講到熔點、導電、硬度等可觀察性質。
