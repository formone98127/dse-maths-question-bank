Question

Consider the following system of inequalities:

$\begin{cases} x-21\le 0\ x-y-35\le 0\ x+5y-91\le 0\ 3x+2y\ge 0\end{cases}$

Let $D$ be the region which represents the solution of the above system of inequalities. If $(x,y)$ is a point lying in $D$, then the least value of $5x+6y+234$ is

  • A. $45$
  • B. $150$
  • C. $178$
  • D. $423$
Share on WhatsAppShare on Telegram

Answer

Correct answer: C. 178

深度分析

線性規劃　認知層次：應用　建議作答 180 秒

核心公式／定理：$x - 21 \leq 0$、$x - y - 35 \leq 0$、$x + 5y - 91 \leq 0$、$3x + 2y \geq 0$、$Z = 5x + 6y + 234$

提示 1（啟發）
線性規劃問題中，目標函數的最值通常出現在可行域的頂點（直線交點）上。
提示 2（知識）
請先畫出或解出各不等式對應的邊界直線方程，並找出相鄰邊界的交點坐標。
提示 3（破題）
將求得的頂點坐標代入目標函數 $Z = 5x + 6y + 234$ 比較大小，即可找到最小值。

誘答項逆向工程

A

審題不清　忽略常數項或計算錯誤

學生算出 $(x,y)$ 坐標後，忘記加上目標函數中的 $+234$，或者將 $5x+6y$ 算成 $189$ 時誤以為是 $45$
B

計算粗心　交點求解錯誤

在解聯立方程 $x-y-35=0$ 與 $x+5y-91=0$ 時，消元法運用出錯，導致 $x,y$ 數值偏差。
C　✓ 正確答案
D

策略錯誤　未檢查可行域邊界

學生可能只計算了某兩條直線交點，卻忽略了該點是否在 $3x+2y \geq 0$ 的範圍內，導致選錯極值點。

速解策略：解聯立方程找出可行域頂點，代入 $5x+6y+234$ 比較即得答案。
