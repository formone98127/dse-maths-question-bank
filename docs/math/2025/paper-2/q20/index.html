題目

已知 $PQRS$ 為一梯形且 $PQ//SR$ 。若 $PS=41\text{ cm}$ 、$RS=53\text{ cm}$ 、$\angle PSR=120^\circ$ 及 $\angle QRS=150^\circ$ ，則 $PQ=$

  • A. $82\text{ cm}$
  • B. $100\text{ cm}$
  • C. $106\text{ cm}$
  • D. $135\text{ cm}$

深度分析

梯形性質與三角函數應用　認知層次：應用　建議作答 180 秒

核心公式／定理：$\cos(180^\circ - \theta) = -\cos \theta$、$c^2 = a^2 + b^2 - 2ab \cos C$

提示 1（啟發）
觀察 $PQ // SR$，推導 $\angle SPR$ 與 $\angle PSR$ 的互補或外角關係。
提示 2（知識）
將梯形分割為三角形與平行四邊形，或利用餘弦定理在 $\triangle PSR$ 中求 $PR$。
提示 3（破題）
注意 $\angle QRS = 150^\circ$ 暗示 $\angle PQR = 30^\circ$，結合 $\triangle PQR$ 的邊角關係求解 $PQ$

誘答項逆向工程

A

概念錯誤　誤用平行線性質

學生可能認為梯形底角互補，直接將 $120^\circ$ 與 $150^\circ$ 相加或相減，未考慮非直角梯形的角度關係。
B

計算粗心　餘弦定理計算錯誤

學生正確畫出輔助線，但在計算 $\triangle PQR$ 或 $\triangle PSR$ 時，誤將角度代入為銳角（如用 $120^\circ$ 的餘弦值算成正值），導致數值偏小。
C

策略錯誤　輔助線作法不當

學生嘗試作高，但錯誤地假設垂足落在底邊延長線上之外側，或未將 $120^\circ$ 轉化為外角 $60^\circ$ 來構建特殊直角三角形。
D　✓ 正確答案

速解策略：作 $PR$ 連線，利用餘弦定理求 $PR$，再於 $\triangle PQR$ 中利用正弦定理或幾何性質求 $PQ$
