題目

If $k$ and $\frac{5}{2-i} + ki$ are real numbers, then $k=$

  • A. $-2$
  • B. $-1$
  • C. $1$
  • D. $2$

深度分析

複數運算與實數條件　認知層次：分析　建議作答 60 秒

核心公式／定理：$\frac{a+bi}{c+di} = \frac{(a+bi)(c-di)}{c^2+d^2}$、$z=x+yi$ 為實數當且僅當 $y=0$

提示 1（啟發）
提示 1：複數除法需將分母變為實數，請乘以分母的共軛複數 $(2+i)$。
提示 2（知識）
提示 2：整理結果後，利用「虛部係數必須為零」的條件建立方程式。
提示 3（破題）
提示 3：解一元一次方程式 $1+k=0$ 即可求得 $k$ 值。

誘答項逆向工程

A

計算粗心　分母有理化時符號錯誤

學生在將 $\frac{5}{2-i}$ 化為 $\frac{5(2+i)}{5}=2+i$ 後，加上 $ki$ 得到 $2+(1+k)i$。令虛部 $1+k=0$ 時算錯成 $k=-2$
B　✓ 正確答案
C

概念錯誤　混淆實數與純虛數定義

學生誤以為 $k$ 需使整體為純虛數，故令實部 $2=0$（不可能），或錯誤認為 $k$ 應抵消分母中的 $-i$ 而選正數
D

計算粗心　忽略負號導致符號反轉

正確算出虛部係數為 $1+k$，但解方程 $1+k=0$ 時誤算成 $k=2$

速解策略：將複數分式有理化得 $2+i+ki$，令虛部 $1+k=0$ 解得 $k=-1$
