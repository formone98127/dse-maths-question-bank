Question

Let $ x_n $ be the $ n $th term of a geometric sequence. If $ x_6 = 216 $ and $ x_8 = 96 $, which of the following must be true? I. $ x_3 = 729 $ II. $ \dfrac{x_5}{x_7} > 1 $ III. $ x_2 + x_4 + x_6 + \cdots + x_{2n} < 2015 $

  • A. I only
  • B. II only
  • C. I and III only
  • D. II and III only
Share on WhatsAppShare on Telegram

Answer

Correct answer: D. II and III only

深度分析

等比數列　認知層次：分析　建議作答 90 秒

核心公式／定理：$x_n = x_1 r^{n-1}$、$\frac{x_m}{x_k} = r^{m-k}$

提示 1（啟發）
利用 $\frac{x_8}{x_6} = r^2$ 先求出公比 $r$ 的絕對值與符號。
提示 2（知識）
計算 $\frac{x_5}{x_7}$ 時，觀察其等於 $r^2$，判斷正負與大小關係。
提示 3（破題）
將等比級數轉化為無限級數求和公式或計算前幾項總和進行比較。

誘答項逆向工程

A

概念錯誤　忽略公比小於一

算出 r=1/3 後，只驗證 I。因 II 中 x5/x7 = r^2 >0 成立，學生誤以為 II 錯或漏看，導致選 A。
B

計算粗心　前項求和估算失誤

確認 I 錯、II 對後，未仔細計算等比級數和。因首項大但公比小，總和可能小於 2015，學生輕率排除 III。
C

概念錯誤　誤判 II 為假

算出 r=1/3，認為 x5/x7 = (1/3)^2 < 1，故 II 錯。這是對不等式方向或數值大小關係的混淆。
D　✓ 正確答案

速解策略：先由 x8/x6 求 r=1/3；再驗 II (r^2>0) 與 III (有限和<無窮和)
