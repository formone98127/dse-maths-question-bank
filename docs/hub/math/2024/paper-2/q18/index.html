題目

圖中，$ABC$ 為一直線。已知 $AD=37\,\text{cm}$ ，$BC=5\,\text{cm}$ ，$BD=12\,\text{cm}$ ，$CD=13\,\text{cm}$ 及 $CE=9\,\text{cm}$ 。若 $\angle ACE=90^\circ$ ，求四邊形 $ADCE$ 的周界。

  • A. $76\,\text{cm}$
  • B. $90\,\text{cm}$
  • C. $100\,\text{cm}$
  • D. $180\,\text{cm}$

深度分析

幾何圖形周界計算　認知層次：應用　建議作答 90 秒

核心公式／定理：$a^2 + b^2 = c^2$、$P = AD + DC + CE + EA$

提示 1（啟發）
觀察圖形，四邊形 $ADCE$ 由哪些線段組成？請列出它們的長度表達式。
提示 2（知識）
已知 $ riangle ACE$ 是直角三角形，如何利用畢氏定理求出未知邊 $AC$ 和 $AE$？
提示 3（破題）
確認所有邊長後，將它們相加即可得到周界，注意不要重複計算或遺漏任何一邊。

誘答項逆向工程

A

計算粗心　漏算斜邊 EA

學生只計算了已知邊 $AD+DC+CE = 37+13+9=59$，誤以為這是答案或混淆選項。若選 A(76)，可能是將 $EA$ 算錯為 $17$ ($59+17=76$) 或單純加錯數字。
B

計算粗心　斜邊計算錯誤

學生算出 $AC=15$ 後，正確算出 $EA=20$。但在總和時將 $37+13+9+20$ 算錯為 $89$ 或四捨五入誤導，導致選 B(90)。
C　✓ 正確答案
D

概念錯誤　誤解周界定義

學生將 $AB$ 的長度 ($37+5=42$) 或其他非邊界線段加入計算，或錯誤地認為周界包含整個直線 $ABC$ 的部分。

速解策略：先求 $AC=\sqrt{13^2+9^2}=15$，再求 $AE=\sqrt{37^2-15^2}=20$，最後加總四邊。
