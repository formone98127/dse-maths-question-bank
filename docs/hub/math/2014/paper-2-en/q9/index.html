Question

There are 792 workers in a factory. If the number of male workers is 20% less than that of female workers, then the number of male workers is

  • A. 352.
  • B. 360.
  • C. 432.
  • D. 440.
Share on WhatsAppShare on Telegram

Answer

Correct answer: A. 352

深度分析

百分比與比例　認知層次：應用　建議作答 60 秒

核心公式／定理：總數 = 男工 + 女工、男工 = 女工 × (1 - 20%)

提示 1（啟發）
設女工人數為 x，則男工人數可表示為何？
提示 2（知識）
男工與女工總數等於 792，請列出方程式。
提示 3（破題）
解出女工人數後，再乘以 0.8 得到男工人數。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　計算錯誤

先設女工為 x，得 0.8x + x = 792，解得 x=432。誤將 432 當作男工數，忘記男工是 0.8x，故選 B。
C

概念錯誤　比例關係混淆

誤以為男工較女工少 20% 是指總數的 20%，直接算 792×0.8=633.6，再亂推導或選接近值 C。
D

概念錯誤　性別角色刻板印象

因題目說男工較女工少，直覺認為男工應少於一半，但誤算 792×0.55≈435，四捨五入選 D。

速解策略：設女工 x，則 1.8x=792，x=440，男工=440×0.8=352。
