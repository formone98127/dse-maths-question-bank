題目

If $ k $ is a constant such that $ x^3 + 4x^2 + kx - 12 $ is divisible by $ x + 3 $, then $ k = $

  • A. $-25$.
  • B. $-1$.
  • C. $1$.
  • D. $17$.

深度分析

多項式除法與餘數定理　認知層次：應用　建議作答 45 秒

核心公式／定理：$P(x)$ 除以 $x-a$ 的餘數為 $P(a)$、若 $x+a$ 為 $P(x)$ 之因式，則 $P(-a) = 0$

提示 1（啟發）
Hint 1 啟發：當一個多項式能被 $(x+a)$ 整除時，根據因式定理，將 $x=-a$ 代入該多項式後結果應為零。
提示 2（知識）
Hint 2 知識：本題需使用公式 $P(-3) = (-3)^3 + 4(-3)^2 + k(-3) - 12 = 0$，請先計算已知數值部分。
提示 3（破題）
Hint 3 破題：計算完常數項後，你會得到一個關於 $k$ 的簡單一次方程，只需將 $k$ 的係數移項並除以該係數即可求得答案。

誘答項逆向工程

A

計算粗心　符號處理錯誤

學生正確代入 $x=-3$ 但計算時將 $4(-3)^2$ 算成 $36$，接著在合併項時誤將 $-12 - 9 + k(-3)$ 中的常數項 $-12$ 與 $-9$ 加總為 $-21$，再錯誤地移項或解方程導致得到 $-25$。另一可能路徑是計算 $k(-3) = -12 - 4(9) = -48$，然後除以 $-3$ 時誤算為 $+25$（忽略負號）或混淆了 $x^3$ 項的係數影響。
B　✓ 正確答案
C

計算粗心　平方運算錯誤

學生在計算 $4(-3)^2$ 時，正確得出 $36$，但在後續步驟中將 $kx$ 項視為 $+k(3)$ 而非 $k(-3)$，或者在移項解 $k$ 時，錯誤地將等式兩邊除以 $-3$ 後忘記了負號，導致結果為正數 $1$（實際應為 $-1$）。
D

概念錯誤　餘數定理誤用

學生可能錯誤地認為因式是 $x+3$ 意味著根是 $3$ 而非 $-3$，於是代入 $x=3$ 計算：$27 + 36 + 3k - 12 = 0 \Rightarrow 51 + 3k = 0 \Rightarrow k = -17$（非選項），或者更嚴重地完全搞混了因式定理的符號規則，直接將 $k$ 設為某個與常數項無關的值，或是將題目看錯成求 $x=3$ 時的值。另一種可能是學生試圖用長除法但算錯了前兩步，導致最後餘數為零時解出錯誤的 $k$ 值。

速解策略：代入 $x=-3$ 使多項式為零，解得 $-27 + 36 - 3k - 12 = 0 \Rightarrow -3 = 3k \Rightarrow k=-1$
