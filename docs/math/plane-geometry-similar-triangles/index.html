溫習要點同常見題型

平面幾何常要證明全等或相似，再用比例求邊，或者用畢氏定理處理直角三角形。相似比同面積比要分清，面積比係相似比嘅平方。

等腰三角形底角用錯、證明條件寫唔清，係卷一常見失分；卷二則多快速判斷夠唔夠條件。

下面索引有相似、全等同畢氏定理標籤，可以先操識揀定理，再寫完整證明步驟。
