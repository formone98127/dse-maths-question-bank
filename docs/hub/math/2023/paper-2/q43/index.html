題目

當某男生擲一飛鏢時，他擲中目標的概率為 0.6。若這男生擲該飛鏢 4 次，求他擲中目標至少 2 次的概率。

  • A. $0.5248$
  • B. $0.7056$
  • C. $0.8208$
  • D. $0.8464$
WhatsApp 分享Telegram 分享

深度分析

二項分佈　認知層次：應用　建議作答 90 秒

核心公式／定理：P(X=k) = C(n,k)p^k q^{n-k}、P(A U B) = P(A) + P(B)

提示 1（啟發）
定義事件：設 X 為擲中次數，求 P(X>=2)。
提示 2（知識）
分解事件：P(X>=2) = P(X=2) + P(X=3) + P(X=4)，注意這些事件是互斥的。
提示 3（破題）
代入公式計算各項概率後相加，檢查是否遺漏了 X=4 的情況。

誘答項逆向工程

A

計算粗心　誤算互斥事件概率和

計算出 P(2 次) 與 P(3 次) 後，將兩者相乘而非相加，導致結果偏小且無意義。
B

計算粗心　誤算互斥事件概率和

計算出 P(2 次) 與 P(3 次) 後，將兩者相乘而非相加，導致結果偏小且無意義。
C　✓ 正確答案
D

計算粗心　忽略互斥事件性質

直接將 P(2 次) 與 P(3 次) 相加，卻忘記了「至少 2 次」包含 P(4 次)，導致漏算一項。

速解策略：利用二項分佈公式分別計算擲中 2、3、4 次的概率，然後將三者相加即得答案。
