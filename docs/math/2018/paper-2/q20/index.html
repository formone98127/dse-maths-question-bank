喺題庫開啟呢題 · 返回 2018 卷二 全卷

題目

圖中，$ABCD$ 為一正方形。$E$ 為 $AB$ 的延線上的一點使得 $BE=4\text{ cm}$。$BC$ 與 $DE$ 相交於點 $F$。若 $EF=5\text{ cm}$，則 $DF=$

  • A. $12\text{ cm}$
  • B. $15\text{ cm}$
  • C. $16\text{ cm}$
  • D. $20\text{ cm}$

深度分析

相似三角形　認知層次：分析　建議作答 90 秒

核心公式／定理：$\frac{DF}{EF} = \frac{CD}{BE}$ (相似比)、$DE^2 = DF^2 + EF^2$ (畢氏定理)

提示 1（啟發）
觀察圖形中哪兩組線段因為正方形性質而平行？
提示 2（知識）
利用平行線截割定理，找出包含 $DF$、$EF$、$CD$、$BE$ 的相似三角形。
提示 3（破題）
寫出相似比公式後，代入已知數值求解未知邊長。

誘答項逆向工程

A

計算粗心　相似比算錯

學生可能誤以為 $DF/EF = CD/AB$ 或其他錯誤比例，導致計算出 $12$。或是算出正確相似比後，將 $DE$ 長度算錯為 $17$ 再減去 $5$ 得 $12$（假設 $CD=4$）。
B　✓ 正確答案
C

概念錯誤　混淆相似對應邊

學生可能將 $DF$ 與 $EF$ 的比設為正方形邊長與 $BE$ 的比，但搞混了斜邊與直角邊的對應關係，或是誤用 $CD$ 而非 $BC$。
D

審題不清　忽略單位或讀圖錯誤

學生可能將 $EF=5$ 誤認為是斜邊總長，直接加上某個數字得到 $20$；或是將 $BE=4$ 與 $DF$ 混淆。

速解策略：由 $AB \parallel CD$ 得 $\triangle EBF \sim \triangle DCF$，列式 $\frac{DF}{EF}=\frac{CD}{BE}$ 求解。
