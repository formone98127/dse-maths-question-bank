題目

圖 1 中，$B$ 及 $D$ 分別為 $AC$ 及 $AE$ 上的點。$BE$ 與 $CD$ 相交於點 $F$。已知 $AB=BE$、$BD//CE$、$\angle CAE=30^\circ$ 及 $\angle ADB=42^\circ$。

(a) 求 $\angle BEC$。

(b) 設 $\angle BDC=\theta$。以 $\theta$ 表 $\angle CFE$。

深度分析

平面幾何　認知層次：應用　建議作答 90 秒

核心公式／定理：$\triangle ABC$ 中若 $AB=AC$，則 $\angle B = \angle C$、$BD // CE \implies \angle ABD + \angle ACE = 180^\circ$

提示 1（啟發）
提示 1：在 $\triangle ABE$ 中，因 $AB=BE$，故底角相等，利用外角定理可求頂角相關角度。
提示 2（知識）
提示 2：平行線 $BD // CE$ 意味著 $\angle ABD + \angle ACE = 180^\circ$，請注意方向性。
提示 3（破題）
提示 3：觀察交點 $F$，$\angle CFE$ 與 $\angle BFD$ 為對頂角，大小相等，可透過 $\triangle BDF$ 計算。

速解策略：先由等腰得 $\angle AEB=30^\circ$，再由平行線得 $\angle ACE=180^\circ-\angle ABD$，最後用外角定理連結 $\theta$ 與 $\angle CFE$
