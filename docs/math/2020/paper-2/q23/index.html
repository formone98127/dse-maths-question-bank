題目

某船位於燈塔以西 $50\, \text{km}$ 。若該船沿 $S60^\circ E$ 方向移動，求該船與燈塔間的最短距離。

  • A. $20\, \text{km}$
  • B. $25\, \text{km}$
  • C. $43\, \text{km}$
  • D. $87\, \text{km}$

深度分析

三角學應用 (方向角與直角三角形)　認知層次：應用　建議作答 60 秒

核心公式／定理：$\sin(90^\circ-\theta) = \cos\theta$、$d = r\cos\alpha$

提示 1（啟發）
畫出燈塔與船的初始位置圖，標記方向角 $S60^\circ E$ 的幾何意義。
提示 2（知識）
回憶「最短距離」在幾何上的定義：點到直線的垂線段長度。
提示 3（破題）
將方向角轉換為直角三角形中的內角，利用鄰邊關係求解。

誘答項逆向工程

A

概念錯誤　混淆角度定義

將 $S60^\circ E$ 誤解為與正東方向夾角 $60^\circ$，導致計算出錯。
B　✓ 正確答案
C

計算粗心　三角函數值計算錯誤

正確建立模型但計算 $\cos 30^\circ$ 時出錯，或誤用 $\sin 60^\circ$ 為 $0.5$
D

策略錯誤　錯誤使用餘弦定理

未意識到最短距離即垂線，直接對 $50\text{km}$ 與角度進行無意義的餘弦運算。

速解策略：將 $S60^\circ E$ 轉化為與正北夾角 $30^\circ$，最短距離即 $50\cos 30^\circ$
