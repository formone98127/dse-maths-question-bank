題目

已知 $f(x)$ 爲兩部分之和，一部分隨 $x^2$ 正變，而另一部分為常數。假定 $f(2)=59$ 及 $f(7)=-121$。

(a) 求 $f(6)$。

(b) $A(6,a)$ 及 $B(-6,b)$ 均為 $y=f(x)$ 的圖像上的點。求 $\Delta ABC$ 的面積，其中 $C$ 爲 $x$ 軸上的一點。

深度分析

函數建模　認知層次：應用　建議作答 180 秒

核心公式／定理：$f(x) = ax^2 + c$、$\text{Area} = \frac{1}{2} \times \text{base} \times \text{height}$

提示 1（啟發）
先利用 $f(x)$ 隨 $x^2$ 正變及常數特性設出通式。
提示 2（知識）
注意 (b) 問中 C 點僅在 x 軸上，並非固定點。
提示 3（破題）
思考：若 C 點移動，三角形面積是否改變？（提示：底邊 AB 水平時高為定值）

速解策略：設 $f(x)=ax^2+c$ 解出係數後，發現 A、B 兩點 y 座標相同，故 AB 為水平線段，C 在 x 軸上，高即為 $|y_A|$。
