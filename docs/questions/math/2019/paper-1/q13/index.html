2019 DSE 數學 P1 Q13 答案＋詳解

題目（中文卷）

圖 1 中，$O$ 為圓 $ABCDE$ 的圓心。$AC$ 為該圓的一直徑。$BD$ 與 $OC$ 相交於點 $F$。已知 $\angle AED = 115^\circ$。

(a) 求 $\angle CBF$。

(b) 假定 $BC \parallel OD$ 及 $OB = 18\, \text{cm}$。扇形 $OBC$ 的周界是否少於 $60\, \text{cm}$？試解釋你的答案。

English version（英文卷題目）

In Figure 1, ( O ) is the centre of circle ( ABCDE ). ( AC ) is a diameter of the circle. ( BD ) and ( OC ) intersect at the point ( F ). It is given that ( \angle AED = 115^\circ ).

(a) Find ( \angle CBF ). (3 marks)

(b) Suppose that ( BC \parallel OD ) and ( OB = 18 \text{ cm} ). Is the perimeter of the sector ( OBC ) less than ( 60 \text{ cm} )? Explain your answer. (5 marks)

Answers written in the margins will not be marked.
