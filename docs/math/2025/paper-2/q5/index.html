題目

設 $k$ 為一常數。解方程 $x^2+4x=k^2-2k-3$ 。

  • A. $x=k-3$ 或 $x=-k-1$
  • B. $x=k-3$ 或 $x=-k+1$
  • C. $x=k+3$ 或 $x=-k-1$
  • D. $x=k+3$ 或 $x=-k+1$

深度分析

一元二次方程式　認知層次：應用　建議作答 60 秒

核心公式／定理：(x+a)^2 = x^2+2ax+a^2

提示 1（啟發）
觀察方程左側 x^2+4x，思考如何配成完全平方 (x+a)^2 的形式。
提示 2（知識）
將方程兩邊同時加上常數完成配方，並利用 (k-1)^2 = k^2-2k+1 簡化右側。
提示 3（破題）
對兩邊開平方時，記得考慮正負兩個根，並檢查選項中符號的對應關係。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　符號錯誤

配方後得 (x+2)^2 = k^2-2k+1，開方時誤將右側 -2k 處理成 +k 或開方時符號搞混，導致 -k+1
C

計算粗心　配方法錯誤

配方時忽略左側加 4，直接將右側 k^2-2k-3 當作 (x+?)^2 展開，導致常數項符號與係數全錯
D

計算粗心　開方符號錯誤

配方正確但開方時，將 ±(k-1) 誤寫成 -k+1 與 -k-1 混合，未注意正負號對應關係

速解策略：配方得 (x+2)^2=(k-1)^2，開方即 x+2=±(k-1)，移項整理即可。
