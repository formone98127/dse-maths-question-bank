題目

設 $ A $ 為直線 $ 9x + 4y - 7 = 0 $ 與直線 $ 9x - 4y + 7 = 0 $ 的交點。若 $ P $ 為直角坐標平面上的一動點使得 $ P $ 與 $ A $ 間的距離為 8 ，則 $ P $ 的軌跡為一

  • A. 圓。
  • B. 三角形。
  • C. 四邊形。
  • D. 正六邊形。

深度分析

直線與圓的幾何性質　認知層次：理解　建議作答 45 秒

核心公式／定理：$Ax + By + C = 0$、$d(P, L) = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$

提示 1（啟發）
回想平面幾何中，滿足「到某一定點距離等於定長」的所有點的集合被稱為什麼圖形？
提示 2（知識）
先求出兩直線 $9x + 4y - 7 = 0$ 與 $9x - 4y + 7 = 0$ 的唯一交點 $A$ 的座標。
提示 3（破題）
根據題目條件，動點 $P$ 到定點 $A$ 的距離恆為 $8$，這直接對應了哪種基本圖形的定義？

誘答項逆向工程

A　✓ 正確答案
B

概念錯誤　誤以為軌跡是線段或封閉多邊形

學生可能混淆了兩直線交點與動點的關係，錯誤地認為 P 只能在有限區域移動，將圓的一部分誤解為三角形。
C

概念錯誤　過度複雜化幾何形狀

學生可能試圖用直線切割圓的思維，錯誤地推導出四邊形，忽略了「距離為定值」在平面上的定義是完整的圓。
D

概念錯誤　無根據的圖形假設

學生可能將此題與正多邊形相關題目混淆，或錯誤地認為兩條直線對稱性會產生正六邊形，完全脫離距離定義。

速解策略：求兩直線交點 A，由 PA=8 知 P 軌跡為以 A 為圓心、8 為半徑之圓。
