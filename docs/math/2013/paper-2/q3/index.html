喺題庫開啟呢題 · 返回 2013 卷二 全卷 · English version

題目

$h\ell-k\ell+hm-km-hn+kn=$

  • A. $(h+k)(\ell-m+n)$。
  • B. $(h+k)(\ell+m-n)$。
  • C. $(h-k)(\ell-m+n)$。
  • D. $(h-k)(\ell+m-n)$。

深度分析

因式分解　認知層次：分析　建議作答 60 秒

核心公式／定理：$ab+ac= a(b+c)$、$-(ab+ac)= -a(b+c)$

提示 1（啟發）
觀察式子中有四項，試著將含有 $\ell$ 的項與不含 $\ell$ 的項分組。
提示 2（知識）
注意每一組中係數的正負號，特別是當提出公因數時，括號內項的符號變化。
提示 3（破題）
將選項 D 展開驗證，看是否能還原回題目原本的式子。

誘答項逆向工程

A

策略錯誤　符號處理錯誤

學生在分組後，將 $-k\ell$ 與 $+hm$ 合併時，錯誤地將負號分配給整個括號 $(h+k)$，導致符號混亂。
B

策略錯誤　符號處理錯誤

學生正確分出 $\ell$ 與 $m$ 的係數，但在處理 $-k\ell+hm$ 時，未能將 $h$ 與 $k$ 合併為 $(h-k)$，而是誤寫為 $(h+k)$。
C

計算粗心　展開驗證失敗

學生選對了 $h-k$ 的結構，但在展開 $(\ell-m+n)$ 時，忘記了 $-k$ 分配給 $n$ 應為 $-kn$，與原題不符。
D　✓ 正確答案

速解策略：前兩項分組：$\ell(h-k)$；後兩項分組：$m(h-k) + n(k-h)$? 不，是 $-mn+kn = n(-m+k)$? 重新觀察：$hm-km-hn+kn = m(h-k) - n(h-k) = (h-k)(m-n)$? 等等，題目是 $hm-km-hn+kn$。分組：$(hm-km) + (-hn+kn) = m(h-k) - n(h-k) = (m-n)(h-k)$。選項 D 是 $(h-k)(\ell+m-n)$? 原題有 $\ell$。重新看題：$h\ell-k\ell+hm-km-hn+kn$。分組：$(h\ell-k\ell) + (hm-km) + (-hn+kn) = \ell(h-k) + m(h-k) - n(h-k) = (h-k)(\ell+m-n)$。
