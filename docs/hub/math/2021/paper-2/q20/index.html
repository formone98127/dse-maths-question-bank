題目

圖中，$ABCD$ 為一正方形。設 $E$ 及 $F$ 分別為 $AB$ 及 $BC$ 上的點使得 $AE=3BE$ 且 $\angle DEF=90^\circ$ 。若 $\triangle DEF$ 的面積為 $25\, \text{cm}^2$ ，則 $\triangle CDF$ 的面積為

  • A. $48\, \text{cm}^2$ 。
  • B. $50\, \text{cm}^2$ 。
  • C. $52\, \text{cm}^2$ 。
  • D. $75\, \text{cm}^2$ 。

深度分析

幾何相似與三角比　認知層次：應用　建議作答 180 秒

核心公式／定理：\triangle ADE \sim \triangle BEF、\text{Area} = \frac{1}{2} \times \text{base} \times \text{height}

提示 1（啟發）
觀察 \angle A = \angle B = \angle DEF = 90^\circ，推斷 \triangle ADE 與 \triangle BEF 是否相似？
提示 2（知識）
利用相似三角形對應邊成比例，設 AD=x，表示出 DE 與 EF 的長度關係。
提示 3（破題）
由 \triangle DEF 面積求出 x 後，再計算 \triangle CDF 的底 CF 與高 CD 來求面積。

誘答項逆向工程

A

計算粗心　邊長比例計算錯誤

算出 DE=5x 後，誤以為 DF=48，未考慮相似比 k=1.2 對面積的影響，直接將 DE 長度當作面積數值或混淆了線段與面積單位。
B

策略錯誤　忽略相似比平方關係

正確算出 DE=5x 與 BEF 面積，但求 CDF 時，未利用相似比 k^2 轉換邊長，而是直接假設 DF 長度為某個整數值導致結果偏差。
C　✓ 正確答案
D

概念錯誤　相似比應用錯誤

誤認為 \triangle DEF 與 \triangle CDF 面積比等於邊長比而非平方比，或錯誤地將 \triangle ADE 的面積直接加總而未扣除重疊部分。

速解策略：證相似得比例 k=1.2，算出 DE，進而得 DF，最後用底乘高除以二求積。
