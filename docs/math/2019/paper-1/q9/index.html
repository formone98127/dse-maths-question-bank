題目

某兩球體的體積之和為 $324\pi\ \text{cm}^3$。較大的球體的半徑等於較小的球體的直徑。以 $\pi$ 表 (a) 較大的球體的體積， (b) 該兩球體的表面面積之和。 (5 分)

深度分析

立體幾何　認知層次：應用　建議作答 180 秒

核心公式／定理：$V = \frac{4}{3}\pi r^3$、$A = 4\pi r^2$

提示 1（啟發）
Hint1: 設未知數時，利用直徑與半徑關係簡化變數。
提示 2（知識）
Hint2: 記住球體體積是 $\frac{4}{3}\pi r^3$，表面積是 $4\pi r^2$。
提示 3（破題）
Hint3: 先解出半徑 r，再分別代入兩個公式計算。

速解策略：設小球半徑 r，大球 2r。體積和方程化簡得 r=6。大球體積 $4\pi(12)^3$，表面積和 $4\pi(2r)^2 + 4\pi r^2$
