Question

Denote the origin by ( O ).

(a) ( A ) and ( B ) are points lying on the positive ( x )-axis such that the ( x )-coordinate of ( A ) is greater than the ( x )-coordinate of ( B ). A vertical line which passes through ( B ) cuts the straight line ( y = mx ) at the point ( C ) such that ( AB = BC ), where ( m ) is a positive constant. Let ( D ) be a point such that ( ABCD ) is a square. Express the slope of ( OD ) in terms of ( m ). (3 marks)

(b) The coordinates of the points ( M ) and ( N ) are ( (6, 5) ) and ( (10, 0) ) respectively. Let ( P ) and ( Q ) be points lying on ( OM ) and ( MN ) respectively while ( R ) and ( S ) be points lying on the ( x )-axis. If the quadrilateral ( PQRS ) is a square, find the ( x )-coordinate of ( P ). (4 marks) Please stick the barcode label here.

直線方程與坐標幾何　認知層次：應用　建議作答 300 秒

核心公式／定理：$m = \frac{y_2 - y_1}{x_2 - x_1}$、$\text{Area} = s^2$、$\tan \theta = \frac{\text{對邊}}{\text{鄰邊}}$

提示 1（啟發）
Hint1: 先畫出 (a) 部分草圖，標註 $A,B,C,D$ 相對位置，確認 $AB=BC$ 的向量意義。
提示 2（知識）
Hint2: 正方形相鄰邊斜率乘積為 -1，且邊長相等，可透過向量旋轉或相似比求解。
提示 3（破題）
Hint3: (b) 部分關鍵在於將 $P$ 點坐標設為 $(x, y)$，利用 $OM$ 直線方程連結 $x,y$。

速解策略：先由 (a) 推導通用斜率公式，再代入 (b) 的具體數值；善用相似三角形比例代替複雜坐標運算。
