題目

點 $ P $ 、點 $ Q $ 及點 $ R $ 的極坐標分別為 $ (3, 160^\circ) $ 、$ (4, 280^\circ) $ 及 $ (6, 340^\circ) $ 。由 $ Q $ 至 $ PR $ 的垂直距離為

  • A. $ 2 $
  • B. $ 3 $
  • C. $ 2\sqrt{3} $
  • D. $ 3\sqrt{3} $

深度分析

極坐標與直角坐標轉換　認知層次：應用　建議作答 180 秒

核心公式／定理：$x = r \cos \theta$、$y = r \sin \theta$、$d = \frac{|Ax_0 + By_0 + C|}{\sqrt{A^2+B^2}}$

提示 1（啟發）
第一步：利用公式 $x=r\cos\theta, y=r\sin\theta$ 將 P、R 的極坐標轉換為直角坐標，並觀察其幾何特徵。
提示 2（知識）
第二步：由 P、R 兩點求出直線 PR 的斜率與一般式方程 $Ax+By+C=0$。
提示 3（破題）
第三步：代入 Q 點直角坐標至點到直線距離公式進行計算。

誘答項逆向工程

A

計算粗心　忽略根號或角度轉換錯誤

學生可能正確算出 P( -3/2, 3√3/2 )，但在計算直線斜率時將 60° 誤認為 30° 導致斜率為 1/√3，最終距離算成 2。
B

概念錯誤　混淆角度與半徑關係

學生可能誤以為 Q(4, 280°) 到 PR 的距離等於 Q 到原點距離減去某固定值，或錯誤地將 30° 角對應的邊長直接當作答案 3。
C　✓ 正確答案
D

計算粗心　斜率符號或分母計算錯誤

學生可能正確轉換坐標，但在求直線方程時，將 $\sqrt{3}$ 的係數搞錯符號或大小，導致分子分母約分後多餘一個根號。

速解策略：先轉 P,R 為直角坐標，發現 PR 垂直於 x 軸或斜率固定，再代公式求距。
