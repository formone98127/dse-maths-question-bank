題目

圖中, 直線 $ L_1 $ 及直線 $ L_2 $ 的方程分別為 $ x + ay + b = 0 $ 及 $ bx + y + c = 0 $ 。下列何者正確? I. $ c < 0 $ II. $ ab < 1 $ III. $ ac < b $

  • A. 只有 I 及 II
  • B. 只有 I 及 III
  • C. 只有 II 及 III
  • D. I 、II 及 III

深度分析

直線方程式與不等式　認知層次：分析　建議作答 90 秒

核心公式／定理：直線一般式 $Ax + By + C = 0$ 的斜率為 $-A/B$、y 軸截距公式 $C/B$

提示 1（啟發）
觀察圖形中直線與 x 軸、y 軸的交點位置，判斷截距 $b, c$ 的正負號。
提示 2（知識）
將兩直線方程化為斜截式 $y=mx+k$，比較斜率大小以驗證 $ab < 1$ 是否成立。
提示 3（破題）
利用 $L_2$ 的截距關係 $b = -c - ac$，結合已知符號判斷 $ac < b$ 的真偽。

誘答項逆向工程

A　✓ 正確答案
B

概念錯誤　忽略III

學生正確判斷I與II，但誤以為 $ac < b$ 成立。可能未將 $b=-c-ac$ 代入比較大小，或錯誤認為截距關係直接導出此不等式。
C

概念錯誤　忽略I

學生正確判斷II與III，但忽略了 $c < 0$。可能誤判 $L_2$ 的 y 軸截距符號，或未能從圖形看出直線與 y 軸交點在負半軸。
D

概念錯誤　忽略I與II

學生認為三個陳述皆成立，可能未仔細檢查 $L_1$ 斜率絕對值大於 1 的條件，導致錯誤推導出 $ab < 1$。

速解策略：由圖得 $b<0, c<0$ (I對)；斜率比較得 $ab<1$ (II對)；代入關係式檢驗 III 錯。
