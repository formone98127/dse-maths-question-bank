Question

It is given that $\log_a y$ is a linear function of $x$, where $0 < a <1$. The intercepts on the vertical axis and on the horizontal axis of the graph of the linear function are 6 and 3 respectively. If $y = mn^x$, which of the following is/are true? I. $m <1$ II. $n <1$ III. $mn^3 = 1$

  • A. I only
  • B. II only
  • C. I and III only
  • D. II and III only

Answer

Correct answer: C. I and III only

展開中文深度分析（Open detailed analysis）

深度分析

對數函數與指數函數的性質　認知層次：分析　建議作答 120 秒

核心公式／定理：$\log_a(mn^x) = \log_a m + x\log_a n$、$y = mx+c$ 的截距定義

提示 1（啟發）
將 $y=mn^x$ 代入對數式後，利用對數性質展開成關於 $x$ 的線性方程式形式。
提示 2（知識）
觀察垂直截距（當 $x=0$）與水平截距（當 $y=0$）對應的方程式條件。
提示 3（破題）
結合 $0<a<1$ 時對數函數的減函数特性，判斷係數符號與大小關係。

誘答項逆向工程

A

概念錯誤　忽略截距條件導致 m>1

學生誤以為只要指數函數底數小於 1，則 m 必小於 1。未考慮垂直截距 $\log_a m = 6$ 且 $0<a<1$ 時，m 必須大於 1 才能使對數為正數。
B

概念錯誤　誤解水平截距與 n 的關係

學生未能正確利用水平截距 $x=3$ 時 $y=0$ 的條件。若忽略此條件，會錯誤地認為 n 的範圍僅由 $0<a<1$ 決定，而忽略了 $\log_a m + 3\log_a n = 0$ 的限制。
C　✓ 正確答案
D

計算粗心　計算 m 與 n 關係時出錯

學生正確推導出 $m>1$，但在處理水平截距條件時，錯誤地得出 $mn^3=1$ 不成立。可能是將 $\log_a(mn^3)=0$ 誤算為其他形式，或混淆了對數運算規則。

速解策略：展開對數得 $y = \log_a m + x\log_a n$，利用截距解出 $m, n$ 關係並判斷不等式。
