題目

圖中所示為 $y=a(x+b)^2$ 的圖像，其中 $a$ 及 $b$ 均為常數。下列何者正確？

  • A. $a<0$ 及 $b<0$
  • B. $a<0$ 及 $b>0$
  • C. $a>0$ 及 $b<0$
  • D. $a>0$ 及 $b>0$

深度分析

二次函數圖形特性　認知層次：理解　建議作答 45 秒

核心公式／定理：y = a(x + b)^2 的頂點為 (-b, 0)、a > 0 時開口向上，a < 0 時開口向下

提示 1（啟發）
觀察拋物線的開口方向，判斷係數 a 的正負。
提示 2（知識）
回憶頂點式 y=a(x+b)^2 的頂點坐標公式為何？
提示 3（破題）
將圖形與 x 軸交點（頂點）的橫座標與 b 的符號建立關聯。

誘答項逆向工程

A

概念錯誤　頂點坐標誤判

學生認為圖形向右移代表 b<0，混淆了 (x+b) 中 b 的符號與平移方向的關係。
B

概念錯誤　頂點坐標誤判

學生正確判斷 a>0，但錯誤地認為圖形向右移代表 b<0，導致符號判斷出錯。
C

概念錯誤　頂點坐標誤判

學生認為圖形向右移代表 b>0，但同時錯誤地判斷 a<0（可能看錯開口方向）。
D　✓ 正確答案

速解策略：開口向上則 a>0；頂點在 x 軸正半軸 (-b>0) 故 b<0，選 D。
