Question

The solution of $4y+1<5y-3\leq8y-9$ is

  • A. $y>-4$
  • B. $y\geq-2$
  • C. $y\geq2$
  • D. $y>4$

Answer

Correct answer: D. y>4

深度分析

複合不等式　認知層次：應用　建議作答 60 秒

核心公式／定理：$a < b \leq c \iff a < b \text{ 且 } b \leq c$、$y > -4$ 且 $y \geq -2$

提示 1（啟發）
複合不等式 $A < B \leq C$ 代表同時滿足 $A < B$ 與 $B \leq C$ 兩個條件。
提示 2（知識）
請分別解這兩個一元一次不等式，並畫數線圖觀察重疊區域。
提示 3（破題）
注意不等號方向：小於號 ($<$) 對應開圓圈，小於等於號 ($\leq$) 對應實心點。

誘答項逆向工程

A

審題不清　忽略右側限制條件

只解了 $4y+1<5y-3$ 得到 $y>-4$，忘記檢查 $5y-3\leq8y-9$ 的限制。
B

計算粗心　移項變號錯誤

解 $5y-3\leq8y-9$ 時，將 $-3$ 移到右邊變成 $+3$，但 $-9$ 移到左邊忘了變號或計算出錯。
C

概念錯誤　混淆不等號方向

解出 $y\geq2$ 後，誤以為這是唯一解，或是將兩個不等式解集取並集而非交集。
D　✓ 正確答案

速解策略：拆成 $4y+1<5y-3$ 與 $5y-3\leq8y-9$，解出交集即為答案。
