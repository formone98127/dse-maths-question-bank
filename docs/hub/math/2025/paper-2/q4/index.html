題目

若 $(3c+1)(d-4)=2d(5c-1)$ ，則 $c=$

  • A. $\frac{3d-4}{7d+12}$ 。
  • B. $\frac{3d+4}{7d-12}$ 。
  • C. $\frac{7d-12}{3d+4}$ 。
  • D. $\frac{7d+12}{3d-4}$ 。
WhatsApp 分享Telegram 分享

深度分析

一元一次方程式與變數移項　認知層次：分析　建議作答 60 秒

核心公式／定理：分配律 (FOIL)、一元一次方程式解法公式 $x = \frac{b}{a}$

提示 1（啟發）
提示 1：請先將方程式左右兩邊完全展開，消除括號。
提示 2（知識）
提示 2：將所有含有 $c$ 的項移到一側，不含 $c$ 的項移到另一側，並合併同類項。
提示 3（破題）
提示 3：整理成 $A \cdot c = B$ 的形式後，即可寫出 $c = \frac{B}{A}$。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　展開時符號錯誤

左邊展開 $3cd - 12c + d - 4$，右邊 $10cd - 2d$。移項得 $-7cd + 8d - 12c - 4 = 0$。若將 $-12c$ 錯算為 $+12c$ 或移項時符號弄反，會得到 $3d+4$ 在分子的情況。
C

策略錯誤　倒數關係混淆

算出正確結果後，忘記題目要求解 $c$ 而非 $\frac{1}{c}$，或是將方程式兩邊取倒數時未考慮整體結構，直接將係數互換。
D

計算粗心　移項後符號全反

在合併 $cd$ 項時，將 $-7cd$ 錯記為 $+7cd$，導致分母變成 $3d-4$，且分子符號也隨之錯誤。

速解策略：展開兩邊 -> 移項歸類含 $c$ 與不含 $c$ 的項 -> 除以 $c$ 的係數。
