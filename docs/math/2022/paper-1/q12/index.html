題目

圓 $C$ 的方程為 $x^2 + y^2 - 154x - 128y + 224 = 0$。將 $C$ 的圓心記為 $G$。點 $H$ 的坐標為 $(65, 48)$。

(a) 求 $G$ 與 $H$ 間的距離。

(b) 設 $P$ 為 $C$ 上的一動點。當 $\triangle GHP$ 的面積最大時，

(i) 描述 $GH$ 與 $GP$ 之間的幾何關係；

(ii) 求 $\triangle GHP$ 的周界。 請在此貼上電腦條碼

| | | | | | | | | | | | | | | | | | | | | | | | | | | | | | |

深度分析

圓的方程　認知層次：應用　建議作答 300 秒

核心公式／定理：$x^2 + y^2 + 2gx + 2fy + c = 0 \Rightarrow (g, f)$、$d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$、$Area = \frac{1}{2} \times base \times height$

提示 1（啟發）
提示：圓的一般方程 $x^2+y^2+2gx+2fy+c=0$ 中，圓心為 $(-g, -f)$。
提示 2（知識）
提示：三角形面積 = \frac{1}{2} \times 底 \times 高，當底邊 GH 固定時，如何使高最大？
提示 3（破題）
提示：當高最大時，P 點位於哪條直線上？這條線與圓心 G 有何關係？

速解策略：先配方得圓心 G，算出半徑 r 及 GH 距離。面積最大時 P 在 GH 延長線上，周界為 GH+r+HP。
