題目

求常數 $k$ 使得直線 $3x + 2y + k = 0$ 與直線 $kx + 12y - 6 = 0$ 互相垂直。

  • A. $-8$
  • B. $-4$
  • C. $4$
  • D. $8$
WhatsApp 分享Telegram 分享

深度分析

直線垂直條件與斜率　認知層次：分析　建議作答 45 秒

核心公式／定理：若 $ax+by+c=0$，則斜率 $m=-\frac{a}{b}$、兩直線垂直時 $m_1 \times m_2 = -1$

提示 1（啟發）
回憶一次方程式 $ax+by+c=0$ 的斜率公式為何？
提示 2（知識）
兩條直線互相垂直時，它們的斜率 $m_1$ 與 $m_2$ 必須滿足什麼數值關係？
提示 3（破題）
將求得的斜率代入垂直條件，解出常數 $k$ 的值。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　斜率計算錯誤

算出 $m_1=-\frac{3}{2}$ 與 $m_2=-\frac{k}{12}$，但將乘積設為 $1$ 而非 $-1$，解得 $k=4$
C

計算粗心　符號處理失誤

正確列出 $(-\frac{3}{2}) \times (-\frac{k}{12}) = -1$，但在化簡時錯誤約分或移項，導致得出 $k=4$
D

概念錯誤　垂直條件混淆

誤以為兩直線平行時才用斜率乘積為 $-1$，或是將第二條直線斜率算成 $\frac{k}{12}$

速解策略：先求兩直線斜率，再利用 $m_1 m_2 = -1$ 建立方程式求解 $k$
