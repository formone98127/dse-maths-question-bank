Question

(a) Solve the inequality $\frac{7x + 26}{4} \leq 2(3x - 1)$. (b) Find the number of integers satisfying both inequalities $\frac{7x + 26}{4} \leq 2(3x - 1)$ and $45 - 5x \geq 0$. (4 marks)

深度分析

一元一次不等式　認知層次：應用　建議作答 120 秒

核心公式／定理：$\frac{A}{B} \leq C \implies A \leq BC$ (當 $B>0$)、$45-5x \geq 0 \implies x \leq 9$

提示 1（啟發）
先專注解出第一個不等式的 $x$ 範圍。
提示 2（知識）
第二個不等式是簡單的線性不等式，注意除負數要變號。
提示 3（破題）
最後步驟是數數，記得包含兩端點（閉區間）。

速解策略：先解出兩個 $x$ 範圍，取交集後直接用「大減小加一」公式計算整數個數。
