點樣用呢頁筆記

以下按課程常見嘅三個主題，用自己嘅話整理溫習線索。呢啲唔係官方課程指引摘要，亦唔取代教科書或內地考察經歷。讀每個主題時，練習用「事實概念 + 一個具體例子 + 對香港／國家／世界嘅意義」去記，考試先容易寫得準。

主題一：香港特別行政區的「一國兩制」

呢個主題要求你理解香港作為國家不可分離部分，點樣喺「一國兩制」之下運作。溫習時可分成幾條線，而唔好背散亂時事：

  • 憲制秩序：憲法同《基本法》構成香港特區嘅憲制基礎；「一國」係前提，「兩制」係喺呢個前提下保持香港既有制度同生活方式。
  • 政權機構同法治：行政、立法、司法之間嘅關係，同特區政府依法施政。答題時用準確名稱，避免口語化空話。
  • 權利同義務：居民依法享有權利，亦有維護國家安全同遵守法律嘅責任。討論權利時要同時見到法律框架。
  • 國家安全同發展：理解維護國家安全同香港繁榮穩定之間嘅關係，用規範概念去寫，而唔好改寫成個人宣洩。
  • 參與同治理：認識特區嘅公共事務參與途徑，以及青年同社會喺建設香港中可以扮演嘅角色。

主題二：改革開放以來的國家

焦點係 1978 年以來國家喺政治、經濟、社會同對外關係上嘅發展路徑。建議按「改革開放前嘅背景—政策方向—具體領域變化—對香港同世界嘅意義」去整理。

  • 發展道路：理解中國特色社會主義發展階段，以及改革開放點樣改變生產力同人民生活。
  • 經濟同民生：工業化、城市化、科技創新、脫貧同共同富裕等議題，要用可觀察嘅改變去說明，而唔好只寫「進步咗好多」。
  • 國家治理同法治建設：認識國家機構同政策如何應對大型治理課題。
  • 文化自信同民族關係：尊重中華文化同各族群共同發展，避免刻板印象。
  • 香港同國家發展：把握香港喺國家發展大局中嘅功能，例如專業服務、國際聯繫同創新科技合作等，用具體領域去寫。

主題三：互聯相依的當代世界

呢個主題睇當代世界點樣因為經濟、科技、公共衛生、環境同國際組織而互相影響。答題時要同時見到機遇同風險，避免單一故事。

  • 經濟全球化：貿易、產業鏈、金融流動可以帶來增長，亦可能放大衝擊。要用「互相依賴」去解釋，而唔係只讚或只罵全球化。
  • 科技同資訊：科技加速交流，亦帶來網絡安全、私隱同數碼鴻溝等課題。
  • 公共衛生同環境：流行病、氣候變化同可持續發展，說明單一地區難以獨自解決。
  • 國際合作同秩序：認識國際組織同多邊合作嘅功能同限制，評論時要有根據。
  • 青年同世界：理解全球議題點樣影響日常生活，並思考負責任參與嘅方式。

跨主題連結

公開卷常常用一組資料同時觸及本地、國家同世界。溫習時預先準備兩至三個可以橫跨主題嘅例子，例如公共衛生事件、科技合作或經貿聯繫，但例子要服務題目，唔好硬套。答題步驟見資料回應技巧。
