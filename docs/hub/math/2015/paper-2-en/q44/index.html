Question

Bag $ P $ contains 2 red balls and 4 green balls while bag $ Q $ contains 1 red ball and 3 green balls. If a bag is randomly chosen and then a ball is randomly drawn from the bag, find the probability that a green ball is drawn.

  • A. $\dfrac{3}{10}$
  • B. $\dfrac{7}{10}$
  • C. $\dfrac{7}{24}$
  • D. $\dfrac{17}{24}$
Share on WhatsAppShare on Telegram

Answer

Correct answer: D. \dfrac{17}{24}

深度分析

條件機率與全機率定理　認知層次：應用　建議作答 120 秒

核心公式／定理：P(A) = P(A|B)P(B) + P(A|C)P(C)

提示 1（啟發）
思考：先選袋子再選球，這是一個分步實驗。請畫出樹狀圖，標註每一條分支的機率。
提示 2（知識）
知識：全機率定理公式為 P(綠) = P(袋 P)×P(綠|袋 P) + P(袋 Q)×P(綠|袋 Q)。
提示 3（破題）
提示：計算時請注意分母應為總可能結果數，或是將兩部分的機率加權平均後得到最終答案。

誘答項逆向工程

A

計算粗心　忽略袋數權重

只計算單一袋子抽到綠球的機率 (3/5)，然後直接除以總球數 10，得到 3/10，完全忽略了選擇袋子的隨機性。
B

計算粗心　簡單相加錯誤

將兩袋抽到綠球的機率 (3/5 + 1/4) 直接相加，得到 17/20，再誤以為是總機率，或混淆了分母處理方式。
C

策略錯誤　分母定義錯誤

計算出分子為 7 (正確有利結果數)，但分母錯誤地設為兩袋球數之和的某種誤算，或將總樣本空間誤認為 24。
D　✓ 正確答案

速解策略：先選袋 (各半)，再乘該袋抽綠球機率，兩者相加即得總機率。
