題目

圖中，$T A$ 為圓 $A B C D E$ 在點 $A$ 的切線。$B C$ 的延線與 $E D$ 的延線相交於點 $P$ 。若 $\angle A C B=43^{\circ}$ ，$\angle D A T=55^{\circ}$ 及 $\angle C P D=29^{\circ}$ ，則 $\angle C B E=$

  • A. $64^{\circ}$
  • B. $69^{\circ}$
  • C. $72^{\circ}$
  • D. $78^{\circ}$

深度分析

圓的幾何性質 (切線、弦切角、圓內接四邊形)　認知層次：應用　建議作答 90 秒

核心公式／定理：$\text{弦切角} = \frac{1}{2}\text{夾弧所對圓周角}$、$\triangle ABC$ 中 $AB=AC \implies \angle ABC = \angle ACB$、$\angle CBE + \angle ACD = 180^\circ$

提示 1（啟發）
觀察圖形，利用圓的半徑相等性質找出等腰三角形 $\triangle ABC$ 的底角關係。
提示 2（知識）
回憶弦切角定理：切線與弦夾角等於該弦所對弧之圆周角（即 $\angle ACD$）。
提示 3（破題）
考慮四邊形 $ACDE$ 為圓內接四邊形，其對角互補性質如何幫助求 $\angle CBE$？

誘答項逆向工程

A

計算粗心　角度加減錯誤

算出 $\angle ACD=78^\circ$ 後，誤以為目標角即為此值，或計算 $180-78$ 時算錯成 $64$。
B　✓ 正確答案
C

概念錯誤　混淆圓內接四邊形性質

誤認為 $\angle CBE$ 與 $\angle ACD$ 互餘或相等，未應用對角互補性質。
D

審題不清　忽略弦切角定義

直接使用 $\angle D A T=55^\circ$ 作為弦切角，未考慮 $T A$ 是切線且夾弧應為 $A D$。

速解策略：先由等腰三角形求 $\angle ABC$，再用弦切角定理求 $\angle ACD$，最後利用圓內接四邊形對角互補求 $\angle CBE$。
