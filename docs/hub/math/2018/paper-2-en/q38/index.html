Question

For $0^{\circ}\le x<360^{\circ}$, how many roots does the equation $6\cos^{2}x=\cos x+5$ have?

  • A. $2$
  • B. $3$
  • C. $4$
  • D. $5$
Share on WhatsAppShare on Telegram

Answer

Correct answer: B. 3

深度分析

三角函數方程　認知層次：分析　建議作答 90 秒

核心公式／定理：$\cos(2x) = 2\cos^2 x - 1$、$\cos(2x) + \cos x - 5 = 0$

提示 1（啟發）
嘗試利用恆等式 $2\cos^2 x - 1 = \cos(2x)$ 將原方程轉換為關於 $2x$ 的形式。
提示 2（知識）
回憶餘弦函數 $y=\cos \theta$ 在 $0^\circ \leq \theta < 360^\circ$ 的圖形特徵，特別是負值解的數量。
提示 3（破題）
先求出一元二次方程的兩個根 $\cos x = k_1, k_2$，再分別檢查每個 $k$ 值在指定範圍內對應幾個角度。

誘答項逆向工程

A

計算粗心　忽略解的數量

算出 $\cos x$ 的值後，只考慮到一個有效解（例如 $x=60^\circ$），忘記了餘弦函數在 $0^\circ$ 至 $360^\circ$ 間通常有兩個解的性質。
B　✓ 正確答案
C

概念錯誤　誤判解的範圍

將 $\cos x = -1$ 視為無解，或者錯誤地認為 $\cos x = -2/3$ 在該區間內沒有對應角度，導致漏算。
D

審題不清　範圍理解偏差

誤以為題目要求的是所有實數解（無限多個），或是將 $360^\circ$ 包含在內導致多算一個週期，或者單純猜測數字。

速解策略：利用倍角公式化簡為 $\cos(2x) + \cos x - 5 = 0$，解得 $\cos x = -1$ 或 $-2/3$，再數出對應角度總數。
