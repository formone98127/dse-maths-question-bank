題目

直線 $ L $ 的方程為 $ kx + 4y - 2k = 0 $，其中 $ k $ 為一常數。若 $ L $ 垂直於直線 $ 6x - 9y + 4 = 0 $，求 $ L $ 的 $ y $ 截距。

  • A. $-3$
  • B. $-2$
  • C. 2
  • D. 3

深度分析

直線斜率與垂直條件　認知層次：應用　建議作答 90 秒

核心公式／定理：直線斜率 $m = -A/B$ (由 $Ax+By+C=0$)、兩直線垂直則斜率乘積為 $-1$ ($m_1 m_2 = -1$)、y 截距公式 $c = y - mx$

提示 1（啟發）
提示 1：將直線 $L$ 的方程改寫為斜截式 $y=mx+c$，找出其斜率與 $k$ 的關係。
提示 2（知識）
提示 2：回憶兩直線垂直時，它們斜率的數值關係是什麼？（乘積為 -1）
提示 3（破題）
提示 3：利用求得的 $k$ 值代回原方程，令 $x=0$ 即可直接讀出 $y$ 截距。

誘答項逆向工程

A

計算粗心　斜率計算錯誤導致 k 值偏差

算出 $L$ 斜率為 $-k/4$，已知直線斜率為 $2/3$。垂直時乘積應為 $-1$。若學生誤以為垂直斜率互為相反數或計算 $(-k/4)*(2/3)=-1$ 時算錯，可能解得 $k=6$，代入截距公式得 $c = -3$。
B

計算粗心　垂直條件理解偏差或計算失誤

正確求出 $k=6$，但在代入原方程 $6x+4y-12=0$ 求截距時，令 $x=0$ 得 $4y=12 \Rightarrow y=3$。若學生粗心將 $12/4$ 算成 $-2$ 或符號搞混，會選 B。
C

審題不清　符號處理錯誤

正確求得 $k=6$ 及截距為 $3$。但學生在抄寫答案或閱讀選項時，忽略正負號差異，將正確的 $3$ 誤選為相反數或其他干擾項（此處 C 為 2，可能是計算 $4y-12=0 \Rightarrow y=3$ 時誤算成 $8/4=2$ 等）。更可能的情況是學生算出截距為 3 但看錯選項。
D　✓ 正確答案

速解策略：先由垂直條件求出 k=6，再代入方程令 x=0 解得 y 截距為 3。
