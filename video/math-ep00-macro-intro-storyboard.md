| **02:35 – 03:00** | 以代數為例。初中你學一次方程、簡單因式分解，好似學識寫單字。到高中，二次方程、不等式區域、函數圖像、指數對數——就係把單字砌成句子，再講成故事。**同一條「解未知數」嘅主線，層層加深。** | **縱向進化動畫 A（青藍）**：底部節點 `一次方程` → 向上 Morph 成 `聯立方程` → `二次方程` → `不等式區域` → `函數圖像`。每個升級用 **node grow + color intensify**；箭嘴向上流動（粒子沿箭流動）。鏡頭跟隨主線 **tilt-up**。 |
| **03:00 – 03:25** | 幾何都一樣。初中你量度角度、計面積；高中你要處理圓的性質、坐標幾何、軌跡——由「量得到」進化到「描述得到、證明得到、定位得到」。形狀冇消失，只係加咗坐標同方程呢兩件武器。 | **縱向進化動畫 B（琥珀橙）**：平面圖形 **morph** → 加坐標軸 → 圓方程 `(x-h)²+(y-k)²=r²` 由圓心「生長」出來 → 軌跡虛線掃出一條垂直平分線。文字標籤順序彈出：`量度` → `性質` → `坐標化` → `軌跡`。 |

| **03:50 – 04:05** | 理解咗縱向，真正令 DSE 變難——亦都變有趣——嘅，係 **橫向連結**。考評好鍾意出 **Cross-topic**，即係跨課題題：一條題目同時踩兩個甚至三個星系。 | 全圖 **re-center**。原先暗淡嘅跨星系連線開始 **逐條點亮成金色**。畫面中央浮現大字 **「CROSS-TOPIC」**，下方中文 **「跨課題」** 由字母間隙彈出。鏡頭輕微 **handheld drift** 增加臨場感。 |
| **04:05 – 04:45** | 第一條高頻橋樑：**代數 × 幾何**。例如坐標幾何——你用方程（代數語言）去描述直線同圓（幾何物件）。一見到「求交點」，本質就係聯立方程；一見到「垂直」，斜率相乘係 −1，又係代數條件。**形狀係舞台，方程係劇本。** 好多同學分開溫「直線方程」同「圓」，一到綜合題就懵——因為橋樑冇練。 | **橫向連結演示 1**：左側青藍節點 `方程／斜率` 與右側橙節點 `直線／圓` 拉出 **粗金線**。金線上跑動一個小光點。畫面中央演出迷你動態：直線與圓相交 → 交點閃白 → 同步彈出聯立方程剪影（唔使解，只展示結構）。標語 **「形狀＝舞台｜方程＝劇本」** 底部橫幅滑入。鏡頭 **zoom** 到交點再 **pull back**。 |
| **04:45 – 05:25** | 第二條橋樑，想重點講：**三角學嘅演變**。初中三角，好多時係直角三角形入面嘅 sin、cos、tan——好具體、好「量得到」。高中三角，會走去正弦餘弦定理、方位角應用，甚至三角方程同圖像。你會發現：三角唔再只係「直角嗰科」，而係一套可以處理一般三角形、甚至週期現象嘅工具。再橫向一拉——三角又可以同坐標、面積公式 `½ab sin C` 綁埋一齊。**一條三角線，串起度量同代數。** | **橫向連結演示 2（三角演變）**：直角三角形（初中） **morph** 成一般斜三角形；角 C 高亮，對邊標籤流動。`sin/cos 定義` 節點上移，分叉出 `正弦／餘弦定理` 同 `三角圖像`。金線同時連去 `求積法`（面積公式短暫放大）同 `坐標平面`。鏡頭沿三角演變路徑做 **path-follow camera**（跟隨變形中心）。色溫由暖橙過渡到青藍邊緣，強調跨範疇。 |

| **06:05 – 06:25** | 當你見到呢三條橋——代數同幾何、三角嘅演變、計數同概率——你就開始明白 DSE 出題人嘅邏輯：佢哋唔係要嚇你，而係測試你 **有冇把知識當成網絡，而唔係一櫃一櫃嘅筆記。** | 三條金橋同時 **pulse**；整張星圖短暫變成「神經網絡」觀感（連線密度提升、節點輕微呼吸動畫）。中央金句：**「網絡 > 筆記櫃」** 以打字機效果出現。 |
| **06:25 – 07:05** | 咁 Cross-topic 題通常點「砌」？常見套路大概係咁：前半用一個課題建立條件——例如幾何性質或者函數圖像；後半要求你轉譯成另一個課題去收穫答案——例如方程、不等式、概率。又或者同一情境入面，又要你計長度，又要你處理數據。應付方法唔係死背「邊年出過邊題」，而係練一種本能：**讀完題，先喺腦入面亮起兩盞燈——『呢題主要踩邊兩座星系？橋喺邊？』** | **出題邏輯動態示意**：一張半透明「題卡」由右飛入（虛擬題幹剪影，唔顯示真實試題）。題卡上方兩盞燈依次亮起——青藍一盞、橙一盞；金橋喺兩盞燈之間連上。流程條動畫：`讀題` → `定位星系` → `找橋樑` → `選工具` → `作答`。每步以小節點沿弧線出現。鏡頭維持中景，避免字太多。 |
| **07:05 – 07:25** | 所以由今日起，我希望你溫書時多問自己兩個問題。一：**呢個課題，係由初中邊啲根長出嚟？** 二：**佢同隔籬嗰科，有冇金線？** 你問得多，星圖就會喺你腦入面自己發光。 | 星圖回到完整三色＋金線狀態。兩個問題以問號氣泡分別由左下、右下浮起，再吸附到星圖中心。節點呼吸加快半拍，象徵「內化」。 |
| **07:25 – 07:45** | 呢個系列往後，我哋會按星系同橋樑，一集一集拆解：有時深潛單一課題，有時專門練跨課題轉移。你唔使一次過吞晒整張圖——**帶住地圖行，永遠比起蒙住眼衝更穩。** | 星圖中個別課題節點依次 **spotlight**（預告後續 EP）：例如 `函數`、`三角`、`概率` 短暫放大並顯示「EP.xx」佔位標籤（可用模糊編號）。鏡頭緩慢 **orbit + pull back**，露出系列標題卡底部位置。 |

### 動態原則（必須遵守）
1. **全程以 Knowledge Map 為單一視覺母體**；題卡、公式、圖形皆為星圖上嘅「局部變焦」，唔好切去白底條列投影片。  
2. **Morphing 優先於硬切**：課題進化、圖形轉方程、統計圖轉概率樹，一律用形變過渡。  
3. **色彩即分類**：觀眾應可喺無聲情況下，靠顏色分清三大範疇；金線＝跨課題。  
4. **文字預算**：同屏關鍵字 ≤ 6 個；金句每次只留一句。  
5. **鏡頭語言**：多用 dolly / orbit / path-follow；少用突然 jump-cut。  

### 旁白語速
- 約 **165–180 字／分鐘**（粵語教學偏清晰）；本稿總字數約 **1,350–1,450 字**，配合停頓同畫面停留，總長約 **8 分鐘**。  
- 金句處（「形狀＝舞台｜方程＝劇本」「計數＝骨架｜概率＝血肉」「網絡 > 筆記櫃」）建議 **停半拍** 等畫面。

### 可選 B-roll／音效
- 節點點亮：短促「叮」  
- 金橋接通：低沉 whoosh + soft chime  
- 題卡飛入：紙張滑動質感（輕）  
- 背景：極低調 ambient，唔搶旁白
