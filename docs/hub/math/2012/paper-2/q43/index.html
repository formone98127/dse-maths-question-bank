題目

某戲劇學會由 12 名男生及 8 名女生組成。若從該學會中選出 5 名學生為一隊參加比賽且該隊至少有一名女生，則可組成多少不同的隊？

  • A. 3960
  • B. 14712
  • C. 15448
  • D. 15504

深度分析

組合數學 (排列與組合)　認知層次：應用　建議作答 90 秒

核心公式／定理：${n \choose k} = \frac{n!}{k!(n-k)!}$、$\sum_{k=0}^n {n \choose k} = 2^n$

提示 1（啟發）
Hint 1 啟發：題目要求「至少有一名女生」，直接計算所有情況會很繁瑣，想想有沒有更聰明的方法可以避開這個麻煩？
提示 2（知識）
Hint 2 知識：利用互補計數法，「總組合數」減去「完全不包含女生（即全為男生）」的組合數即可。請列出公式 ${n \choose k}$ 並計算 ${20 \choose 5}$ 與 ${12 \choose 5}$。
提示 3（破題）
Hint 3 破題：關鍵在於正確計算出全男生的組合數 ${12 \choose 5} = 792$，然後從總數 $15504$ 中減去這個數字，注意減法運算的準確性。

誘答項逆向工程

A

概念錯誤　直接計算特定情況

學生可能誤以為只需計算「恰有 1 名女生」的情況：${8 \choose 1} \times {12 \choose 4} = 8 \times 495 = 3960$，忽略了至少一名女生包含 2, 3, 4, 5 名女生的情況。
B　✓ 正確答案
C

計算粗心　總數減去錯誤的補集

學生正確使用了互補法，但計算總組合數時出錯（例如算成 ${20 \choose 5} = 15504$），或者在計算全男生情況時算錯（${12 \choose 5} = 792$），導致 $15504 - 792 = 14712$ 被誤算或混淆。實際上 C 選項 $15448$ 可能是將 ${20 \choose 5}$ 算錯或是減去了錯誤的數字（例如減去 $56$ 或其他小數）。更可能的錯誤過程是：計算總數 ${20 \choose 5} = 15504$，然後誤以為全男生情況不是 $792$ 而是其他值，或者單純加法錯誤。另一種可能是學生計算了「至少 1 女」的各項並加總時算錯：$(8\times495) + (28\times495) + ...$ 累加錯誤。
D

審題不清　忽略「至少」條件直接選總數

學生沒有閱讀題目中的限制條件「至少有一名女生」，直接將所有可能的 5 人隊伍組合數 ${12+8 \choose 5} = {20 \choose 5}$ 當作答案，得出 $15504$。

速解策略：計算總組合 ${20 \choose 5}$ 減去全男生組合 ${12 \choose 5}$。
