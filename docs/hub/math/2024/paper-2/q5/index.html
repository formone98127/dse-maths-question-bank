題目

2 個蘋果和 3 個檸檬的價錢為 $38。若 3 個蘋果和 2 個檸檬的價錢為 $47，則 4 個蘋果和 7 個檸檬的價錢為

  • A. $78。
  • B. $80。
  • C. $82。
  • D. $84。

深度分析

二元一次聯立方程式　認知層次：應用　建議作答 90 秒

核心公式／定理：$2a + 3b = 38$、$3a + 2b = 47$

提示 1（啟發）
設蘋果價格為 a, 檸檬價格為 b，列出兩個線性方程：$2a + 3b = 38$ 與 $3a + 2b = 47$。
提示 2（知識）
觀察目標式 $4a + 7b$ 與已知方程係數的關係，嘗試將兩個方程進行線性組合（如相加、相減或乘以常數）來構造目標式。
提示 3（破題）
若直接解出 a, b 的數值代入計算，請仔細檢查最後一步的乘法與加法運算是否正確。

誘答項逆向工程

A

計算粗心　加法誤算

解得 a=13, b=2 後，計算 4*13+7*2=52+14=66，卻算成 78。或是將兩個原方程相加 (5a+5b=85) 再乘以某個錯誤係數得到此結果。
B　✓ 正確答案
C

策略錯誤　目標表達錯誤

解出 a=13, b=2 後，直接將原方程相加 (5a+5b) 並誤以為等於目標，或計算 4a+7b 時把 b 的係數搞錯成 6(4*13+6*2=80) 再調整數值錯誤。
D

概念錯誤　忽略變量關係

試圖用平均法或比例，誤以為 4 蘋果 7 檸檬是 2 蘋果 3 檸檬的簡單倍數，直接將 $38 與 $47 相加得 $85 後隨意調整至 $84。

速解策略：將兩方程相加得 $5a+5b=85$，再結合其中一方程消元求單價，或直接解出 a, b 後代數計算 $4a+7b$。
