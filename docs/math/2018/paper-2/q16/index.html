DSE 數學 2018 卷二 第 16 題【相似三角形與面積比】深度分析

題目

圖中，$ABCD$ 為一平行四邊形。$E$ 為$BC$上的一點使得$BE:EC=5:3$。$AE$ 與$BD$相交於點$F$。若$\triangle ABF$的面積為$120\, \text{cm}^2$，則四邊形$CDFE$的面積為

  • A. $237\, \text{cm}^2$。
  • B. $307\, \text{cm}^2$。
  • C. $312\, \text{cm}^2$。
  • D. $429\, \text{cm}^2$。

深度分析

相似三角形與面積比　認知層次：應用　建議作答 180 秒

核心公式／定理：\frac{Area_1}{Area_2} = \left(\frac{side_1}{side_2}\right)^2 (相似圖形)、\frac{Area_{\triangle ABF}}{Area_{\triangle EDF}} = \left(\frac{AB}{ED}\right)^2、\frac{AF}{FE} = \frac{BF}{FD} = \frac{AB}{DE}

提示 1（啟發）
觀察圖形，\triangle ABF 與 \triangle EDF 是相似三角形，請找出它們的相似比。
提示 2（知識）
利用平行四邊形對邊相等的性質，確定 DE 與 AB 的長度關係。
提示 3（破題）
將四邊形 CDFE 的面積拆解為 \triangle DEF 與 \triangle CEF 兩部分分別計算。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　比例計算錯誤

算出 \triangle ABE 面積為 200，但忘記加上 \triangle DEF 的面積 (67.5)，直接加錯或漏加。
C

概念錯誤　混淆相似比與線段比

誤以為 \triangle ABF 與 \triangle EDF 的相似比是 5:3，導致面積比算成 25:9，後續計算全錯。
D

策略錯誤　漏掉關鍵區域

只算了 \triangle ABF + \triangle ABE 的部分，或者錯誤地將 \triangle BFE 的面積重複計算。

速解策略：先求相似比得面積比算出 \triangle DEF，再利用底邊比求 \triangle CEF，最後相加。
