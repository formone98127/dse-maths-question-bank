2012 DSE 數學 P1 Q18 答案＋詳解

題目（中文卷）

圖 5(a) 顯示以正方形為底的直立角錐體 VABCD ，其中 ∠VAB = 72° 。該底的邊長為 20 cm 。設 P 及 Q 分別為 VA 及 VD 上的點使得 PQ 平行於 BC 且 ∠PBA = 60° 。從 VABCD 切去角錐體 VPBCQ 造成一幾何模型，如圖 5(b) 所示。

(a) 求 AP 的長度。 (2 分)

(b) 設 α 爲平面 PBCQ 與底 ABCD 間之交角。

(i) 求 α 。 (3 分)

(ii) 設 β 爲 PB 與底 ABCD 間之交角。α 與 β 哪一個較大？試解釋你的答案。 (6 分) | | | | | | | | | | | | | | | | | | | | | | | | | | | | | | |

English version（英文卷題目）

Figure 5(a) shows a right pyramid ( VABCD ) with a square base, where ( \angle VAB = 72^\circ ). The length of a side of the base is ( 20 \text{ cm} ). Let ( P ) and ( Q ) be the points lying on ( VA ) and ( VD ) respectively such that ( PQ ) is parallel to ( BC ) and ( \angle PBA = 60^\circ ). A geometric model is made by cutting off the pyramid ( VPBCQ ) from ( VABCD ) as shown in Figure 5(b).

(a) Find the length of ( AP ).

(b) Let ( \alpha ) be the angle between the plane ( PBCQ ) and the base ( ABCD ).

(i) Find ( \alpha ).

(ii) Let ( \beta ) be the angle between ( PB ) and the base ( ABCD ). Which one of ( \alpha ) and ( \beta ) is greater? Explain your answer.

官方評卷參考（Marking Scheme）

考評報告

良好。部分考生誤以爲 $\angle AVB = 72^\circ$ 而非 $\angle VAB = 72^\circ$ 。甚差。大部分考生不知道如何求 $\alpha$ 。甚差。大部分考生未能指出 $\beta$ 是哪一個角,部分考生誤以爲 $\beta$ 是 $\angle PBA$ 。
