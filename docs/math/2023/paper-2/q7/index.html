題目

若 $y = 73.8$（準確至三位有效數字），求 $y$ 值的範圍。

  • A. $73.7 \leq y < 73.9$
  • B. $73.7 < y \leq 73.9$
  • C. $73.75 \leq y < 73.85$
  • D. $73.75 < y \leq 73.85$

深度分析

有效數字與誤差範圍　認知層次：理解　建議作答 45 秒

核心公式／定理：若 $x$ 準確至第 $n$ 位小數，則下界為 $x - 0.5 \times 10^{-n}$，上界為 $x + 0.5 \times 10^{-n}$

提示 1（啟發）
當一個數值被四捨五入到某一位時，實際值必須落在該位數前後各半個單位的區間內。
提示 2（知識）
對於 $73.8$（三位有效數字），最後一位是百分位，因此誤差範圍應以 $0.05$ 為單位計算。
提示 3（破題）
考慮四捨五入的定義：若小數點後第三位大於等於 5 則進位，小於 5 則捨去，推導出上下界的不等式方向。

誘答項逆向工程

A

概念錯誤　誤差範圍計算錯誤

學生直接將有效數字減加 0.1，忽略了四捨五入的精度是半個單位（0.05），導致範圍過大。
B

概念錯誤　誤差範圍計算錯誤

同樣犯了將誤差視為 0.1 的錯誤，且不等號方向弄反，認為小於 73.8 的部分不包含下界。
C　✓ 正確答案
D

審題不清　不等號方向錯誤

學生正確計算出 73.75 與 73.85，但混淆了四捨五入的含義，誤以為小於原值才符合條件。

速解策略：將 $73.8$ 視為 $73.80$，誤差為 $\pm 0.05$，故範圍為 $[73.75, 73.85)$。
