題目

設 $ g(x) = (x+1)(x+a) $，其中 $ a $ 為一常數。若 $ g(1) = g(2) $，則 $ g(a) = $

  • A. $-4$
  • B. $0$
  • C. $12$
  • D. $24$

深度分析

一元二次函數與多項式　認知層次：分析　建議作答 90 秒

核心公式／定理：$g(x) = (x+1)(x+a)$、$g(1) = 2(1+a)$、$g(2) = 3(2+a)$

提示 1（啟發）
先利用 $g(1)=g(2)$ 這個條件，建立關於常數 $a$ 的線性方程式。
提示 2（知識）
解出 $a$ 的具體數值後，記得將該數值代回原函數式 $g(x)$ 中計算 $g(a)$。
提示 3（破題）
小心計算 $(-2)\times(-6)$ 的結果，確認符號與乘積是否正確。

誘答項逆向工程

A

計算粗心　符號處理錯誤

解出 a=-3 後，代入 g(a) 時算成 ( -3+1)(-3-3) = (-2)(-6)=12 選錯 C，或算成 g(-3) 時漏掉括號展開錯誤。
B

概念錯誤　混淆變數與常數

誤以為 g(a) 就是 a 的根，直接選 0；或將 a 當作 x=0 時的值計算。
C

計算粗心　代入錯誤數值

正確算出 a=-3，但計算 g(-3) 時算錯：$(-3+1)(-3-3) = (-2)\times(-6) = 12$。
D　✓ 正確答案

速解策略：由 $2(1+a)=3(2+a)$ 解得 $a=-3$，再算 $g(-3)=(-2)(-6)=12$
