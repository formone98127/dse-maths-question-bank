Question

If $6x-7y=40=2x+11y$, then $y=$

  • A. $-4$.
  • B. $2$.
  • C. $4$.
  • D. $9$.

Answer

Correct answer: B. 2

深度分析

二元一次聯立方程式　認知層次：應用　建議作答 45 秒

核心公式／定理：聯立消元法、代入消元法

提示 1（啟發）
觀察題目結構，發現三個表達式相連，表示它們都等於同一個常數。
提示 2（知識）
先將等式拆分成兩個二元一次聯立方程式：6x-7y=40 與 2x+11y=40。
提示 3（破題）
利用消元法或代入法解出 x 與 y 的值，注意符號變化。

誘答項逆向工程

A

計算粗心　符號處理錯誤

解出 x=21 後，代入原式時計算 -7y=40-6(21)=-82，卻誤算為 y=2，導致結果為負數或忽略符號變化。
B　✓ 正確答案
C

計算粗心　移項符號遺漏

由 6x-7y=40 與 2x+11y=40 相減得 4x=0，誤以為 x=0，代入得 y=-4/11 或計算錯誤導致選正數。
D

概念錯誤　聯立方程理解偏差

誤將兩個等式視為獨立，分別解出 y 值後取平均值，或未注意到三項相等意味著兩組方程同時成立。

速解策略：將等式拆為兩組方程，聯立求解 x 與 y。
