題目

$\frac{(2a)^3}{(4a^{-5})^{-1}} =$

  • A. $2a^8$
  • B. $32a^8$
  • C. $\frac{2}{a^2}$
  • D. $\frac{32}{a^2}$

深度分析

指數法則與冪數運算　認知層次：應用　建議作答 60 秒

核心公式／定理：(a^m)^n = a^(mn)、(ab)^n = a^n b^n、a^-n = 1/a^n、a^m / a^n = a^(m-n)

提示 1（啟發）
提示 1：先觀察分母中的負指數 -1，根據 (x^-1) = 1/x，這會如何改變分母的結構？
提示 2（知識）
提示 2：處理完負指數後，你現在面對的是兩個冪的除法。請分別回憶係數部分和變數 a 的部分該如何分開計算。
提示 3（破題）
提示 3：將分子 (2a)^3 展開為 8a^3，分母化簡後為 4a^5，接著計算 8/4 與 a^3/a^5 即可得到最終答案。

誘答項逆向工程

A

計算粗心　冪的乘方運算錯誤

學生計算 (2a)^3 時得到 8a^3，但處理分母時將 (4a^-5)^-1 誤算為 4a^5 或直接忽略係數，導致最終係數變成 2。
B

計算粗心　冪的乘方運算錯誤

學生正確處理了 (4a^-5)^-1 得到 4a^5，但計算 (2a)^3 / (4a^5) 時，係數 8/4 算成 32，或是將指數運算混淆。
C

計算粗心　負指數處理錯誤

學生在處理分母的負指數時，可能將 (4a^-5)^-1 誤認為只是 a^5 而忽略係數 4，或者在最後一步約分時出錯。
D　✓ 正確答案

速解策略：先化簡分母的負指數，再將分子分母係數與變數分別運算。
