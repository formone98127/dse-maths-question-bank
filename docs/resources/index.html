點用呢個資源庫

DSE Hub 本來以數學、經濟、化學、生物、物理嘅歷屆試題索引為主。呢一頁把現行香港中學文憑試甲類高中科目嘅原創溫習資源集中列出，方便你由科目頁行去公式表、課題筆記或答題框架。

科目名單以考評局 2026／2027 年考試規則所列嘅甲類科目為準，已經停止開設嘅科目（例如組合科學、綜合科學）唔會收錄。乙類應用學習同丙類其他語言唔設詳細筆記，只提供官方目錄，避免寫出過時或唔準確嘅課程內容。

官方試題、評卷參考同考試報告有版權，請到考評局刊物頁查閱或購買。指定文言經典學習材料原文，請用教育局頁面。
