題目

若 $f(x)=3x^2-2x+1$，則 $f(2m-1)=$

  • A. $6m^2-4m+2$
  • B. $6m^2-4m+6$
  • C. $12m^2-16m+2$
  • D. $12m^2-16m+6$
WhatsApp 分享Telegram 分享

深度分析

函數代入與展開　認知層次：應用　建議作答 45 秒

核心公式／定理：$f(g(x)) = 3(g(x))^2 - 2(g(x)) + 1$

提示 1（啟發）
提示 1：請先將 $x=2m-1$ 代入函數式，注意括號的運算順序。
提示 2（知識）
提示 2：展開 $(2m-1)^2$ 時，記得使用公式 $(a-b)^2=a^2-2ab+b^2$。
提示 3（破題）
提示 3：將各項係數合併後，檢查二次項、一次項與常數項是否正確。

誘答項逆向工程

A

計算粗心　展開平方項時漏掉交叉項

學生計算 $3(2m-1)^2$ 時，可能只算成 $3(4m^2)$ 或忘記了 $-4m+2$ 的部分，導致常數項與一次項完全錯誤。
B

計算粗心　展開平方項時漏掉交叉項且常數項算錯

學生算出 $3(4m^2-4m+1)=12m^2-12m+3$ 後，未乘以 3 或加法錯誤，導致一次項係數變為 -4，常數項變為 6。
C

計算粗心　展開平方項時漏掉交叉項且常數項算錯

學生算出 $3(4m^2-4m+1)=12m^2-12m+3$ 後，未乘以 3 或加法錯誤，導致一次項係數變為 -16，常數項變為 2。
D　✓ 正確答案

速解策略：代入 $x=2m-1$ 展開平方項，再分配係數並合併同類項。
