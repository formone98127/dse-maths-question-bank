題目

圖2顯示 Ada 和 Billy 在同一條直路上從鎮 $P$ 到鎮 $Q$ 的跑步圖像，時間範圍為下午1:00至3:00。Ada 以恆定速度跑步，已知鎮 $P$ 與鎮 $Q$ 相距16公里。

(a) Billy 在該期間內休息了多久？（2 分）

(b) 在該期間內，Ada 和 Billy 相遇時距離鎮 $P$ 有多遠？（3 分）

(c) 使用該期間的平均速度來判斷誰跑得更快，並解釋你的答案。（2 分）

深度分析

統計圖表　認知層次：理解　建議作答 180 秒

核心公式／定理：$\text{速度} = \frac{\text{距離}}{\text{時間}}$、$\text{相遇條件}: d_A(t) = d_B(t)$

提示 1（啟發）
Hint1: 觀察 Billy 的圖線哪一段是水平的？這代表他在做什麼？
提示 2（知識）
Hint2: Ada 的圖線是一條直線，如何從圖中計算她的速度？
提示 3（破題）
Hint3: 相遇時兩人的距離 $d$ 相等，如何利用這個條件建立方程？

速解策略：先讀圖得 Billy 休息時間；再寫 Ada 與 Billy 跑步段的直線方程式；聯立解出相遇點 $(t, d)$；最後比較總耗時判斷平均速度。
