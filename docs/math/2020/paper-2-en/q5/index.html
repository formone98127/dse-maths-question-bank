Question

Let $f(x)=3x^2-x-2$. If $\beta$ is a constant, then $f(1+\beta)-f(1-\beta)=$

  • A. $2\beta$.
  • B. $10\beta$.
  • C. $6\beta^2-2$.
  • D. $6\beta^2-2\beta$.

Answer

Correct answer: B. 10\beta

深度分析

一元二次函數的代數運算　認知層次：應用　建議作答 60 秒

核心公式／定理：$f(a) = 3a^2 - a - 2$、$f(b) = 3b^2 - b - 2$

提示 1（啟發）
提示 1：嘗試先將 $x=1+\beta$ 和 $x=1-\beta$ 分別代入函數表達式 $f(x)$。
提示 2（知識）
提示 2：展開多項式時，注意 $(1\pm\beta)^2 = 1 \pm 2\beta + \beta^2$ 的結構。
提示 3（破題）
提示 3：將兩個結果相減時，觀察哪些項會相互抵消，哪些項會保留。

誘答項逆向工程

A

計算粗心　漏掉二次項係數

計算時忽略 $3x^2$ 項，僅考慮一次項與常數項的差值，導致結果偏小。
B　✓ 正確答案
C

計算粗心　漏掉一次項係數

正確算出二次項 $6\beta^2$，但計算一次項時遺漏了 $-(-\beta) - (-(-\beta)) = -2\beta$ 的部分。
D

計算粗心　符號處理錯誤

在展開 $f(1-\beta)$ 時，對 $-(1-\beta)$ 的符號處理出錯，導致一次項係數計算不正確。

速解策略：直接代入並展開，利用 $(1+\beta)^2-(1-\beta)^2=4\beta$ 簡化二次項計算。
