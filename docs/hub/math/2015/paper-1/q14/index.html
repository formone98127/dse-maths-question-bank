題目

點 ( P ) 及點 ( Q ) 的坐標分別為 ( (4, -1) ) 及 ( (-14, 23) ) 。

(a) 設 ( L ) 為 ( PQ ) 的垂直平分線。

(i) 求 ( L ) 的方程。

(ii) 假定 ( G ) 為 ( L ) 上的一點。將 ( G ) 的 ( x ) 坐標記為 ( h )。設 ( C ) 為一圓，其圓心為 ( G ) 且通過 ( P ) 及 ( Q ) 。證明 ( C ) 的方程為 ( 2x^2 + 2y^2 - 4hx - (3h + 59)y + 13h - 93 = 0 ) 。

深度分析

直線與圓　認知層次：分析　建議作答 480 秒

核心公式／定理：$\text{中點} = \left(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}\right)$、$\text{斜率} = \frac{y_2-y_1}{x_2-x_1}$、$\text{垂直線斜率關係}: m_1 m_2 = -1$、$\text{圓方程}: (x-h)^2 + (y-k)^2 = r^2$

提示 1（啟發）
提示 1: 垂直平分線必過 PQ 中點且斜率為 PQ 斜率的負倒數。
提示 2（知識）
提示 2: G 在 L 上意味著 G 的 y 坐標可透過 L 的方程用 h 表示。
提示 3（破題）
提示 3: 圓通過 P,Q 代表半徑 r = GP = GQ，利用距離公式建立等式。

速解策略：先求中點與垂直斜率寫出 L；再利用 G(h, k) 在 L 上代換 k；最後由 GP^2=r^2 展開整理即得證。
