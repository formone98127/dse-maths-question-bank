題目

若 $x=6.24$（準確至二位小數），求 $x$ 值的範圍。

  • A. $6.23 < x \leq 6.25$
  • B. $6.23 \leq x < 6.25$
  • C. $6.235 < x \leq 6.245$
  • D. $6.235 \leq x < 6.245$

深度分析

近似值與誤差範圍　認知層次：理解　建議作答 45 秒

核心公式／定理：若 $x$ 準確至第 $n$ 位小數為 $d_n.d_{n-1}...d_1$，則實際範圍為 $[d_n.d_{n-1}...d_1 - 0.5\times10^{-n}, d_n.d_{n-1}...d_1 + 0.5\times10^{-n})$

提示 1（啟發）
回想「四捨五入」的定義：當末位後一位小數大於等於 5 時，末位進 1。
提示 2（知識）
思考：若 $x$ 四捨五入後為 $6.24$，則 $x$ 必須落在哪個區間內？請考慮邊界值 $6.235$ 和 $6.245$ 分別會變成什麼數。
提示 3（破題）
確認邊界值的包含性：若邊界值本身四捨五入後等於目標值，該邊界是否應被包含在範圍內（使用 $\leq$ 或 $<$）？

誘答項逆向工程

A

概念錯誤　誤差邊界計算錯誤

學生只考慮了整數部分變化，將誤差範圍擴大到下一個小數位（0.01），忽略了四捨五入時僅影響末位小數的性質，導致上下限變成 6.23 和 6.25。
B

概念錯誤　誤差邊界計算錯誤與不等號方向混淆

學生同樣將誤差範圍擴大到 0.01，且在不確定四捨五入規則下，隨機選擇了包含下限但不含上限的不等式形式，未能正確識別 $6.245$ 會進位成 $6.25$。
C

策略錯誤　不等號方向判斷錯誤

學生正確計算出誤差半徑為 $0.005$，得到邊界 $6.235$ 和 $6.245$，但錯誤地認為較小的數值（$6.235$）對應大於符號，混淆了「四捨五入後等於目標值」時，原數需滿足的大小關係。
D　✓ 正確答案

速解策略：計算誤差半徑 $0.5 \times 10^{-2}=0.005$，得邊界 $6.235, 6.245$；驗證邊界值四捨五入後是否等於 $6.24$ 以決定不等號方向。
