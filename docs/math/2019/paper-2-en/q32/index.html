Question

If $\dfrac{3}{3\log x-2}+7=\dfrac{2}{2\log x+1}$, then $\log \dfrac{1}{x}=$

  • A. $-3$ or $2$
  • B. $-2$ or $3$
  • C. $\dfrac{-1}{3}$ or $\dfrac{1}{2}$
  • D. $\dfrac{-1}{2}$ or $\dfrac{1}{3}$

Answer

Correct answer: D. \dfrac{-1}{2} or \dfrac{1}{3}

深度分析

對數方程式　認知層次：分析　建議作答 90 秒

核心公式／定理：\log_b(1/x) = -\log_b(x)、\frac{a}{b} + c = \frac{d}{e} \Rightarrow \text{交叉相乘或通分}

提示 1（啟發）
觀察方程中重複出現的 \log x，考慮設 t = \log x 簡化式子。
提示 2（知識）
將原式化為關於 t 的一元二次分式方程，小心處理分母不為零的限制條件。
提示 3（破題）
求出 t 的值後，記得題目問的是 \log(1/x)，利用性質將其轉換為 -t。

誘答項逆向工程

A

概念錯誤　變數代換錯誤導致解錯

學生令 t=logx，解得 t=1/3 或 -1/2。但題目求 log(1/x)=-t。學生可能忘記負號，直接將 t 的值填入，選出 A 或 B（若算錯符號）。
B

計算粗心　分式運算錯誤

學生令 t=logx，解方程時交叉相乘或移項通分出錯。例如將 7 移到右邊後計算錯誤，導致得到 t=2 或 -3 等無效解。
C

概念錯誤　未轉換題目所求目標

學生正確算出 logx = -1/2 或 1/3，但題目要求的是 \log(1/x)=-\log x。學生誤以為題目就是問 logx，因此直接選 C。
D　✓ 正確答案

速解策略：令 t=logx，解出 t 後取相反數即為答案。
