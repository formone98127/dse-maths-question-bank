題目

某等比數列的第 3 項及第 6 項分別為 144 及 486 。

(a) 求該數列的第 1 項。 (2 分)

(b) 求 ( n ) 的最小值使得該數列的首 ( n ) 項之和大於 ( 8 \times 10^{18} ) 。 (3 分)

深度分析

數列　認知層次：分析　建議作答 300 秒

核心公式／定理：$a_n = a r^{n-1}$、$S_n = \frac{a(r^n - 1)}{r - 1} (r \neq 1)$

提示 1（啟發）
先由 a3=144, a6=486 得 r^3 = 486/144 = 3.375
提示 2（知識）
求和公式為 S_n = a(r^n - 1)/(r-1)，注意 r>1 時分母正負
提示 3（破題）
將不等式轉為 r^n > ...，再取 log_r 解 n

速解策略：先求 r=1.5, a=64；代入 Sn 公式得不等式，取對數解 n≥20，故最小值為 20。
