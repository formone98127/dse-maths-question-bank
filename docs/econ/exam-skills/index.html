同現有經濟課題頁一齊用

經濟科已有課題頁同部分歷屆試卷。呢頁集中講資料回應、短題同較長題嘅作答框架。2028 年起評核框架將有更新，溫習時請核對你應考年份嘅大綱，而唔好假設所有舊卷結構永遠不變。

基本經濟概念 生產與企業 市場與價格 市場結構與競爭 效率、公平與政府角色 經濟表現量度 國民收入與價格水平 貨幣與銀行 宏觀經濟問題與政策 國際貿易與金融

以 2027 年大綱為例嘅卷面

卷一通常係必修範圍嘅多項選擇。卷二大致包括必修短題、必修結構或資料回應，以及選修單元題（選答其中一個單元）。時間同確切比重以官方文件為準。

短題同定義題

  • 定義要完整：例如機會成本要包含「被放棄嘅最高價值用途」，而唔係只寫「放棄咗嘅東西」。
  • 辨識題用課程術語命名現象（短缺、剩餘、公共物品、外部性、名義同實質），再補一個題目情境中嘅證據。
  • 計算題寫公式、代入、單位，例如指數、乘數或彈性，並說明數值含義。

資料回應同長題

  1. 先讀資料標題、單位、年期。圖表講趨勢，文字資料分清事實同意見。
  2. 用經濟學工具分析：供求移動要講邊邊移動、係需求定供給、點解，以及均衡價格與量嘅方向。
  3. 政策題用準則，例如效率、公平、誘因、財政負擔、時間滯後，先再下判斷。兩邊都要寫，結論先有力。
  4. 宏觀題分清名義／實質、短期／長期、開放經濟下嘅泄漏。唔好把所有下跌都叫衰退，而不看定義。

常見失分

  • 把存量同流量、平均同邊際、移動曲線同沿曲線移動搞亂。
  • 只描述資料（「圖顯示上升」）而沒有經濟學解釋。
  • 長題沒有段落功能，或者例子同原理互不相干。
