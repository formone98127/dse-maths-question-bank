題目

圖中，$AB=BC$ 及 $AB//CD$ 。設 $E$ 為 $AD$ 與 $BC$ 的交點。若 $\angle ADC=28^\circ$ 及 $\angle AEB=94^\circ$ ，則 $\angle CAD=$

  • A. $30^\circ$ 。
  • B. $33^\circ$ 。
  • C. $36^\circ$ 。
  • D. $39^\circ$ 。

深度分析

幾何圖形性質　認知層次：分析　建議作答 90 秒

核心公式／定理：平行線內錯角相等、等腰三角形底角相等、三角形外角等於不相鄰兩內角和、三角形內角和為 180°

提示 1（啟發）
觀察平行線 $AB // CD$，利用內錯角性質找出與 $\angle ADC$ 相關的角。
提示 2（知識）
在 $\triangle CDE$ 中，利用三角形外角定理或內角和，求出 $\angle DCE$ 的度數。
提示 3（破題）
結合等腰三角形 $AB=BC$ 的性質，推導出 $\angle BAC$ 與 $\angle BCA$ 的關係，進而求解目標角。

誘答項逆向工程

A

計算粗心　角度運算錯誤

學生可能正確算出 $\angle C=94^\circ$ 與 $\angle BDC=28^\circ$，但在計算 $\angle CAD$ 時，誤將 $94-56=38$ 或 $180-(94+28)=58$ 等錯誤組合，最終選錯。
B　✓ 正確答案
C

概念錯誤　混淆外角定理應用

學生可能誤以為 $\angle AEB$ 是 $\triangle CDE$ 的外角，直接計算 $94-28=66$，再除以 2 得 $33^\circ$ 但中間步驟邏輯混亂，或混淆了三角形內角關係。
D

審題不清　看錯題目條件

學生可能忽略 $AB=BC$ 這個等腰條件，或誤讀 $\angle ADC=28^\circ$ 為其他角，導致計算結果偏離正確路徑。

速解策略：利用平行線得內錯角相等，再於小三角形中運用外角定理或內角和求角。
