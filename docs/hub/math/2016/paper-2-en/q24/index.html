Question

If the sum of the interior angles of a regular $n$-sided polygon is $3240^\circ$, which of the following is true?

  • A. The value of $n$ is 16.
  • B. Each exterior angle of the polygon is $18^\circ$.
  • C. The number of diagonals of the polygon is 20.
  • D. Each interior angle of the polygon is $160^\circ$.
Share on WhatsAppShare on Telegram

Answer

Correct answer: B. Each exterior angle of the polygon is 18^\circ

深度分析

正多邊形性質　認知層次：應用　建議作答 90 秒

核心公式／定理：(n-2)\times 180^\circ、\sum \text{外角}=360^\circ、\frac{n(n-3)}{2}

提示 1（啟發）
回想正 n 邊形內角和公式 (n-2)\times 180^\circ，先求出 n 的值。
提示 2（知識）
利用外角和恆為 360^\circ 的性質，由 n 計算單一外角大小。
提示 3（破題）
確認選項 B 的外角數值與計算結果是否吻合。

誘答項逆向工程

A

計算粗心　解出 n=15 誤植為 16

由 (n-2)×180=3240 得 n-2=18，計算錯誤認為 n=16，或直接忽略 -2 項誤算。
B　✓ 正確答案
C

計算粗心　代入 n=15 算錯為 20

將 n=15 代入 \frac{n(n-3)}{2}，計算 15×12÷2=90，卻誤記或筆誤寫成 20。
D

概念錯誤　混淆內角與外角數值

算出外角為 18^\circ，卻誤以為題目問的是內角，直接將 18^\circ 當作內角或誤加。

速解策略：先求 n=15，再算外角=360/15=18^\circ。
