題目

$(x + 3y)^2 - (x - 3y)^2 =$

  • A. $2x^2$
  • B. $6xy$
  • C. $12xy$
  • D. $2x^2 + 18y^2$

深度分析

代數展開與平方差公式　認知層次：應用　建議作答 45 秒

核心公式／定理：$(a+b)^2 = a^2 + 2ab + b^2$、$(a-b)^2 = a^2 - 2ab + b^2$、$A^2 - B^2 = (A-B)(A+B)$

提示 1（啟發）
嘗試先將題目視為 $A^2 - B^2$ 的形式，其中 $A = x+3y$, $B = x-3y$。
提示 2（知識）
回憶平方差公式 $A^2 - B^2 = (A-B)(A+B)$ 是否比直接展開更簡便？
提示 3（破題）
計算 $(x+3y) + (x-3y)$ 與 $(x+3y) - (x-3y)$ 的結果，再相乘即可。

誘答項逆向工程

A

計算粗心　漏掉交叉項

學生展開後得到 $x^2+6xy+9y^2$ 與 $x^2-6xy+9y^2$，相減時錯誤地認為 $9y^2$ 抵消後只剩 $12xy$，卻又誤算係數或混淆選項，最終選到只有 $2x^2$ 的錯誤結果，可能是在計算 $6xy - (-6xy)$ 時出錯。
B

計算粗心　係數算錯

學生正確展開得到 $12xy$，但在合併 $6xy - (-6xy)$ 時，錯誤地將結果寫成 $6xy$，可能是忘記了負負得正的規則或單純計算加法錯誤。
C　✓ 正確答案
D

概念錯誤　誤解平方差結構

學生可能認為 $(x+3y)^2$ 與 $(x-3y)^2$ 的 $y^2$ 項不會抵消，或者錯誤地將兩式相加而非相減，導致保留了 $18y^2$ 項。

速解策略：利用平方差公式 $A^2-B^2=(A-B)(A+B)$，代入後直接計算括號內式子。
