Question

Let $a$ and $b$ be constants. If the figure shows the graph of $y = a \cos 2x^\circ$, then [FIGURE Q37: Cartesian coordinate system graph with curve, labeled points O, b, and y=2. Dotted horizontal line at y=2. No angles, shading, or right-angle marks.]

  • A. $a = -2$ and $b = 90$.
  • B. $a = -2$ and $b = 360$.
  • C. $a = 2$ and $b = 90$.
  • D. $a = 2$ and $b = 360$.
Share on WhatsAppShare on Telegram

Answer

Correct answer: A. a = -2 and b = 90

深度分析

三角函數圖像分析　認知層次：分析　建議作答 90 秒

核心公式／定理：y = A cos(k(x-d)) + c、振幅 = |A|、最大/最小值 = c ± 振幅

提示 1（啟發）
觀察圖形在 $x=0$ 處的 $y$ 值，判斷這是最大值還是最小值，並思考這如何影響參數 $a$ 的正負號。
提示 2（知識）
測量圖像中一個完整波形（從波峰到下一個波峰或波谷）所佔用的 $x$ 軸長度，利用週期公式 $T = \frac{360}{|k|}$ 計算 $b$ 的值。
提示 3（破題）
綜合振幅與週期的分析結果，驗證哪個選項同時滿足圖像的極值位置與波動頻率。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　週期計算錯誤

學生正確判斷振幅為 2，但誤算週期。由圖知一個完整週期對應 x 軸跨度約 180°，故 $360/|k|=180 \Rightarrow |k|=2$。選項 B 將 b 設為 360，忽略圖像顯示的實際週期長度。
C

概念錯誤　振幅符號誤判

學生觀察到圖形在 $x=0$ 處為最小值，但忘記餘弦函數 $\cos(0)=1$。若 $a>0$，則 $y=a$ 應為最大值；唯有 $a<0$ 時，$y=-a$ 才為最小值。學生未考慮係數符號對極值的影響。
D

概念錯誤　振幅與週期雙重誤判

學生同時犯下兩個錯誤：一是認為 $a$ 應為正（忽略圖像翻轉），二是將週期誤算為整個座標軸長度而非圖像顯示的單一波長。導致選出 $a=2, b=360$ 的錯誤組合。

速解策略：由 $x=0$ 為最小值推知 $a<0$；由一個週期佔 $180^\circ$ 推知 $b=90$
