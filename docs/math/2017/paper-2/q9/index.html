題目

圖中所示為 $ y = (px+5)^2 + q $ 的圖像，其中 $ p $ 及 $ q $ 均為常數。下列何者正確？

  • A. $ p < 0 $ 及 $ q < 0 $
  • B. $ p < 0 $ 及 $ q > 0 $
  • C. $ p > 0 $ 及 $ q < 0 $
  • D. $ p > 0 $ 及 $ q > 0 $

深度分析

二次函數圖形性質　認知層次：理解　建議作答 45 秒

核心公式／定理：y = a(x-h)^2 + k (其中 h, k 為頂點座標，a 決定開口方向)

提示 1（啟發）
二次函數 $y=(px+5)^2+q$ 的圖形頂點坐標為何？
提示 2（知識）
比較圖中頂點的 y 座標與 x 軸的位置關係，判斷 q 的正負。
提示 3（破題）
將方程式展開或代入特殊點驗證 p 的符號是否合理。

誘答項逆向工程

A

概念錯誤　誤判 q 的符號

學生認為頂點在 x 軸下方故 q<0 正確，但誤以為 p 與 x 軸交點位置直接決定 p 符號而忽略平移關係。
B

概念錯誤　誤判 q 的符號

學生正確判斷圖形向下延伸故 p>0，但錯誤地將頂點 y 座標視為負數，忽略頂點其實在 x 軸上方。
C　✓ 正確答案
D

概念錯誤　誤判 q 的符號

學生正確判斷 p>0，但完全誤解頂點 y 座標為負值，未觀察到頂點位於 x 軸上方。

速解策略：由頂點 $( -5/p, q )$ 知 $q>0$；圖形向下延伸故 $p>0$
