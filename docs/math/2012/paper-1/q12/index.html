題目

圖 3(a) 顯示底半徑為 $48\, \text{cm}$ 及高為 $96\, \text{cm}$ 的實心金屬直立圓錐體。

(a) 求該圓錐體的體積，答案以 $\pi$ 表示。 (2 分)

(b) 把半徑為 $60\, \text{cm}$ 的半球形容器鉛垂置於一水平面上。該容器載滿牛奶。

(i) 求該容器內牛奶的體積，答案以 $\pi$ 表示。 (5 分)

(ii) 現把該圓錐體鉛垂置於該容器內，如圖 3(b) 所示。某工匠宣稱剩下在該容器內的牛奶的體積大於 $0.3\, \text{m}^3$。你是否同意？試解釋你的答案。 請在此貼上電腦條碼

| | | | | | | | | | | | | | | | | | | | | | | | | | | | | | |

深度分析

立體幾何　認知層次：應用　建議作答 60 秒

核心公式／定理：$V_{\text{cone}} = \frac{1}{3}\pi r^2 h$、$V_{\text{hemisphere}} = \frac{2}{3}\pi r^3$

提示 1（啟發）
Hint1: 圓錐體積公式為 $\frac{1}{3}\pi r^2 h$，半球為 $\frac{2}{3}\pi r^3$。
提示 2（知識）
Hint2: (ii) 問中圓錐未必完全浸沒，需利用相似三角形求浸入高度。
提示 3（破題）
Hint3: 題目給出 cm，比較時務必統一換算為 m ($1\, \text{m} = 100\, \text{cm}$)。

速解策略：先算圓錐與半球體積 (注意單位)，再求圓錐浸入高度算排開液體，最後比較剩餘量。
