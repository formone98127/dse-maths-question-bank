# 數學技能冊（必修部分）

所有題目分析只准用本冊編號。唔准自由另起課題／公式名。

版本：1　課題 20　知識點 105　公式 78　能力 8

## 能力（全科共用 8 種）

- `A-SUB` **代入數值** — 把已知數值代入式子或公式
- `A-ALG` **代數變形** — 搬項、展開、因式、合併同類項
- `A-COND` **睇條件** — 注意單位、範圍、正負、非零、定義域
- `A-GRAPH` **讀圖** — 從圖像讀出斜率、截距、頂點、週期等
- `A-BACK` **由答案倒推** — 用選項反推或驗證
- `A-CHAIN` **多步串連** — 多步解題，中間一步錯會帶歪後續
- `A-ELIM` **排除錯選項** — 用性質或邊界情況剔除不合理選項
- `A-CALC` **計算仔細度** — 符號、係數、口算與代數操作準確
