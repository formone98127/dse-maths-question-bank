題目

$p^{2}-4q^{2}$、$p^{3}-8q^{3}$ 及 $(p+2q)(p^{2}-4q^{2})$ 的 L.C.M. 為

  • A. $p-2q$
  • B. $p^{2}-4q^{2}$
  • C. $(p+2q)^{2}(p^{3}-8q^{3})$
  • D. $(p+2q)(p^{2}-4q^{2})(p^{3}-8q^{3})$
WhatsApp 分享Telegram 分享

深度分析

因式分解與最小公倍數 (LCM)　認知層次：應用　建議作答 90 秒

核心公式／定理：$a^2 - b^2 = (a-b)(a+b)$、$a^3 - b^3 = (a-b)(a^2 + ab + b^2)$

提示 1（啟發）
請先將三個代数式分別進行完全因式分解。
提示 2（知識）
平方差公式為 $a^2-b^2=(a-b)(a+b)$，立方差公式為 $a^3-b^3=(a-b)(a^2+ab+b^2)$。
提示 3（破題）
求 LCM 時，取所有出現過的因式，並取其在不同項式中出現的最高次方。

誘答項逆向工程

A

概念錯誤　混淆 LCM 與 GCD

學生將題目誤解為求最大公因數 (GCD)。$p-2q$ 是三個式子的公因數，但並非最小公倍數。
B

概念錯誤　誤解 LCM 定義

學生認為 LCM 僅需取所有式子中最高次項的乘積，或誤以為其中一個複雜式子即為答案。
C　✓ 正確答案
D

策略錯誤　重複因式

學生在求 LCM 時，將不同項式中相同的因式 $(p+2q)$ 與 $(p-2q)$ 全部相乘，未考慮取最高次方。

速解策略：分解後取各質因數最高次方之積：$(p-2q)(p+2q)^2(p^2+4pq+4q^2)$。
