題目

圖 2 中，實心直立角柱體 $ABCDEFGH$ 的體積為 $1020\, \text{cm}^3$。該角柱體的底 $ABCD$ 爲一梯形，其中 $AD$ 平行於 $BC$。已知 $\angle BAD = 90^\circ$、$AB = 12\, \text{cm}$、$BC = 6\, \text{cm}$ 及 $DE = 10\, \text{cm}$。

求

(a) $AD$ 的長度，

(b) 角柱體 $ABCDEFGH$ 的總表面面積。

深度分析

概率　認知層次：應用　建議作答 300 秒

核心公式／定理：$P(X \geq 43) = 1 - P(Z < \frac{43-\mu}{\sigma})$、$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$、$X \sim B(n, p)$

提示 1（啟發）
先畫樹狀圖理清 Revise/NoRevise 與 Pass/Fail 的關係。
提示 2（知識）
正態分佈計算時務必標記清楚兩個不同的 (μ, σ)。
提示 3（破題）
第 (c) 問的 p 值必須來自第 (b) 問的結果，而非直覺猜測。

速解策略：先算兩組通過率 -> 全概率求總通過率 -> 貝氏定理求條件機率 -> 二項分佈代入計算。
