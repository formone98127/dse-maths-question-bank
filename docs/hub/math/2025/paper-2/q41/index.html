題目

將原點記為 $O$。點 $U$ 的坐標為 $(20,0)$。設 $V$ 為正 $y$ 軸上的一點使得 $\Delta OUV$ 的內心的 $x$ 坐標為 $6$。求 $\Delta OUV$ 的面積。

  • A. $70$
  • B. $87$
  • C. $210$
  • D. $250$

深度分析

幾何，三角形內心坐標公式　認知層次：應用　建議作答 180 秒

核心公式／定理：(x_a, y_a), (x_b, y_b), (x_c, y_c) 為頂點，a, b, c 為對邊長，則內心 I 之 x 坐標為 \frac{ax_a + bx_b + cx_c}{a+b+c}

提示 1（啟發）
回憶三角形內心坐標的加權平均公式，其權重為何？
提示 2（知識）
在 \Delta OUV 中，\angle UOV = 90^\circ，這意味著哪些邊長可以用 y 表示？
提示 3（破題）
將內心 x 坐標公式代入已知條件，解出 y 後計算面積。

誘答項逆向工程

A

計算粗心　內心公式分母處理錯誤

學生可能將內心坐標公式記錯，誤以為是 \frac{x_a+x_b+x_c}{3} 或混淆邊權重，導致計算出錯誤數值如 70。
B

計算粗心　邊長表達式代入錯誤

學生在設定 \Delta OUV 邊長時，可能將斜邊 \sqrt{20^2+y^2} 簡化錯誤，或計算過程中出現代數運算失誤。
C　✓ 正確答案
D

概念錯誤　忽略直角三角形特性

學生可能未利用 \Delta OUV 為直角三角形的性質，隨意假設邊長關係或誤用一般三角形公式導致過大結果。

速解策略：利用內心 x 坐標公式 \frac{a x_O + b x_U + c x_V}{a+b+c} = 6，其中 a, b, c 為對應邊長，解出 y 即可。
