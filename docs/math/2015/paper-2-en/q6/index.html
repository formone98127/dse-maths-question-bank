Question

The solution of $18 + 7x > 4$ or $5 - 2x < 3$ is

  • A. $x > -2$.
  • B. $x > -1$.
  • C. $x > 1$.
  • D. $-2 < x < 1$.

Answer

Correct answer: A. x > -2

深度分析

一元一次不等式與邏輯或　認知層次：應用　建議作答 45 秒

核心公式／定理：$ax + b > c \Rightarrow x > (c-b)/a$ (當 $a>0$)、$A \lor B = A \cup B$

提示 1（啟發）
請先分別求解兩個獨立的不等式，並寫出各自的解集。
提示 2（知識）
注意題目中的連接詞是「或」(OR)，這代表我們需要尋找滿足其中任一條件的 $x$ 值範圍。
提示 3（破題）
在數軸上畫出這兩個解集，觀察它們合併後的形狀，即可找到正確選項。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　解第一式時移項錯誤

解 $18+7x>4$ 得 $7x>-14 \Rightarrow x>-2$。解第二式 $5-2x<3$ 得 $-2x<-2 \Rightarrow x>1$。學生將兩解取交集而非並集，且可能誤算第一式為 $x>-1$
C

概念錯誤　混淆或與且的邏輯

學生認為題目是「且」的關係，因此取兩個解集的交集 $x>1$。忽略了題目中關鍵的「或」字樣。
D

策略錯誤　錯誤處理不等號方向

解第二式時，除以負數 $-2$ 忘記改變不等號方向，得出 $x>1$。再將第一式解錯或誤讀，導致範圍變成 $-2<x<1$

速解策略：分別解兩不等式得 $x>-2$ 與 $x>1$；因是「或」關係，取並集即為 $x>-2$
