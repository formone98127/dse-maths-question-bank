2025 DSE 數學 Paper 2 第 36 題 答案＋詳解＋答對率 26%

官方答案

B

歷年考生答對率 26%（官方統計）

題目（中文卷）

考慮以下的不等式組：

$\begin{cases}x\leq11\4x+5y-19\geq0\7x-6y+11\leq0\end{cases}$

設$D$為表示以上的不等式組的解之區域。若$(x,y)$為$D$中的一點，則$8x-6y+11$的最大值為

  • A. $1$
  • B. $11$
  • C. $15$
  • D. $129$
English version（英文卷題目）

Consider the following system of inequalities:

$$

\begin{cases}

x \leq 11 \

4x + 5y - 19 \geq 0 \

7x - 6y + 11 \leq 0

\end{cases}

$$

Let $ D $ be the region which represents the solution of the above system of inequalities. If $ (x, y) $ is a point lying in $ D $, then the greatest value of $ 8x - 6y + 11 $ is

  • A. $1$
  • B. $11$
  • C. $15$
  • D. $129$

官方題解 / 評卷參考

答案：B

  1. 由第三條不等式：$7x-6y+11\le 0\Rightarrow 7x-6y\le-11$。
  2. 把目標式拆開：$8x-6y+11=(7x-6y+11)+x\le 0+x$。
  3. 再由 $x\le 11$ 得 $8x-6y+11\le 11$。
  4. 取等號需同時 $x=11$ 且 $7x-6y+11=0$，即 $y=\dfrac{88}{6}$；此點滿足 $4x+5y-19\ge0$，故最大值為 $11$。

錯項分析：

  • A. 把目標式當成與 $7x-6y+11$ 相同，只在邊界上取到 $0$ 或 $1$。
  • C. 只代入 $x=11$ 並隨便取一個 $y$ 值（例如 $y=-2$ 附近），令目標值偏小。
  • D. 以 $x=11$、$y=-6$ 之類直接代入，忽略 $y$ 同時受另外兩條不等式限制。

考評報告

在第 36 题中，很多考生誤以為 (11, -5) 是 D 中的一點，因此錯誤地選 D 為答案。
