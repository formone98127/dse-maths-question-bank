Question

$\alpha^2 - \alpha - \beta^2 + \beta =$

  • A. $(\alpha + \beta)(\alpha - \beta + 1)$.
  • B. $(\alpha + \beta)(\alpha - \beta - 1)$.
  • C. $(\alpha - \beta)(\alpha + \beta + 1)$.
  • D. $(\alpha - \beta)(\alpha + \beta - 1)$.
Share on WhatsAppShare on Telegram

Answer

Correct answer: D. (\alpha - \beta)(\alpha + \beta - 1)

深度分析

因式分解　認知層次：應用　建議作答 45 秒

核心公式／定理：a^2 - b^2 = (a-b)(a+b)、a^2 - a = a(a-1)

提示 1（啟發）
觀察題目中的四個項，嘗試將它們分成兩組，使每組內部可以進行因式分解。
提示 2（知識）
回憶平方差公式 a^2-b^2=(a-b)(a+b)，並思考如何處理剩下的線性項 -α+β。
提示 3（破題）
檢查選項 D 的結構，將其展開驗證是否等於原題目，確認常數項與一次項係數是否吻合。

誘答項逆向工程

A

計算粗心　符號處理錯誤

學生正確分組為 (α^2-β^2) 與 (-α+β)，但將 -α+β 提公因式時，誤認為是 -(α-β+1) 的展開形式，導致最後常數項符號錯誤，算成 +1。
B

計算粗心　公因式提取失誤

學生將 -α+β 錯誤地視為 -(α-β)，忽略了中間項的係數變化，導致展開後常數項變成 -1，而非正確的 -1（此處應為 -α+β=-(α-β)）。
C

概念錯誤　分組策略錯誤

學生嘗試將 α^2 與 -α 分組，β^2 與 β 分組，但忽略了 -α+β 無法直接提出 (α-β) 的公因式，導致結構完全錯誤。
D　✓ 正確答案

速解策略：分組為 (α^2-β^2) 和 (-α+β)，利用平方差公式及提取公因式 -(α-β)。
