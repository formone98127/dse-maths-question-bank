題目

$\frac{\cos 180^\circ}{1+\sin (90^\circ+\theta)}+\frac{\cos 360^\circ}{1+\sin (270^\circ+\theta)}=$

  • A. $0$
  • B. $\frac{2}{\cos \theta}$
  • C. $\frac{2 \cos \theta}{\sin^2 \theta}$
  • D. $\frac{2 \sin \theta}{\cos^2 \theta}$
WhatsApp 分享Telegram 分享

深度分析

三角函數恆等式　認知層次：應用　建議作答 90 秒

核心公式／定理：$\cos(180^\circ) = -1$、$\sin(90^\circ + \theta) = \cos \theta$、$\cos(360^\circ) = 1$、$\sin(270^\circ + \theta) = -\cos \theta$、$\frac{1}{1-x} + \frac{1}{1+x} = \frac{2}{1-x^2}$

提示 1（啟發）
請先利用誘導公式化簡題目中的兩個正弦項：$\sin(90^\circ+\theta)$ 與 $\sin(270^\circ+\theta)$。
提示 2（知識）
注意特殊角 $180^\circ$ 與 $360^\circ$ 的餘弦值分別為何？
提示 3（破題）
將化簡後的式子通分，利用恆等式 $1-\cos^2 \theta = \sin^2 \theta$ 進行約分。

誘答項逆向工程

A

計算粗心　忽略分母符號變化

學生算出分子為 0，忘記第二項分母為 $1-\cos \theta$，誤以為兩項互消或計算錯誤導致結果為 0。
B

策略錯誤　通分後約分錯誤

正確通分得 $\frac{2}{1-\cos^2 \theta}$，但學生誤將分母寫成 $\cos \theta$ 或忘記平方，直接選 B。
C　✓ 正確答案
D

概念錯誤　混淆正弦餘弦關係

學生在誘導公式中將 $\sin(270^\circ+\theta)$ 誤認為與 $\sin \theta$ 相關，導致分母變為 $1-\sin^2 \theta = \cos^2 \theta$

速解策略：化簡分母後通分，分子相加得 2，分母變為 $\sin^2 \theta$。
