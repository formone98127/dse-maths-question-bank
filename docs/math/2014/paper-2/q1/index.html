題目

$(2n^3)^{-5}=$

  • A. $\dfrac{1}{32n^2}$。
  • B. $\dfrac{1}{32n^{15}}$。
  • C. $\dfrac{1}{10n^{125}}$。
  • D. $\dfrac{1}{10n^{243}}$。

深度分析

指數法則　認知層次：應用　建議作答 45 秒

核心公式／定理：$(ab)^n = a^n b^n$、$(a^m)^n = a^{mn}$、$a^{-n} = \frac{1}{a^n}$

提示 1（啟發）
提示 1：回想一下冪的乘法法則 $(ab)^n = a^n b^n$ 和 $(a^m)^n = a^{mn}$，如何將題目中的式子拆解？
提示 2（知識）
提示 2：記得負指數 $x^{-n}$ 代表什麼意義？它與分數有何關係？
提示 3（破題）
提示 3：分別計算係數 $2$ 的 $-5$ 次方以及變數 $n^3$ 的 $-5$ 次方，最後將它們相乘。

誘答項逆向工程

A

計算粗心　冪的指數運算錯誤

學生可能將 $(2n^3)^{-5}$ 誤算為 $2^{-5} \cdot n^{3 \times -1}$，或者在計算 $3 \times -5$ 時出錯得到 $-2$。
B　✓ 正確答案
C

概念錯誤　誤解負指數與係數關係

學生可能將 $2^{-5}$ 錯誤地視為 $10$（混淆底數），並將指數運算完全搞錯，認為結果是 $n^{125}$。
D

計算粗心　冪的指數乘法錯誤

學生正確應用了 $(ab)^n$ 法則，但在計算 $3 \times -5$ 時，可能將負號忽略或算錯，得到 $243$（可能是 $3^5$ 的結果）。

速解策略：先將係數與變數分開處理，再應用冪的指數法則計算。
