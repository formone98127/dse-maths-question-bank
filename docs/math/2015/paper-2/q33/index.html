題目

$11+2^6+2^{10}+2^{11}=$

  • A. $110001001011_2$
  • B. $110100100011_2$
  • C. $1100001001011_2$
  • D. $1101001000011_2$

深度分析

二進位數值運算　認知層次：應用　建議作答 60 秒

核心公式／定理：$2^n = \underbrace{10...0}_{n\text{個}0}$ (二進位)

提示 1（啟發）
將十進位的 $11$、$2^6$、$2^{10}$、$2^{11}$ 分別轉換成二進位數值，觀察它們佔據的位元位置。
提示 2（知識）
記住二進位中 $2^n$ 對應的是第 $n$ 個零的位置（從右往左數，最低位為第 0 位）。
提示 3（破題）
將四個二進位數值對齊後進行直式加法運算，注意相同位元相加後的進位規則。

誘答項逆向工程

A　✓ 正確答案
B

計算粗心　權重加總錯誤

計算 $2^6+2^{10}$ 時，誤將位元位置錯開或進位處理不當，導致中間連續零的數量錯誤。
C

審題不清　少寫一個零

在將 $2^6$ 與 $2^{10}$ 疊加時，漏掉了 $2^6$ 對應位元後的進位影響，導致結果比正確值多了一個零。
D

計算粗心　起始位元錯誤

將 $11$ 轉換為二進位時，誤以為是 $8+2=10_2$ 而非 $1011_2$，導致最高位與次高位排列混亂。

速解策略：先轉 $11$ 為 $1011_2$，再將各次方項寫成對應位元的 $1$，最後疊加求和。
