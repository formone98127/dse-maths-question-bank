卷面概況（以 2027 年大綱為例）

卷一涵蓋必修，通常包括選擇同傳統題，時間約兩小時三十分鐘；卷二涵蓋選修，考生由若干選修課題中選答指定數目。學校考生另有實驗技巧同探究報告嘅校本評核。自修生安排以官方說明為準。

傳統題點寫

  • 定義用精確術語。比較題用表或對照句，每點都兩邊寫。
  • 實驗題寫清自變項、應變項、控制項、量度方法同重覆。解釋結果時連返原理，而唔好只重述表格數字。
  • 圖表題先讀軸同單位，描述趨勢再用生物學原因解釋。
  • 計算題（例如放大率、速率、能量傳遞）寫公式、代入、單位。
