題目

一手袋的標價為 $560$。已知該手袋的標價較成本高 $40\%$。

(a) 求該手袋的成本。

(b) 若該手袋以 $460$ 售出，求盈利百分率。

(4 分)

深度分析

百分數　認知層次：應用　建議作答 90 秒

核心公式／定理：$\text{標價} = \text{成本} \times (1 + \text{加成率})$、$\text{盈利百分率} = \frac{\text{售價} - \text{成本}}{\text{成本}} \times 100\%$

提示 1（啟發）
Hint1: 標價是成本的 140%，不是成本的 40%。
提示 2（知識）
Hint2: 盈利百分率的基準永遠是「成本」。
提示 3（破題）
Hint3: 先畫出成本 -> 標價 -> 售價的數值關係圖。

速解策略：設成本 x，x(1.4)=560→x=400；盈利=(460-400)/400=15%。
