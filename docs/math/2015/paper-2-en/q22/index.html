Question

If an interior angle of a regular polygon is 5 times an exterior angle of the polygon, which of the following is/are true? I. Each interior angle of the polygon is $150^\circ$. II. The number of diagonals of the polygon is 6. III. The number of folds of rotational symmetry of the polygon is 6.

  • A. I only
  • B. II only
  • C. I and III only
  • D. II and III only

Answer

Correct answer: A. I only

深度分析

正多邊形性質　認知層次：分析　建議作答 90 秒

核心公式／定理：內角 + 外角 = 180°、n 邊形對角線數 = n(n-3)/2、正 n 邊形旋轉對稱次數 = n

提示 1（啟發）
先設內角為 x，外角為 y，利用 x + y = 180° 及題意建立方程式求解 n。
提示 2（知識）
確認正多邊形所有內角相等後，計算對角線數目公式 n(n-3)/2 與旋轉對稱次數等於邊數 n。
提示 3（破題）
綜合上述結果判斷哪些陳述正確，注意選項組合是否包含所有正確項目。

誘答項逆向工程

A　✓ 正確答案
B

概念錯誤　忽略 I 項正確性

學生誤判內角為 150°，認為對角線數目 6 是唯一重點，或忘記檢查 I 項是否成立。
C

概念錯誤　誤認 III 項正確

學生算出內角 150°，對角線 6，但錯誤認為正十二邊形旋轉對稱次數為 6（應為 12）。
D

概念錯誤　同時誤認 II、III

學生完全忽略 I 項正確，且錯誤計算旋轉對稱次數為 6，將邊數與對角線數混淆。

速解策略：由內角=5×外角→內角=150°→邊數=12→對角線=54,旋轉=12→僅 I 正確。
