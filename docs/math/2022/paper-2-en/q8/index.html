喺題庫開啟呢題 · 返回 2022 卷二 全卷

題目

Let $f(x) = x^2 - x + 1$. If $k$ is a constant, which of the following must be true?

  • A. $f(k) = f(-k)$
  • B. $f(k) = f(1-k)$
  • C. $f(k+1) = f(k) + f(1)$
  • D. $f(k-1) = f(k) - f(1)$

深度分析

函數的對稱性與代數運算　認知層次：分析　建議作答 45 秒

核心公式／定理：f(x) = x^2 - x + 1、f(a+b) = (a+b)^2 - (a+b) + 1

提示 1（啟發）
思考：一般二次函數 y=ax^2+bx+c 的圖形對稱軸在哪裡？
提示 2（知識）
提示：計算 f(0.5+k) 與 f(0.5-k) 的關係，觀察哪兩個點關於 x=0.5 對稱。
提示 3（破題）
引導：將選項 B 中的 (1-k) 代入原式計算，看看是否等於 f(k)。

誘答項逆向工程

A

概念錯誤　誤判對稱軸位置

學生認為所有二次函數都關於 y 軸對稱 (偶函數)，忽略此題 f(x) 的一次項係數為 -1，對稱軸在 x=0.5。
B　✓ 正確答案
C

計算粗心　展開合併同類項錯誤

學生嘗試代入 k+1，但在展開 (k+1)^2 時忘記了 -2k 或 +1 的符號處理，導致等式不成立。
D

策略錯誤　錯誤的線性假設

學生將二次函數誤認為是線性函數，直接套用 f(a-b)=f(a)-f(b) 的錯誤邏輯進行推導。

速解策略：找出對稱軸 x=1/2，驗證兩選項輸入值是否關於 1/2 對稱。
