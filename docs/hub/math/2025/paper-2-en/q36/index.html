Question

Consider the following system of inequalities:

$$

\begin{cases}

x \leq 11 \

4x + 5y - 19 \geq 0 \

7x - 6y + 11 \leq 0

\end{cases}

$$

Let $ D $ be the region which represents the solution of the above system of inequalities. If $ (x, y) $ is a point lying in $ D $, then the greatest value of $ 8x - 6y + 11 $ is

  • A. $1$
  • B. $11$
  • C. $15$
  • D. $129$
Share on WhatsAppShare on Telegram

Answer

Correct answer: B. 11

深度分析

線性規劃　認知層次：應用　建議作答 120 秒

核心公式／定理：直線截距式與一般式轉換、兩直線交點座標計算公式、目標函數在可行域頂點取極值定理

提示 1（啟發）
線性規劃問題中，目標函數的最大值通常出現在可行域的頂點（邊界交點）上。
提示 2（知識）
請先繪製或想像三條直線 $x=11$、$4x+5y-19=0$ 與 $7x-6y+11=0$，找出它們圍成的封閉區域。
提示 3（破題）
計算出所有相鄰邊界的交點座標，並將這些頂點代入目標函數 $8x-6y+11$ 比較大小即可。

誘答項逆向工程

A

計算粗心　端點計算錯誤

算出交點後，代入目標函數時將 $x$ 或 $y$ 的符號搞錯，導致結果偏小，誤選最小值。
B　✓ 正確答案
C

計算粗心　交點求解錯誤

解聯立方程組時，消元法步驟出錯，算出的交點座標不滿足原不等式條件。
D

概念錯誤　忽略可行域限制

忘記檢查解是否在可行域內，直接將目標函數對 $x$ 的係數放大計算，得到不存在的虛假最大值。

速解策略：解聯立方程求可行域三個頂點，代入 $8x-6y+11$ 比較即得最大值。
