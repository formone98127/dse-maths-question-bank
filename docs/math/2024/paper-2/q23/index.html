題目

圖中，$ABC$ 為一直線。$\frac{BC}{AD} =$

  • A. $\frac{\sin \theta}{\tan \phi}$
  • B. $\frac{\tan \phi}{\sin \theta}$
  • C. $\frac{\cos \theta}{\tan \phi}$
  • D. $\frac{\tan \phi}{\cos \theta}$

深度分析

三角比與相似三角形　認知層次：應用　建議作答 120 秒

核心公式／定理：$\sin \theta = \frac{對邊}{斜邊}$、$\tan \phi = \frac{對邊}{鄰邊}$、$\cos \theta = \sin (90^\circ - \theta)$

提示 1（啟發）
觀察圖形中 $AD$ 與 $BC$ 的位置關係，它們分別位於哪兩個直角三角形中？
提示 2（知識）
利用平行線截割定理或相似三角形的性質，找出這兩個三角形對應邊的比率關係。
提示 3（破題）
將 $AD$ 和 $BC$ 分別用 $\theta$ 和 $\phi$ 的三角函數表示出來，並化簡分式。

誘答項逆向工程

A　✓ 正確答案
B

策略錯誤　倒置比例關係

學生可能混淆了 $\frac{BC}{AD}$ 與 $\frac{AD}{BC}$ 的順序，或者在建立相似比時將分子分母顛倒。
C

概念錯誤　誤用餘弦定義

學生試圖用 $\cos \theta$ 表達，但錯誤地將鄰邊與斜邊的比率直接套用到不同三角形的對應邊上。
D

計算粗心　三角函數轉換錯誤

學生正確識別出需要 $\tan \phi$ 與 $\cos \theta$，但在進行三角恆等式變形時計算出錯。

速解策略：設 $AB=x$，利用相似三角形性質建立 $BC$ 與 $AD$ 的比率關係。
