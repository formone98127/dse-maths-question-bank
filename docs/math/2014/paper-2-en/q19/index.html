Question

$(\cos(90^\circ + \theta) + 1)(\sin(360^\circ - \theta) - 1) =$

  • A. $-\cos^2 \theta$.
  • B. $-\sin^2 \theta$.
  • C. $\cos^2 \theta$.
  • D. $\sin^2 \theta$.

Answer

Correct answer: A. -\cos^2 \theta

深度分析

三角函數　認知層次：應用　建議作答 45 秒

核心公式／定理：$\cos(90^\circ + \theta) = -\sin\theta$、$\sin(360^\circ - \theta) = -\sin\theta$、$(a+b)(a-b) = a^2 - b^2$

提示 1（啟發）
請先利用三角函數的诱导公式，將括號內的 $90^\circ+\theta$ 與 $360^\circ-\theta$ 轉換為只含 $\sin\theta$ 或 $\cos\theta$ 的形式。
提示 2（知識）
觀察轉換後的式子結構，這是否符合 $(a+b)(a-b)$ 的平方差公式特徵？請注意各項的符號變化。
提示 3（破題）
將轉換後的結果代入平方差公式展開，即可得到最終答案。

誘答項逆向工程

A　✓ 正確答案
B

概念錯誤　符號遺漏

學生可能正確算出 $-\sin\theta$ 與 $-\sin\theta$，但在平方差公式應用時，誤將 $(a+b)(a-b)$ 視為 $(a+b)^2$ 或忘記了第二項的負號導致符號錯誤。
C

概念錯誤　符號遺漏

學生在處理 $\cos(90^\circ+\theta)$ 時，錯誤地認為結果為正 $\sin\theta$，導致最終乘積符號錯誤。
D

計算粗心　平方差公式誤用

學生正確轉換角度為 $-\sin\theta$，但計算 $( -\sin\theta + 1 )( -\sin\theta - 1 )$ 時，錯誤地將其視為完全平方或算錯符號。

速解策略：利用诱导公式化簡為 $(-\sin\theta+1)(-\sin\theta-1)$，再套用平方差公式求解。
