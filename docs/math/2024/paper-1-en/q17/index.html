題目

The coordinates of the points ( Q ) and ( R ) are ( (10, -1) ) and ( (-4, -9) ) respectively.

(a) Let ( P ) be a moving point in the rectangular coordinate plane such that ( PQ = PR ). Denote the locus of ( P ) by ( \Gamma ).

(i) Describe the geometric relationship between ( \Gamma ) and ( QR ).

(ii) Find the equation of ( \Gamma ).

(3 marks)

(b) Let ( C ) be the circle which passes through ( Q ), ( R ) and the point ( (4, 3) ).

(i) Find the equation of ( C ).

(ii) The coordinates of the point ( U ) are ( (10, 4) ). It is found that ( U ) lies outside ( C ). ( UV ) and ( UW ) are the tangents to ( C ) at the points ( V ) and ( W ) respectively. Is the area of the circumcircle of ( \triangle UVW ) greater than 100? Explain your answer.

(5 marks)

深度分析

圓與直線　認知層次：分析　建議作答 300 秒

核心公式／定理：$x^2 + y^2 = r^2$、$(x-h)^2 + (y-k)^2 = r^2$、$d^2 = (x_1-x_2)^2 + (y_1-y_2)^2$

提示 1（啟發）
Hint1: $PQ=PR$ 代表 $P$ 到兩點距離相等，這是垂直平分線的定義。
提示 2（知識）
Hint2: 求圓方程需先找出圓心（三點外心）與半徑。
提示 3（破題）
Hint3: 從圓外一點引兩條切線，切點連線與該點構成三角形，其外接圓即為原圓。

速解策略：先由 $PQ=PR$ 得垂直平分線；再由三點求圓心半徑；最後利用切線性質知 $\Delta UVW$ 外接圓即原圓，直接比較面積。
