題目

若 $x-\log y=x^2-\log y^2-10=2$，則 $y=$

  • A. $100$。
  • B. $2$ 或 $-4$。
  • C. $\dfrac{1}{100}$ 或 $10\,000$。
  • D. $\dfrac{1}{10\,000}$ 或 $100$。

深度分析

對數方程式　認知層次：分析　建議作答 90 秒

核心公式／定理：$\log_b(x^n) = n\log_b x$、$x^2 - 10x + c = 0$

提示 1（啟發）
觀察題目結構，將等式拆分為兩個獨立條件：x-log y = x^2-log y^2-10 與 =2。
提示 2（知識）
利用對數性質 log y^2 = 2log |y| 或分情況討論 y>0 與 y<0（若定義域允許）來簡化方程。
提示 3（破題）
解出 x 的兩個可能值後，分別代回原式求 y，並務必驗證所得 y 值是否滿足對數真數大於零的條件。

誘答項逆向工程

A

計算粗心　忽略負根

解出 x=10 後，代入 y=x^2/100 得 100。但忘記檢查另一種情況（當 log y^2 = -10 時），導致漏解。
B

概念錯誤　混淆對數定義域

誤以為 log y^2 可直接化為 2log y 且 y 可為負數，忽略對數真數必須大於零的限制。
C

計算粗心　指數運算錯誤

正確解出 x=10 與 x=-10，但在計算 y 時，將 (-10)^2 誤算為 10000 而非 100。
D　✓ 正確答案

速解策略：由 =2 得 x-log y=2；代入另一式化簡得關於 x 與 y 關係，解出兩組 (x,y) 並驗證定義域。
