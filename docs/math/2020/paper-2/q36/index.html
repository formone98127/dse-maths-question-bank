題目

考慮以下的不等式組：

$$

\begin{cases}

0 \leq x \leq 2 \

2x + y + 3 \geq 0 \

x + y + 1 \leq 0

\end{cases}

$$

設 $ D $ 為表示以上的不等式組的解之區域。求常數 $ k $ 使得 $ 4x + 3y + k $ 的最小值為 24 ，其中 $ (x, y) $ 為 $ D $ 中的一點。

  • A. 25
  • B. 27
  • C. 37
  • D. 53

深度分析

線性規劃　認知層次：應用　建議作答 120 秒

核心公式／定理：$Ax + By + C = 0$、$z = mx + ny + k$

提示 1（啟發）
線性規劃問題中，目標函數的最值一定出現在可行域的頂點上。
提示 2（知識）
請先畫出由三個不等式圍成的可行域 $D$，並標出其所有頂點坐標。
提示 3（破題）
觀察目標函數 $4x+3y+k=24$ 的斜率與邊界直線的斜率關係，判斷最小值出現在哪個頂點。

誘答項逆向工程

A

計算粗心　忽略可行域邊界條件

學生可能只考慮 $x+y+1=0$ 與 $y$ 軸交點，或錯誤計算斜率比率，導致算出較小的 $k$ 值。
B

概念錯誤　混淆最大值與最小值位置

學生誤以為目標函數在可行域另一頂點（如 $x=2$ 處）取得最小值，而非斜率最陡的邊界。
C　✓ 正確答案
D

計算粗心　代入錯誤頂點坐標

學生正確畫出可行域，但將最小值點誤判為 $(-1, 0)$ 或其他非最遠頂點，導致 $k$ 值偏大。

速解策略：畫出可行域找出三個頂點，代入 $4x+3y=k-24$ 比較何者使 $k$ 最大（因係數為負時最小值對應最大 $k$）。
