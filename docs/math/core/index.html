必修部分範圍

必修部分分三大範疇：數與代數、度量圖形與空間、數據處理。Paper 1 以長題目考推導同解釋，Paper 2 以多項選擇考速度同概念辨析。實際題型同分數分佈以考評局當年評核大綱為準。
