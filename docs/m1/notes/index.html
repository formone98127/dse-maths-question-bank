微積分思路

先建立「平均變化率可以縮到瞬間變化率」嘅直覺，再用法則去算。遇到文字題，先指定變量同單位，寫出 s(t)、A(x) 呢類函數，先再微分。增減、凹性同最值要分清楚：導數為零只係候選，唔等於一定係所需答案。

積分方面，先問自己「呢條函數嘅原函數係咩」，再用代入法處理複合函數。面積題一定要畫圖，交點要解方程，而唔好目測。如果區間內函數係負，面積要用絕對值或分拆區間。

統計思路

每次先命名試驗同隨機變量。二項同幾何等離散模型，要把「成功」定義寫出來。連續模型則注意概率對應面積，單點概率為零。標準化時，方向（大於／小於／之間）會決定你點樣用表。

推斷統計最易混淆嘅係用語：點估計係一個值，區間估計係一個範圍。解釋置信水平時，重點放喺方法嘅長期表現。假設檢驗如果出現喺課程範圍內，要寫零假設、對立假設、檢定統計量同結論語氣（拒絕或不拒絕，而唔好聲稱證明）。

常見陷阱

  • 微分之後忘記單位，或者把變化率當成總量。
  • 積分漏咗常數，或者定積分上下限代入次序顛倒。
  • 把獨立當成互斥，或把樣本標準差同總體參數混為一談。
  • 常態近似未檢查條件，就直接套用。
