題目

若 $ a>0 $，則下列何者為等差數列？ I. $\log a^{-3}, \log a, \log a^5$ II. $8-4a, 9-5a, 10-6a$ III. $\cos(90-a)^\circ, \cos 90^\circ, \cos(90+a)^\circ$

  • A. 只有 I 及 II
  • B. 只有 I 及 III
  • C. 只有 II 及 III
  • D. I 、II 及 III

深度分析

等差數列, 對數性質, 餘弦函數　認知層次：分析　建議作答 45 秒

核心公式／定理：\log(a^b) = b\log a、\cos(90\pm \theta) = \sin/\cos \theta、\text{等差條件: } d_2-d_1 = d_3-d_2

提示 1（啟發）
檢查 I：利用對數法則 \log a^n = n\log a，將三項化為 \log a 的倍數形式。
提示 2（知識）
檢查 II：觀察三項係數變化規律，計算相鄰兩項之差是否為常數。
提示 3（破題）
檢查 III：利用 \cos(90-\theta) = \sin \theta 與 \cos(90+\theta) = -\sin \theta 展開並比較公差。

誘答項逆向工程

A

概念錯誤　忽略 III 項為等差

學生算出 I(公比)與 II(公差)正確，但誤判 III。可能認為餘弦函數非線性故無等差，或計算 \cos(90-a)-\cos 90\neq \cos 90-\cos(90+a) 時出錯。
B

計算粗心　誤判 II 項非等差

學生正確判斷 I 與 III，但在計算 II 時，將 \frac{(9-5a)-(8-4a)}{1} = 1-a\neq 0 看錯，或混淆線性表達式是否為常數。
C

概念錯誤　誤判 I 項非等差

學生忽略對數指數法則，將 \log a^{-3}, \log a, \log a^5 視為 \log(a^{-3}), \log a, \log a^5 直接比較數值，未化簡係數 -3, 1, 5 成等差。
D　✓ 正確答案

速解策略：化簡 I 為係數等差；II 為線性式公差固定；III 轉餘弦為正弦後驗證等差。
