閱讀卷一：先判斷任務

甲部圍繞指定文言材料，乙部係課外篇章。兩部都可能出現解釋、填表、選擇、短答同較長嘅分析題。先睇題目要你「解釋」「概括」「分析手法」定「比較」，再決定答案長度，唔好未審題就默寫預製段。

甲部指定篇章

  • 解釋詞句：先釋關鍵詞，再放到整句或整段說明；最後補一句同主題嘅關係。
  • 段旨或主旨：用自己嘅句子寫「作者要講乜 + 點樣推進」，避免只抄段中四字語。
  • 手法：點明手法名稱、指出文中安排（用自己嘅話概述位置即可）、說明對情意或論點嘅作用。三者缺一，分數好易停喺中間。
  • 比較：先寫共同點，再寫差異，最後收束。比較對象可以係兩段、兩人，或兩篇指定材料。各篇可比較角度見篇章總目。

乙部課外篇章

  • 先快速標示文體（記事、抒情、議論、說明或實用），估計作者立場同寫作對象。
  • 整合題先用表列出「材料 A／B 各自重點」，再寫異同或關係，避免邊睇邊寫到後半先發現漏咗一段。
  • 開放題都要文本依據：先引用或概述原文細節，再先評價。只有感想會偏離評核重點。

寫作卷二：甲部實用寫作

甲部通常提供閱讀材料，要求你完成一項有對象、有目的嘅任務，並設字數上限。得分關鍵往往唔係文采，而係有冇完成任務。

  1. 圈出讀者、身份、目的、文體（例如書信、演講辭、建議書、評論）同限制。
  2. 從材料抽出可用事實、立場同數據，分成「必須用」同「可選用」，避免整段抄錄。
  3. 先寫結構大綱，再行文。實用文要有標題或稱謂、分段目的、具體建議或理據、同得體收束。
  4. 寫完用一分鐘核對：有冇越權（寫咗題目唔要求嘅文體）、有冇忽略某則關鍵材料、有冇超過字數。

寫作卷二：乙部命題或情境寫作

乙部可能要求長文一篇，或短文數篇，題目或命題、或指定情境，並提供選擇。揀題先問自己：有冇足夠生活或閱讀材料去寫出層次，而唔係揀表面「好寫」。

  • 記敘抒情：時間線要清楚，細節服務主題，結尾有回望或意義，避免流水帳。
  • 議論：立論要可辯，結構用「立場—理據—反面或限制—結論」。每段一個功能。
  • 短文組合：每篇完成一個任務，但三者最好有隱線（同一主題嘅不同側面），唔好三篇互唔相干。
  • 語言：通順、得體、標點清楚，比堆砌成語重要。有余力先追求修辭。

校本評核同日常操練

閱讀匯報要求你就作品寫文字報告同做口頭匯報。選書之後，應用「作品資訊、內容把握、個人評價、提問同反思」呢組骨架，並且保留過程紀錄。口頭匯報要排練時間，用提綱而唔係朗讀整份報告。詳細次數同評準，請以校本評核手冊同學校安排為準。
